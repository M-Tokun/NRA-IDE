

# NRA-TCM Parser (Text Crystallization Method)



> **"Linear time is a constraint. Gravity is the truth."**

> 線形時間を破壊し、意味的重力によって情報を結晶化させる次世代テキスト解析エンジン。



## 1. 概要 (Overview)

**NRA-TCM Parser** は、1500ページ級（1Mトークン）の超長文コンテキストを処理するために設計されたPython製解析ツールです。



従来の「要約（Summarization）」が情報の**不可逆圧縮（量だけ減らす）**であるのに対し、本ツールは情報の**位相変換（質を変える）**を行います。

文章を「時系列ログ」としてではなく「意味空間に浮遊する粒子」として扱い、**動的な閾値（Dynamic Threshold）**と**直感回路（Intuition Circuit）**を用いて、ノイズ（残滓）とシグナル（結晶）を物理的に分離します。



## 2. 核心機能 (Core Features)



### 🌌 動的ラッパー (Dynamic Momentum Wrapper)

システムは静的な基準を持ちません。

読み進める中で「有益な情報」に出会うと**厚み（Momentum）**が増し、閾値が下がります（没頭モード）。逆に「ノイズ」が続くと厚みが減り、閾値が上がります（飛ばし読みモード）。

これにより、人間のような**「文脈に依存した読み」**を再現します。



### ⚡ 直感回路 (Intuition Circuit)

論理的な文脈（厚み）が失われている状態でも、システムは常に**特異点（Singularity）**を探しています。

「結論」「しかし」「重要」といった強力なキーワードを検知すると、論理ゲートをバイパスして強制的に結晶化（Spark）を行い、システムの集中力を一撃で回復させます。



### 🏗️ 階層逆転ポテンシャル (Inverse Hierarchy Potential)

Markdownの構造において、浅い階層（`#`）よりも深い階層（`###`）にこそ、具体的かつ重要な情報が宿ると定義します。

深い階層の記述には重力ボーナスが与えられ、些細な注釈の中に隠された真実を見逃しません。



## 3. 動作環境 (Requirements)

- **Python 3.8+**

- **依存ライブラリなし** (Standard Library Only)

  - `os`, `sys`, `re`, `math`, `dataclasses` のみを使用。

  - 外部依存を排除することで、あらゆる環境で即座に動作する「標準装備」としての堅牢性を確保。



## 4. 使い方 (Usage)



### 基本実行

解析したいMarkdownファイル（またはテキストファイル）を引数に渡して実行します。



```bash

python nra_crystallizer_JP_v3_1.py input_document.md



```



### 出力



実行後、同ディレクトリにレポートファイルが生成されます。



* `input_document_要約_YYYY-MMDD-HHMM.md`



レポートは以下のセクションで構成されます：



1. **⚡ INTUITION SPARKS:** 文脈を無視してでも拾うべき「お宝（特異点）」。

2. **◆ CRYSTALLIZED KNOWLEDGE:** 文脈の流れの中で重要と判定された知識。



## 5.チューニング (Configuration)



コード内の定数 `BASE_TAU` を変更することで、結晶化の「純度」を調整できます。



```python

# nra_crystallizer_JP_v3_1.py : Line 18

BASE_TAU = 0.41



```



| 値 (Value) | モード | 挙動の説明 |

| --- | --- | --- |

| **0.35** | **Strict (厳格)** | 水位が低い。核心とスパークのみを残す「超要約」。 |

| **0.41** | **Balance (標準)** | **推奨**。文脈と核心のバランスが良い。 |

| **0.50** | **Loose (寛容)** | 水位が高い。雑談や補足も含めて広く拾う。 |





## 6. 入力プロトコル (Input Protocol)



本システムは **「構造化された意思」** のみを解析対象とします。



* ✅ **Allowed:** `.md`, `.txt`

* 🚫 **Rejected:** `.pdf`, `.doc`, `.html` (これらはノイズとみなされます)
