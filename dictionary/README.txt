NRA-IDE Dictionary Directory / リポジトリの辞書置き場
=====================================================

[English]

This directory is the repository's dictionary location. It holds
dictionaries that let you look up, in one place, the meaning,
notation, permitted uses, and common confusions of the terms,
symbols, and fixed names used across this repository.

Files in this directory:
- NRA-IDE_Dictionary_JP.md — the NRA-IDE theory dictionary, Japanese
  version (entries in Japanese-alphabetical order)
- NRA-IDE_Dictionary_EN.md — the NRA-IDE theory dictionary, English
  version (entries in alphabetical order)

The Japanese and English versions are separate files, paired by a
shared entry ID for every term (for example, #absorption-thickness),
so the same entry can be found in both.

These dictionaries are non-normative. They neither create nor change
canonical definitions. Where meaning or notation conflicts, the
precedence order in theory/AXIOMS.md section 16 and the reservations
in FORMULA.md section 7 govern.

If dictionaries for other domains in this repository are added later
(for example, a separate glossary for a different subsystem), they
are placed in this same directory, each as its own file or subfolder.

[日本語]

このディレクトリは、リポジトリの辞書置き場である。このリポジトリで
使う用語・記号・固定名の意味、書き方、使ってよい先、混同しやすい点
を一か所で引けるようにした辞書を置く。

このディレクトリにあるファイル:
- NRA-IDE_Dictionary_JP.md — NRA-IDE理論の辞書、日本語版
  （見出しは五十音順）
- NRA-IDE_Dictionary_EN.md — NRA-IDE理論の辞書、英語版
  （見出しはアルファベット順）

日本語版と英語版は別ファイルであり、各用語に共通の見出しID
（例: #absorption-thickness）を付けて対にしている。同じ見出しを
どちらの版からも見つけられる。

これらの辞書は非規範である。正典の定義を作らず、変えない。意味また
は記号の予約が競合する場合は、theory/AXIOMS.md 第16節の優先順位と
FORMULA.md 第7節の記号予約に従う。

このリポジトリの他分野の辞書が後で追加される場合（例えば、別の下位
システム向けの用語集など）は、同じくこのディレクトリに、それぞれ
別のファイルまたはサブフォルダとして置く。
