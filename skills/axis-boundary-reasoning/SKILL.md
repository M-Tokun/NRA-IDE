# Axis Boundary Reasoning

## Core Principle

推定は、根拠と境界の内側でのみ成立する。

縦軸探索で根拠となる有意点を見つけ、横軸境界探索でその根拠が通用する範囲を限定する。

出発点の数値・条件・境界が不明確な場合、その先は推定ではなく仮説として分離する。

仮説同士を掛け合わせて確定結論にしてはならない。

## Reasoning Discipline

縦軸探索は、情報の中から根拠となる有意点を探す作法である。

横軸境界探索は、時点・条件・層・分類を比較し、根拠が通用する範囲を限定する作法である。

縦軸は、根拠へ向かうアクセルである。

横軸は、推論の適用範囲を止めるブレーキである。

推論では常に、観測された事実、根拠に基づく推定、未確認の仮説を分離する。

結論を出す前に、その結論がどの根拠に立ち、どの境界の内側でだけ通用するのかを明示する。

## Vertical Search

縦軸探索は、わらの中の針を探す能力として扱う。

大量の情報、ログ、文章、コード、記録の中から、目的に対して有意な一点を探す。

縦軸探索では、次を確認する。

- 何を針として探しているか
- その一点が根拠として使える理由は何か
- その根拠は観測事実か、推定か、仮説か
- その根拠を支える出発点の数値・条件・境界は明確か

## Horizontal Boundary Search

横軸境界探索は、10日前の敷き藁と昨日の敷き藁の境界線を見つける能力として扱う。

複数の時点、状態、条件、層、分類を並べ、どこから意味や扱いが変わるかを探す。

横軸境界探索では、次を確認する。

- 比較する対象は何か
- どの順序または軸に並べるか
- どこまでは同じ根拠が通用するか
- どこから別の根拠、条件、分類として扱うべきか

## Estimation Rules

推定は、明示された根拠または観測値の上にだけ立てる。

確定値と明示ルールから導けるものは推定として扱える。

確定値と仮説から導くものは、条件付き推定として扱う。

仮説と仮説から導くものは、推定ではなく仮説の連鎖として扱う。

不明な出発点から導いたものは、探索対象であり、結論にしてはならない。

## Output Pattern

不確実性を含む問題では、次の順で整理する。

1. 観測された事実
2. 出発点となる数値・条件・境界
3. 縦軸探索で見つけた根拠
4. 横軸探索で引いた適用境界
5. 根拠と境界の内側で成立する推定
6. 推定から分離した仮説
7. 追加探索が必要な不明点

## Guardrails

根拠が見つからない場合は、推定を止めて仮説として報告する。

境界が見つからない場合は、適用範囲を限定できないものとして報告する。

出発点の数値・条件・境界が曖昧な場合は、その曖昧さを先に明示する。

推論を進めるときは、縦軸で根拠を増やし、横軸で適用範囲を狭める。
