# Skill: 文書・論文・数式執筆の直下式経路（Document & Paper Writing Route）

> 本 Skill は `RULES_DETAIL.md` の `400` から `GOSUB` で呼び出される。新規の文書・論文・解説の作成、および既存文書の節・定義・公理・数式の追加・改訂時に適用する。基礎原則は `skills/README.md` に従う。

## 本体経路（`10`〜`999`）

```text
#ROUTE DOCUMENT_PAPER_WRITING v1 ; 番号はこのブロック内だけ（他文書の経路番号とは独立）
#RETURN 990=STOP 999=DONE ; 呼び出し元へは語だけを返す。番号をブロックの外へ持ち出さない
#CONST ; 全経路で常に成立。破れたら 990
W1 観測事実・推論・仮説・不明を混同しない。不明箇所を推測で埋めず (0) または [不明] として明示する
W2 禁止語句（「おそらく」「一般的に」「多くの場合」「確率」「平均」「統計」の無根拠使用）を本文へ混入させない
W3 数式は数学的同値変形による逆導出を行わず、因果流・符号・入子順序・未知数/残差スロットを保持する
W4 Markdown は LF のみ・UTF-8（BOM なし）・ブロック数式は $$ を使用する（RULES_DETAIL.md C4）
#END-CONST

10 起点固定：skills/thought-boundary-5w1h/SKILL.md を適用し、目的・対象・固定条件・5W1H・0〜50 数値ラベルを確定する（必須領域のため不明要素は (0) と明記）。GOTO 20
20 IF 不確実性・仮説・複数時点/条件/層の比較を含む:
      skills/axis-boundary-reasoning/SKILL.md を適用し、縦軸探索（根拠）と横軸探索（適用境界）を分離する。仮説同士の連鎖で確定結論を出さない。GOTO 30
   ELSE: GOTO 30
30 正典・語彙照合：NRA-IDE 正典（AXIOMS.md・FORMULA.md・dictionary/NRA-IDE_Dictionary_JP.md）と用語・記号・状態名を照合する。非正典・草案・検討記録の場合は文書冒頭へ位置付けを明記する。GOTO 40
40 IF 数式を含む:
      dictionary/NRA-IDE数式配置の5大鉄則（式の文法）.md を適用し、左右項の因果流・通分禁止・符号統一・入子分解順序・未知数/残差スロット分離を確認する。GOTO 50
   ELSE: GOTO 50
50 表現・書式検査：W1〜W4 の違反がないか照合する。違反があれば修正する。修正不能または根拠不足なら GOTO 990、適合すれば GOTO 60
60 IF 既存の利用者記述を変更する AND 箇所の承認なし:
      対象箇所・原文・問題と根拠・修正案・影響を提示する。GOTO 990
   ELSE: GOTO 999
990 STOP：不足・根拠欠落・未承認事項を報告し、呼び出し元へ STOP を返す
999 DONE：執筆条件・照合完了を呼び出し元へ DONE で返す
```

## 適用対象と除外

- **適用対象**：新規の文書・論文・解説・仕様書の作成、および既存文書における節・定義・公理・数式の追加・改訂。
- **適用外**：Git 制御（`commit` / `push`）、エラー直下停止（`docs/ERROR_MANUAL.md`）、箇所と内容が明示済みの 1 行誤字修正・定型スクリプト出力同期。
