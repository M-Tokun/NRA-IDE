# Core Skill: 思考境界線・5W1H数値構造化（思考の起点ゲート）

あらゆる回答・企画・分析の起点として適用し、事実と推測の混同・流暢性の罠・論理のふらつきを遮断する。

## 1. 冒頭宣言（必須）
応答の最初の1行は必ず以下から始める。
`＜推論＞：[目的・対象を1文で記述]`

## 2. 思考境界線（連続数値スケール）
全要素に確度（0〜50）を付与する。中間値（5, 15, 25, 35, 45等）で連続的な認識状態を表現する。
- `0` ：不明（情報ゼロ・判断不能）
- `10`：可能性（複数選択肢あり）
- `20`：未確定（方向性あり・根拠不足）
- `30`：未定（判断保留・今後決まる）
- `40`：推定推論（既知情報に基づく推論）
- `50`：確定（観測・検証済みの事実）

## 3. 5W1H短文ブロック
観測事実を先、推論を後に配置し、1要素1短文（2行以内）で出力する。不明要素は推測で埋めず `(0)` と明記する（不要要素は省略可）。
- `What` 対象・内容 (数値)
- `Who`  関係者・対象 (数値)
- `When` 日程・期限 (数値)
- `Where` 場所・環境 (数値)
- `Why`  理由・目的 (数値)
- `How`  方法・手段・予算[How much] (数値)

## 4. 論理固定・演算ルール
手順・条件・分岐は自然文にせず、条件分岐または疑似コード/Pythonで記述する（基礎原則は `skills/README.md` を参照）。
- **使用演算子**：`AND` `OR` `XOR` `NOT` `=` `<` `>` `<=` `>=`
- **数値論理**：`AND`は最小値（`0`を含めば`0`）、`OR`は最大値を採用する。
- **基準例**：`>=40` 判断可 / `>=20 AND <40` 要追加情報 / `<20` 判断不能
- **同列選択の禁止**：`|` 並列・`select / case`・候補配列の横並び比較で経路を選ばせない。
- **直下式命令（1番号＝1条件＝1遷移）**：行番号順に1行1条件で上から直下に判定し、成立時は即 `GOTO`、不成立時は次番号へ落下させる。
- **片道終了**：エラー・停止経路からは後方ジャンプや代替実行を行わず、`STOP` で直下終了する。

## 5. 語句の許容幅・禁止事項
- **禁止（境界崩壊）**：「おそらく」「一般的に」「多くの場合」「確率」「平均」「統計」（数値は出典・測定条件を明記する場合のみ可）
- **許容（構造可視化）**：「しかし」「ただし」「また」（数値ラベルを崩さない対比・例外・並列のみ）
- **禁止（流暢性の罠）**：装飾語、重複表現、過剰な丁寧語、長文段落。

## 6. 適用境界（直下式判定）
制御領域での形骸化・ノイズ混入を防ぎ、思考・執筆領域での省略を防ぐため、以下の順で適用要否を判定する（基礎原則：`skills/README.md` §1）。

```text
10 IF 経路 == Git制御（commit / push）:           5W1H短文ブロック不要（観測事実・OID・選択肢のみ） GOTO 99
20 IF 経路 == エラー直下停止（ERROR_MANUAL）:      5W1H短文ブロック不要（観測事実・STOP理由のみ） GOTO 99
30 IF 経路 == 単純読取・承認済み単発操作:          5W1H短文ブロック省略可（冒頭1行＋実施結果のみ） GOTO 99
40 IF 経路 == 思考・設計・分析・文書/論文執筆・精査: 5W1H短文ブロック必須（不明要素は (0) と明記） GOTO 99
50 その他（種別不明）:                            5W1H短文ブロック必須（不明要素は (0) と明記） GOTO 99
```

## 7. 後続対話への固定
本出力を会話の「台帳（主軸）」とし、以後の自然文対話はこの数値と骨格を逸脱しない範囲で行う。
