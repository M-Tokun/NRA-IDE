# 誤ってコピーされた入れ子フォルダの削除

- 操作コードは DEL。利用者が Windows エクスプローラーから、`NRA-IDE/NRA-IDE/` を削除した。
- 理由: 利用者の申告によると、コピーコマンドの誤操作で作られた同名の入れ子フォルダで、不要だったため。
- 削除の実行時刻は不明。2026-11-25 15:21 JST の確認時点で、ファイルは残っていなかった。
- 削除前の確認（読取のみ）: 独立した `.git` を持つリポジトリの丸ごとのコピーで、10,265 ファイル、721MB（うち `.gitignore` 対象のキャッシュ類 7,386 件）。HEAD は `e8d4aad` で、未push commit、stash、未追跡ファイル、未commit変更はいずれも 0 件だった。内側にだけある作業は確認されなかった。
- 削除後の確認: ファイルは 0 件。ただし、空のディレクトリ 12 個（`NRA-IDE/NRA-IDE/` 自身と、`NRA-IDE/NRA-IDE/local_reports/gate-acceptance-*/` 配下の 11 個）が残っていた。更新時刻は 15:18〜15:19 JST で、確認の約 2 分前にあたる。削除の途中または直後に作られたものとみられる。原因は未確認。
- 残りの処理: 利用者の指示（「空のフォルダ 12 個削除」）を受け、空のディレクトリ 12 個のみを削除する操作（`find -depth -type d -empty -delete`。ファイルがあれば削除されない）で削除した。削除前のファイルは 0 件。削除後、`NRA-IDE/NRA-IDE/` は存在しない。外側の Git の状態は変わらない（追跡ファイルの欠落なし）。
- このフォルダは外側のリポジトリの Git 管理外（未追跡）であり、外側の追跡ファイルに欠けはなかった（欠落 0 件）。Git の commit による削除の記録（AGENTS.md §7）の対象外。この報告書が記録にあたる。
