# Deployment Checklist

## ✅ Legal & Ethical
- [ ] 倫理委員会の承認取得
- [ ] 患者同意書（Informed Consent）の準備
- [ ] 責任医師（Gatekeeper）の指名

## ✅ Technical
- [ ] FPGAの自己診断LED（Green）点灯確認
- [ ] ホストPCとFPGAの通信ループバックテスト完了
- [ ] 停電対策（ノートPCまたはUPS使用）

## ✅ Operational
- [ ] 緊急停止手順（Ctrl+C および 電源OFF）の周知
- [ ] 定期メンテナンススケジュールの策定
