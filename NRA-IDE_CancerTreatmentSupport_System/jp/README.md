## 1. プロジェクト概要 (Project Overview)

**NRA-IDE**（Non-statistical Ritsukan Axiom - Integrated Deterministic Engine）は、癌細胞の物理的特性を解析し、転移リスクを決定論的に判定する次世代のがん治療支援システムです。

従来の医療AIが数百万人の「統計（平均）」に依存するのに対し、本システムは目の前の患者一人の「物理（実測値）」に依拠します。
物理法則（構造力学）によって計算される「転移が不可能な条件」を特定し、治療計画を支援します。

## 2. 核心哲学：律環公理 (The Ritsukan Axiom)

本システムの全ての設計判断は、以下の3つの公理に従っています。

1. **Physics First (物理第一主義):** 判定の根拠はすべて物理式 

 で説明可能であり、ブラックボックスを排除する。
2. **Fail-Closed (ギアメカニズム):** 通信、計算、入力のいずれかに 1ビットでも不確実性があれば、システムは安全側に倒れ、警告（Error）を発する。
3. **Gate Axiom (ゲート公理):** システムは計算機に徹する。最終的な「治療の断行」は、倫理的責任を負う医師が決定する。

## 3. 技術アーキテクチャ (Technical Architecture)

本システムは、高い再現性とリアルタイム性を保証するため、ハードウェアとソフトウェアのハイブリッド構成を採用しています。

* **Compute Layer (FPGA):** Intel Cyclone V / Xilinx Artix-7 上で動作する専用演算回路。Q8.8 固定小数点演算により、OSの介入を排した決定論的計算を実行。
* **Control Layer (Python):** 医師の入力を物理的に検証し、FPGA とバイナリプロトコルで通信。臨床レポートと安全マップ（Safety Map）を生成。
* **Verification Layer:** 物理シミュレーションに基づく期待値（Oracle）を用いた自動診断機能を備え、稼働前の健全性を証明。

## 4. クイックスタート (Quick Start)

導入と運用の詳細は以下のドキュメントを参照してください。

1. **設置:** `50_Deployment/installation_guide.md` に従い、FPGA と PC を接続。

3. **運用:** `python main.py --data patient.json` を実行し、臨床レポートを出力。

## 🔍 1. 背景：従来の治療と再発リスク層別化

* 図: 子宮体腫瘍の血流モデル / おおまかな単なる概要参考図4.png

従来の治療指針では、主に**「筋層浸潤の深さ」や「組織グレード」**に基づき、手術・化学療法・放射線治療を選択し、下記のようにリスク分類されます：

* **低リスク**：内膜内、分化型
* **中リスク**：1/2未満浸潤、Grade 1/2
* **高リスク**：1/2以上の深部浸潤、リンパ転移・血管浸潤

* 図: 子宮体がんの治療フロー /おおまかな単なる概要参考図5.png)
* 図: 再発リスク層別化マップ/おおまかな単なる概要参考図6.png)

これらの分類は重要ですが、**薬剤が物理的に“届いていない”領域**があることを、数値的に評価する術は乏しいのが現状です。

## ⚠️ 2. 問題提起：「効いていない」ではなく「届いていない」

### 🔴 問題点

* がん組織内では**高間質圧（IFP）**が発生し、**中心部への薬剤到達が困難**
* **低灌流領域**では、**静脈内投与薬剤が血流とともに押し返され、局所浸潤や再発の温床**となる
* 子宮体腫瘍では**リンパ節と連動した分岐流路**があり、**方向性を伴わない拡散薬物動態**が起きやすい

---

## ⚙️ 3. NRA-IDEの手法：構造力学 × 判定エンジン

* 図: NRA-IDE対応構造図イメージ /おおまかな単なる概要参考図7.png

NRA-IDEは、**薬剤投与の「届く/届かない」**を以下のように**物理モデルで定式化**します。

### 🧠 抵抗モデル（律環公理に基づく判定）

$$
F_{\text{resist}} = (k_{\text{cell}} + B_{\text{drug}}) \cdot \Delta x + \eta \cdot \frac{dv}{dt}
$$

* $k_{\text{cell}}$: 腫瘍細胞の硬さ（ヤング率）
* $\eta$: 粘性（細胞質・血漿・基質流体）
* $\Delta x$: 薬剤変形侵入量（腫瘍間隙とのミスマッチ）
* $\frac{dv}{dt}$: 投与速度変動

### ✅ 判定基準

$$
F_{\text{resist}} > \Delta P \cdot A \Rightarrow \text{STOP (薬剤届かない)}
$$

* 投与圧が腫瘍構造の抵抗に勝てない → **"届かない領域"**
* 粘性がゼロ、または圧力低下で侵入不能なケース → **Error (DANGER)判定**

---

## 🧪 4. 応用：SAFE / BORDER / DANGER 領域定義

NRA-IDEでは、腫瘍周辺の各領域において、**入力パラメータ（細胞硬度・粘性・血流圧・腫瘍厚）**をFPGAによりリアルタイム処理し、次の3ゾーンに分離します：

| 判定ゾーン     | 状態       | 処置方針      |
| --------- | -------- | --------- |
| ✅ SAFE    | 抵抗 < 投与圧 | 通常投与可     |
| ⚠️ BORDER | 抵抗 ≈ 投与圧 | 粘性・速度調整推奨 |
| ❌ DANGER  | 抵抗 > 投与圧 | 投与中止・経路変更 |
