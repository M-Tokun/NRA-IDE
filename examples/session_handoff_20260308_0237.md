## 今セッションの重要な知見

### 農業の構造的問題（とおくにさんの現場知識）
```
- 拮抗作用の文献が極めて少ない
- 専門家が縦割り特化で統合視点がない
- 静的グラフしか作れない → 動的記述ツールがない
- 現場データ収集は「τを決めるため」と割り切れる
```

### 黒ぼく土（Andosol）の特性
```
- CEC：30〜50 cmolc/kg（一般の2〜3倍）
- K⁺が固定されやすい → τを広め設定
- 北海道専門家でMg²⁺/K⁺拮抗の解釈が分かれている
- NRA-IDE視点：争うべきはτの値であって式の構造ではない
```

### Mg²⁺/K⁺拮抗の構造
```
- 畑作3品の通常時τ差は小さい（作物間差異は少ない）
- 障害発生時のMg²⁺吸収阻害 → K⁺拮抗連鎖が主要リスク
- 連結ゲートで構造的に記述できることを実証
```

### Layer 5 の位置づけ確定
```
FvCBモデル = δ生成装置
NRA-IDE   = δを受け取ってR判定するだけ
→ 「外部理論体系が必要な領域」でも
  R = δ/τ の式は変わらない
```

### 植物の複雑さの本質
```
外部要因の時間軸：
  秒：気孔開閉
  分：光合成応答
  時間：イオン吸収
  日：フェノロジー
  季節：根系発達

NRA-IDEの強み：
  全てαの値を変えるだけで吸収できる
  原因が何であれδに変換すれば同じ軸で比較
```
