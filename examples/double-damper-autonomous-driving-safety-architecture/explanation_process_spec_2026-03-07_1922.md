# explanation_process_spec_20260307_192203.md

## NRA-IDE サンプル.html 説明工程仕様書

### 1. 目的
この仕様書は、`nra_ide_sample_demo_20260307_192203.html` をどのような意図で構成したかを説明するものです。狙いは、単発の閾値判定デモではなく、NRA-IDE の重要な流れである「瞬間境界」「短期ログ再構成」「長期劣化監視」「上限下限ダンパー」を一つの画面で連結し、初見の閲覧者にも一本道で理解できるようにすることです。

### 2. 設計方針
今回のサンプルでは、既存のデモ群の良さを残しつつ、読み手が迷いやすい点を先に潰す方針を取りました。既存サンプルは個別テーマごとの完成度が高い反面、初見では「何が先で何が後か」が分かりにくくなりやすいです。そこで、ゆいならばまず「一画面で理論の流れを閉じる最小構成」を先に置きます。

設計方針は次の四本柱です。

1. AI 内部の正誤判定ではなく、物理境界の直前を監視対象にすること。  
2. 瞬間 R だけで終わらせず、短期ログから傾向を再構成すること。  
3. 年限固定ではなく、負荷由来の長期劣化指数を持つこと。  
4. 上限だけでなく下限も持つダンパー構造を入れて振動と見逃しを抑えること。

### 3. 画面構成
画面は左に制御パネル、右に可視化と説明パネルを置く二列構成です。これにより、操作と結果の関係が一目で分かるようにしています。

#### 3.1 ヘッダー
ヘッダーでは、この HTML が何を実演するのかを一文で明示します。ここで重要なのは、単なる「Band Gate デモ」ではなく、「状態境界＋短期再構成＋長期劣化」の連結であることを先に言い切ることです。

#### 3.2 左パネル
左パネルは監視パラメータと主要メトリクスです。ここで操作できる値は以下です。

- `τ_base` : 基準となる厚み。  
- `α_upper` : 上限側ダンパーの追従感度。  
- `α_lower` : 下限側ダンパーの追従感度。  
- `disturbance` : 外乱強度。  
- `degrade` : 長期劣化の進行速度。  

主要メトリクスは以下です。

- `R_now` : 瞬間の逸脱比。  
- `R_short` : 短期ログ再構成値。  
- `D_long` : 長期劣化指数。  
- `τ_dyn_upper` : 上限側の動的厚み。  
- `τ_dyn_lower` : 下限側の動的厚み。  
- `state` : PASS / DAMP / SILENCE の現在判定。  

この構成にした理由は、利用者が「どの入力を変えるとどの状態量が動くか」を即座に掴めるようにするためです。

### 4. ロジック仕様

#### 4.1 基本思想
この HTML のロジックは、AI の内部推論を検証するものではありません。あくまで「出力が物理境界に対してどう見えるか」を監視するものです。つまり対象は意味ではなく状態です。

#### 4.2 瞬間判定
瞬間判定では、上限側と下限側の逸脱を別々に計算します。

```text
upperDev = max(0, raw)
lowerDev = max(0, -raw)
```

ここで `raw` は外乱を含んだ現在状態です。

動的厚みは、上限側と下限側で異なる構造を持ちます。

```text
τ_dyn_upper = τ_base + upperEMA * 0.65
τ_dyn_lower = max(2.0, τ_base - lowerEMA * 0.35)
```

上限側は蓄積されるほど厚みを拡げてピークを丸めます。下限側は蓄積されるほど厚みを縮めて早く検知します。これが非対称ダンパーです。

瞬間 R は次式です。

```text
R_now = max( upperDev / τ_dyn_upper , lowerDev / τ_dyn_lower )
```

#### 4.3 短期ログ再構成
瞬間 R だけでは静かな悪化を捉えにくいため、直近 28 サイクルの移動平均を持たせています。

```text
R_short = mean(last 28 of R_now)
```

この値は「その瞬間はまだ 1.0 を超えていないが、全体として危険側へ寄っている」という状況を見せるための値です。

#### 4.4 長期劣化指数
長期劣化指数 `D_long` は、短期再構成値と瞬間的な超過から徐々に蓄積されます。

```text
wearInput = max(0, R_short - 0.58) * (0.8 + disturbance * 0.35)
D_long = min(1.8, D_long * 0.995 + wearInput * degradeRate * 0.8 + max(0, R_now - 1.0) * 0.02)
```

ここでは厳密な工学式よりも、「常時ではなく、負荷に応じて寿命的なものが更新される」という設計思想を見せることを優先しています。

### 5. 状態遷移仕様
このデモでは三段階の状態遷移を採用しています。

```text
PASS    : R_now < 0.72 かつ R_short が低く、D_long も低い
DAMP    : R_now >= 0.72 または R_short >= 0.60 または D_long >= 0.45
SILENCE : R_now >= 1.00 または D_long >= 1.00
```

この三段階にした理由は、上限超過だけで即停止すると、境界近傍で振動的な挙動が出やすいからです。DAMP を中間に置くことで、減衰させながら安全側へ戻す工程を作れます。

### 6. 可視化仕様
可視化キャンバスには三本の系列を重ねています。

- 白線 : 生の状態波形。  
- 黄線 : 短期ログ再構成値。  
- 紫線 : 長期劣化指数。  

緑帯は安全域を表し、赤いフラッシュは SILENCE を表します。これにより、瞬間の危険と長期の蓄積を同時に見せられます。

### 7. 操作シナリオ
このサンプルで最低限見せたい操作は次の三つです。

#### 7.1 通常状態
`disturbance` と `degrade` を低めにすると PASS が続きます。ここでは通常通過の状態を確認します。

#### 7.2 スパイク状態
`外乱スパイク` ボタンを押すと瞬間的に `R_now` が跳ね上がります。ここでは瞬間境界が働く様子を見せます。

#### 7.3 静かな劣化
`disturbance` と `degrade` を中程度以上に上げて継続観察すると、最初は PASS でも次第に `R_short` と `D_long` が上がり、DAMP を経て SILENCE に近づきます。ここがこのサンプルの核心です。

### 8. このサンプルを先に置く理由
既存 Git サンプル群は、個別テーマとしてはすでに十分強いです。ただ、初見の閲覧者には「どこから見るべきか」が少し見えにくいです。そこで、最初にこのサンプルを置くことで、次の理解順を固定できます。

1. 瞬間境界を見る。  
2. それだけでは足りないと理解する。  
3. 短期ログ再構成を見る。  
4. さらに長期劣化を見る。  
5. 最後に上限下限ダンパーで安定化を見る。  

この順番にすることで、各既存デモが「何を補っているのか」が見えやすくなります。

### 9. 今後の拡張案
このサンプルは説明用の骨格です。実運用向けに近づけるなら、次の拡張が考えられます。

- センサー別の独立ログ窓を追加する。  
- 上限下限だけでなく、複数指標の重み付き合成を導入する。  
- 劣化指数を温度、荷重、時間密度ごとに分離する。  
- SILENCE の直前に「予兆状態」を一段追加する。  
- 既存の農業、三相モーター、自動運転デモへ同じ骨格を移植する。  

### 10. 結論
ゆいならば、まずこのような「一本道で理解できる雛形」を先頭に置きます。理由は単純で、理論の正しさだけではなく、閲覧者が迷わず構造を掴めることが研究公開ではとても大切だからです。今の NRA-IDE はすでに部品ごとの強さがあります。次に必要なのは、それらを初見の人にも伝わる順番に並べることです。このサンプル HTML は、そのための入口として設計しています。
