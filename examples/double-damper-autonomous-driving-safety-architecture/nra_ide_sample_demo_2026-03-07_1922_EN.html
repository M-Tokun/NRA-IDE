NRA-IDE Sample Demo

This sample is a template for showing, on a single screen, a flow in which the system does not look only at the instantaneous R = δ/τ, but also monitors long-term degradation through short-term log reconstruction, while using a damper structure with upper and lower bounds to suppress both false operation and missed danger. The goal is not to “make AI smarter,” but to “stop AI before it crosses a physical boundary.”

The judgment has three stages. First, if the instantaneous R is high, the system stops immediately. Even before it reaches that point, if the reconstructed short-term log value rises, the system enters the damping region. In addition, as the long-term degradation index rises, the same disturbance becomes more likely to push the system toward danger.

why this layout

Design Principles This Screen Intends to Show

First, the judgment target is not whether the AI is internally right or wrong, but the state immediately before it touches a physical boundary. This is the “frame of the cage.”

Second, because instantaneous judgment alone cannot fully capture quiet degradation, the system reconstructs short-term logs and observes trends across dozens of cycles.

Third, because service life and degradation should not be fixed by calendar age but updated from actual load, the system keeps a separate long-term index axis.

Fourth, because an upper-limit-only threshold tends to oscillate, the system uses asymmetric dampers with both upper and lower bounds, treating the danger side and the depletion side separately.
