Core Principle ／ 根幹原理
⚙️
ESCAPEMENT / 脱進機
機械式時計が精度を保てるのは歯車が完璧だからではない。脱進機が「完全な一歯分」という離散ステップで進むからだ。
🔥
HEAT EMISSION / 熱排出
各ステップの残差（端数）は次のステップに持ち越されず、熱として排出される。これが誤差累積の構造的防止だ。
🔒
INTEGER PHASE LOCK
NRA-IDEはこの原則を実装する。R = δ/τ の計算において残差キャリーオーバーを禁止し、各状態遷移を完結させる。
R = δ / τ
この比率計算においても同一の原則が適用される。
商の整数部 → 次の状態判定に使用 ／ 残差 ε → 破棄（熱として排出）／ キャリーオーバー → 禁止
The same principle applies: integer part used for judgment, residual ε discarded, carry-over forbidden.
