## 概要



本ドキュメントは、NRA-IDE（律環公理・内包性動力学エンジン）の設計原則を実装した  

インタラクティブHTML可視化ツール7本の使い方・内容・ロジック工夫点をまとめたものです。  

すべてのファイルはブラウザ単体で動作します（サーバー不要）。



**共通設計原則**



```

R = δ / τ

  δ : 設計値からの蓄積ズレ

  τ : 構造が吸収できる余裕（一部は動的計算）

  R < 0.75  : SAFE

  R >= 0.75 : WARNING

  R >= 1.0  : FAIL_CLOSED（整合性なければ不能を返す）

```

## ① ベルトコンベアー・Vベルト張力管理



**ファイル名:** `belt_tension_nra_ide_20260319_0059.html`



### 使い方



- 上部ボタンで **コンベアー / Vベルト** を切り替える

- **TENSION CONTROL スライダー** で現在張力を変化させる

- SAFE → WARNING → FAIL_CLOSED の三段階がリアルタイムで遷移する

- FAIL_CLOSED 時はベルトアニメーションが停止する



### 内容



| 項目 | コンベアー | Vベルト |

|------|-----------|--------|

| 最適張力 T_OPT | 500 N | 300 N |

| 許容下限 T_MIN | 400 N | 240 N |

| 許容上限 T_MAX | 650 N | 380 N |

| τ_hi | 150 N（固定） | 80 N（固定） |

| τ_lo | 100 N（固定） | 60 N（固定） |



### ロジック工夫点



- τを「最適値から当該方向の限界までの全余裕」として定義することで、  

  Rが自然に [0, 1] の正規化値になる設計

- スライダーのグラジェントが T_MIN〜T_OPT〜T_MAX の帯を色分け表示

- TRACE LOG に R値・状態・張力を時系列記録

## ② チェーン張力 ゆらぎ利用型自動調整



**ファイル名:** `chain_tension_nra_ide_20260319_0113.html`



### 使い方



- **MANUAL BIAS スライダー** で張力バイアスを変化させる

- **AUTO-ADJ ON/OFF** で自動調整の有効・無効を切り替える

- **DISTURBANCE スライダー** で外乱を手動付加できる

- 波形パネルの **白線** が生波形、**カラー線** が平滑化波形、**紫線** が自動調整出力



### 内容



```

ポリゴン効果（多角形効果）の再現：

  スプロケット歯数による周期的張力ゆらぎを三層合成

  基本波 + 2次高調波 + 3次高調波 + ランダム成分



自動調整の3段階：

  R < 0.5          : 調整不要

  0.5 ≤ R < 0.75  : 微調整（ゆらぎ方向に追従）

  R >= 0.75        : 先行調整（dR/dt から到達時刻を予測）

  R >= 1.0         : FAIL_CLOSED（調整権限を人間に返却）

```



### ロジック工夫点



- `dR/dt`（R値の変化速度）を制御信号として使用することで、  

  到達前に先行介入する予測制御を実装

- **ゆらぎを除去するのではなく追跡する**設計思想を採用

- FAIL_CLOSED 時は自動調整が停止し、スプロケット回転も止まる

## ③ 水温上限・下限管理システム



**ファイル名:** `water_temp_nra_ide_20260319_0120.html`



### 使い方



- **加熱 ON / 冷却 ON** ボタンで温度を変化させる

- **TARGET TEMPERATURE スライダー** で最適温度設定値を変更（上下限が連動）

- **DISTURBANCE スライダー** で外乱温度を付加する

- タンク内の水色が温度状態を反映（青→シアン→橙→赤）



### 内容



```

上限側と下限側を独立評価：

  R_hi = (T - T_OPT) / τ_hi  （温度が上昇側にある場合のみ）

  R_lo = (T_OPT - T) / τ_lo  （温度が下降側にある場合のみ）



τ設計：

  τ_hi = T_MAX - T_OPT = 15℃（固定）

  τ_lo = T_OPT - T_MIN = 20℃（固定）



ゆらぎ構造：

  熱対流ゆらぎ：sin(1.3Hz) + sin(2.7Hz) + sin(4.1Hz)

  センサーノイズ：ランダム成分

  振幅：加熱ON時に2.8倍、高温ほど増大

```



### ロジック工夫点



- 波形グラフをT_OPT±30℃にズームすることでゆらぎを視認しやすく設計

- FAIL_CLOSED 時は反対方向の動作が自動停止  

  （上限超過 → 加熱停止・冷却継続 / 下限超過 → 冷却停止・加熱継続）

- 気泡アニメーションが高温時に発生し、温度上昇を直感的に表現

## ④ 光量（照度）上限・下限管理システム



**ファイル名:** `light_lux_nra_ide_20260319_0135.html`



### 使い方



- **SUN ELEVATION スライダー** で太陽高度を変化させる（天頂90°で最大照度）

- **CLOUD COVER スライダー** で雲量を調整する

- **雲を追加ボタン** で個別の雲が画面を流れる

- **AUTO-SHADE ON** で過照射時に遮光パネルが自動展開する



### 内容



```

照度計算：

  L = 100,000 × sin(elevation°) × (1 - cloudFactor) × (1 - shadeFactor)  [lx]



閾値設定（農業・温室・植物工場想定）：

  L_OPT  = 20,000 lx

  L_MAX  = 50,000 lx（葉焼け・熱ストレス限界）

  L_MIN  =  5,000 lx（光合成停止限界）



ゆらぎ構造：

  大気揺らぎ：sin(0.8Hz) + sin(1.7Hz) + sin(3.1Hz)

  雲通過ゆらぎ：雲存在時に低周波成分追加

  センサーノイズ：ランダム成分

```



### ロジック工夫点



- **単位の整理**：カンデラ（光源側）ではなくルクス（受光側）を採用  

  採光・農業管理は受ける側の管理であるため

- AUTO-SHADE は R_hi が 0.75 を超えた時点から比例的に遮光率を増加させる  

  予兆段階から段階的に介入する設計

- 波形グラフを L_OPT 中心の±30,000lx にズームしてゆらぎを可視化

## ⑤ 電力管理システム（電流×電圧統合）



**ファイル名:** `power_nra_ide_20260319_0150.html`



### 使い方



- **VOLTAGE スライダー** と **CURRENT スライダー** で電圧・電流を設定する

- **負荷増加 ON** で電流が自動増加し過電力状態へ遷移する

- 回路図上の電子が配線を流れるアニメーションが動作する

- 熱蓄積バーが過電力継続時間を反映する



### 内容



```

電流・電圧を電力 P = V × I として統合：

  δ = P_current - P_OPT

  τ_hi = P_MAX - P_OPT = 4,000 W（焼損限界まで）

  τ_lo = P_OPT - P_MIN = 1,000 W（動作不安定限界まで）



ゆらぎ構造（交流電源リップル）：

  50Hz リップル + 100Hz 2次高調波 + 7Hz 負荷変動 + ランダム



熱蓄積：

  過電力が続くほど熱δが積み上がり R値を時間的に押し上げる

  正常時は放熱で自然減少

```



### ロジック工夫点



- 電流・電圧を別々に管理せず **電力 P = V×I** として一本化することで  

  「どちらが先に異常になっても電力として捕捉できる」設計

- **熱蓄積**の概念を追加：瞬間的な過電力より継続的な過電力が危険という  

  物理的事実を R値の時間積分として表現

- FAIL_CLOSED 時はヒューズ断線のビジュアルエフェクトが表示される

## ⑥ 水圧管理システム（非圧縮性流体・固定τ）



**ファイル名:** `water_pressure_nra_ide_20260319_0202.html`



### 使い方



- **PUMP OUTPUT スライダー** でポンプ吐出圧を設定する

- **FLOW RATE スライダー** で流量を調整する

- **ポンプ ON** でポンプ加圧が追加される

- **弁絞り ON** で弁急閉を発動し **ウォーターハンマー** が発生する



### 内容



```

非圧縮性流体の特性：τが固定値

  P_OPT  = 0.50 MPa

  P_MAX  = 0.80 MPa（破裂・安全弁作動限界）

  P_MIN  = 0.30 MPa（ポンプ空転・キャビテーション限界）

  τ_hi   = 0.30 MPa（固定）

  τ_lo   = 0.20 MPa（固定）



脈動ゆらぎ（ポンプ回転数同期）：

  基本波 + 2次高調波 + 3次高調波



ウォーターハンマー：

  弁急閉時に流体の運動エネルギーが圧力衝撃波に変換

  指数減衰×正弦波で物理的波形を再現

```



### ロジック工夫点



- 水圧の脈動ゆらぎはチェーンのポリゴン効果と**同一の数式構造**  

  NRA-IDEの単位非依存性を実証する設計

- ウォーターハンマーは「δが蓄積ではなく衝撃的に発生する特殊ケース」として実装  

  通常の脈動と明確に異なる波形（鋭いスパイク）が波形グラフに現れる

- 配管内の水色が圧力・流量に応じてリアルタイム変化

## ⑦ 空気圧管理システム（圧縮性流体・動的τ・二重ゆらぎ）



**ファイル名:** `air_pressure_nra_ide_20260319_0209.html`



### 使い方



- **COMPRESSOR スライダー** でコンプレッサー出力を設定する

- **TEMPERATURE スライダー** で気体温度を変化させる

- **加熱 ON** でボイル・シャルル則による圧力上昇と τ_hi の縮小が同時発生する

- **排気 ON** で圧力を急速に低下させる

- 波形グラフの**橙色破線**が動的に変動する τ_hi ラインである



### 内容



```

圧縮性流体の特性：τが温度依存で動的計算

  τ_hi(T) = τ_base × (T_ref / T_current)   [ボイル・シャルル則]

    → 温度上昇 → τ_hi 縮小 → R_hi 上昇

    → 圧力を変えなくても温度だけでFAIL_CLOSEDに到達しうる



二重ゆらぎ構造：

  第1ゆらぎ（δ）：コンプレッサー脈動による圧力変動

  第2ゆらぎ（τ）：温度ゆらぎによる余裕の変動

  → R = δ(t) / τ(T,t)  両辺が独立にゆらぐ



τ_lo の温度依存：

  低温時は凝縮リスクを加算してτ_lo を微減させる

```



### ロジック工夫点



- **NRA-IDE 二重ゆらぎ式の実装例として最も深い構造**  

  δとτが両方変動する場合、Rの挙動は単純な比ではなくなる

- 波形グラフに **τの動的ライン**（橙色破線）を追記することで  

  「Rが上昇しているのは圧力のせいかτの縮小のせいか」が視覚的に判別できる

- タンク右側の縦スケールがτ_hi のリアルタイム変動を表示

- 気体分子アニメーションの速度・色が温度と圧力に連動して変化

## NRA-IDE 単位非依存性の実証



7本のツールを通じて明確になったことがあります。



```

R = δ / τ の式は単位に依存しない



  ① 張力  [N]    → R で管理

  ③ 温度  [℃]   → R で管理

  ④ 照度  [lx]   → R で管理

  ⑤ 電力  [W]    → R で管理

  ⑥ 水圧  [MPa]  → R で管理（τ固定）

  ⑦ 空気圧[MPa]  → R で管理（τ動的）

```



変わるのは **δとτの物理的な定義**だけです。  

計算構造・判定構造・Fail-Closed 原則は全7本で完全に共通しています。  

これが NRA-IDE の「構造閾値による状態遷移記述」の本質です。
