# 境界への到達と、そこへ至る履歴 — 2つの視点による模式図

この2つの図は、破断境界に到達した時点と、その手前で進む履歴を、それぞれ異なる合成モデルで示します。

1つ目は、境界到達の場所と重なりを見ます。2つ目は、破断前から進む蓄積と厚みの損失、そして介入が必要になる過程を見ます。

> どちらも模式図です。数値はすべて説明のために式から作った合成値で、実測値でも、検証済みの物理モデルでもありません。6つの層の間に結合はなく、層どうしの相関や因果を示す図ではありません。新しい2本とこの説明は日本語版です。

## 1. 2つの視点と、見る順序

| 視点 | 開くHTML | 主に見ること |
|---|---|---|
| 1：境界への到達 | [多層の同時境界到達](./01_simultaneous_boundary_JP.html) | 同じ時刻・同じ地点で、いくつの層がR≥1に達しているか |
| 2：境界へ至る履歴 | [破断前の履歴と介入](./02_pre_rupture_history_JP.html) | R=1の手前で何が失われ、介入が必要になる状態へどう進むか |

視点1で「境界に達した場所」を見た後、視点2で「その手前の履歴」を見ます。

**2本は、同じ計算結果を別の画面にしたものではありません。** 荷重の生成式、時間範囲、厚みの扱いが異なる別々の合成モデルです。2本の数値を直接比較して効果を証明する対照実験ではなく、共通する主題を違う側から説明する構成です。

## 2. 共通する言葉と、モデルごとの仮定

| 言葉 | この資料での扱い |
|---|---|
| R | 境界接近比。R=δ/τ。大きいほど境界へ近づく |
| δ | この模式では、説明用に合成した荷重を偏差へ対応させる仮定を置く |
| τ | 吸収厚み。δと同じ模式単位で扱う |
| R=1 | 破断境界。R≥1の地点を「破断境界到達」と表示する |
| Fail-Closed | 許可されない自律処理を抑止する運用原則。破断境界の別名ではない |
| x, y | 模式空間の座標。現実の物理的な位置は定義していない |

正典のδは、評価開始前に固定した基準状態から測る、履歴を伴う蓄積ズレです。温度・圧力・電力などの外力や観測値を、そのまま正規のδへ置き換えられるという意味ではありません。この2本には、各物理ドメインで検証した換算規則はありません。

正典の意味は[AXIOMS.md](../../theory/AXIOMS.md)と[axioms.json](../../theory/axioms.json)を参照してください。この図は、正規のR_warn・R_handoff・R_irrevによる状態分類や、実機のFail-Closed制御を実装したものではありません。

## 3. 視点1：境界への到達を見る

対象：[01_simultaneous_boundary_JP.html](./01_simultaneous_boundary_JP.html)

温度・圧力・電力・照度・流量・振動の6層に、移動する荷重の山と背景ゆらぎを置いています。各時刻の場を独立に計算し、R≥1の地点を探します。厚みは層ごとに固定し、蓄積や不可逆履歴は計算しません。

### 表示の読み方

| 表示 | 意味 |
|---|---|
| 積層ビューの各平面 | 1つの層。濃淡はR、明るい塗りはR≥1の地点 |
| 各層の線 | R=1の境界線 |
| 平面図のk | 同じ時刻・同じ地点でR≥1となる、判定対象の層数 |
| 暖色 | 選択したk以上の層が同時に到達している地点 |
| 白い柱・番号 | 同時超過領域を代表する地点 |
| 右側のカード | 層ごとの厚み、最大偏差、最大R、到達地点数 |

k以上の地点を上下左右の4近傍でつなぎ、1つの「箇所」にまとめます。その中でkが最大の地点を代表にします。白い柱は全超過地点を描いたものではなく、層を結ぶ因果経路でもありません。番号と一覧は先頭9箇所までです。

### 操作

| 操作 | 内容 |
|---|---|
| 時間 | t=0〜600の時刻を選ぶ。止めて見たいときは先に一時停止する |
| 再生中／停止中 | 再生と一時停止 |
| 先頭へ | t=0へ戻す。再生・停止の状態は維持する |
| 速度 | ×0.5、×1、×2 |
| 判定k | 同時到達と表示する層数を2〜6から選ぶ |
| 層のチェック | 同時到達の判定に含める層を選ぶ。外した層は積層表示で薄くなる |
| 仰角・回転・ドラッグ | 積層表示の向きを変える |

### 計算と限界

各層で、正の背景と3つの移動する山から比率を作り、δ=比率×τ、R=δ/τとします。τに対する振幅比を与える構成なので、これは厚みの違いによる物理的効果を調べる実験ではありません。

格子は41×41地点、層数は6、乱数の種は33です。時間方向の周波数を整数にしているため、周期T=600で場が繰り返します。到達状態は各時刻の値であり、到達後のラッチはありません。

平均値・多数決で境界を決めていません。独立に生成した層の重なりから、物理的相関や因果を結論づけることもできません。

## 4. 視点2：境界へ至る履歴を見る

対象：[02_pre_rupture_history_JP.html](./02_pre_rupture_history_JP.html)

持続する荷重によって蓄積Aが増え、元の要素の厚みが失われる合成モデルです。瞬間の荷重が小さくなっても、元の厚みと蓄積記録は戻りません。R≥1へ到達する前に、平常荷重だけでも蓄積が続く状態へ入る場合があります。

### 区別する3つのこと

| 項目 | 意味 |
|---|---|
| 元の厚み損失の不可逆性 | 蓄積が始まった時点から、元の要素の厚みが失われる。新しい厚みを追加しても、その損失は消えない |
| 介入必須点 | 平常荷重／合計厚みがr_onを超え、荷重の山が引いても蓄積が続く状態へ入る点 |
| 破断境界到達点 | R≥1に達した点。到達履歴を試行の終了まで保持する |

介入必須点は、「介入なしで蓄積を止める経路があるか」という本モデルの条件です。十分な厚みの追加でその条件を解消できる場合があるため、元の厚み損失が不可逆になる点と同一ではありません。正規のR_handoffやR_irrevそのものとしても扱いません。

### 2面の地図

同じ層・同じ時刻を、2つの見方で並べています。

| 左：R≥1だけを警報する見方 | 右：履歴と自己持続条件を見る見方 |
|---|---|
| 灰色の濃淡：Rの大きさ | 茶〜橙：蓄積履歴がある地点の、介入必須点への進み |
| 赤：R≥1 | 紫：死角区間 |
| | 赤：死角区間を経て破断境界へ到達 |
| | 薄い朱：死角区間を経ずに直接到達 |
| | 青緑の枠：介入した地点 |

右に紫が現れても、左は灰色のままです。この区間ではR自体も変化していますが、**R≥1だけを警報条件にした監視では警報されません。** 厚みと平常荷重を併せて見ることで、自己持続している状態を区別できます。

急な荷重で直接到達する地点もあります。すべての地点で介入必須点が先行する、という意味ではありません。

### 選択地点の推移

地図をクリックすると、その地点の推移が表示されます。

| 線・印 | 意味 |
|---|---|
| 白い実線 | R |
| 水色の破線 | 合計厚み比τ/τ0 |
| 橙の破線 | 蓄積開始レベルr_on |
| 赤の破線・縦線 | R=1と、破断境界へ到達した時点 |
| 紫の網掛け・縦線 | 死角区間と、その開始点 |
| 青緑の三角 | 介入した時点 |

下の説明には、現在の自己持続条件と現在荷重による蓄積の状態を分けて表示します。自己持続条件を解消しても、荷重の山が残っていれば蓄積は続くことがあります。介入の時点では時間やAを進めず、同じ荷重でRと表示を更新します。

破断境界へ到達した地点は、それ以降のR・厚み・Aを更新せず、到達時の保存値を表示します。現在の荷重を観測し続ける監視系を再現した表示ではありません。他地点の計算は続きます。

### 厚みゲージと全体表示

ゲージは左ほど厚い尺度です。初期値1.00を基準にしつつ、追加後の合計が1を超える場合も表示範囲に含めます。

- 上段は合計厚みと境界の関係です。茶〜橙は自己持続開始前、紫は自己持続する厚み帯、暗い赤は平常荷重でR≥1となる厚み帯です。白い三角は現在の合計厚みです。
- 下段は、既存要素の厚み（橙）と追加分（青緑）の内訳です。数値欄にも、既存＋追加＝合計を示します。
- 平常荷重より大きい荷重がかかると、上段の暗い赤の帯へ入る前でも破断境界へ到達します。
- 積層ビューは6層の状態を重ねた補助表示です。選択層は濃く、他は薄く描き、白い輪が選択地点です。ドラッグで回転できます。
- 右側カードのバーは、蓄積履歴あり・死角区間・到達経由・到達直接の地点数の内訳です。「蓄積履歴あり」は、現在もAが増えていることだけを意味する名前ではありません。

### 操作

| 操作 | 内容 |
|---|---|
| 再生中／停止中 | 再生と一時停止 |
| 最初から | 全地点と介入記録を初期化して新しい試行にする。終了後は再生を再開する |
| 速度 | ×0.25〜×16。既定の表示は約4倍 |
| 介入 | その時点で死角区間にある全層の全地点へ、厚み比+0.25を加える |
| 蓄積開始r_on | 蓄積開始レベルを変更し、新しい試行にする |
| 減り方κ | Aに対して厚みが減る速さを変更し、新しい試行にする |

介入の表示には、追加した地点数、なお自己持続する地点数、現在荷重で蓄積する地点数を示します。破断境界到達後の地点には追加しません。

一巡t=2400で全体を停止し、表示と履歴を保持します。時間経過による自動リセットはありません。「最初から」またはパラメータ変更は、損傷を修復する操作ではなく、別の試行の開始です。

r_onが平常荷重の最大値以下の設定では、平常荷重だけで蓄積が始まる場合があるため警告を表示します。

### おすすめの見方

1. 既定の約4倍で再生し、右の地図に紫が現れるのを待ちます。最初の地点はt≈328.5です。
2. 左の地図では、その地点がまだ灰色であることを確かめます。
3. 時系列で、荷重の山が過ぎても厚みが戻らず、平常荷重で進行する区間を見ます。
4. 紫の開始と赤の到達との間が死角区間です。到達前の厚み損失にも注目してください。
5. 初期化して、紫が現れたところで一時停止し、介入します。R・時系列・説明の変化と、既存厚みの損失が残ることを見ます。早い介入と遅い介入では、+0.25の結果が異なる場合があります。
6. 照度・振動の層では、既定の一巡中に死角区間へ入らない例を見られます。急な荷重で直接到達する別の地点はあります。

## 5. 視点2の式と、介入効果の条件

d=δ/τ0を合成した荷重比、h=τ/τ0を合計厚み比とします。A、r_on、κはこの模式専用の量です。

各地点で時間を0.5刻みに進めます。

```text
d = 平常荷重比 + 持続型の山（2つ）+ スパイク（1つ）
R = d / h
R > r_on のとき：
    Aに (R − r_on) × 0.5 を加える（減らさない）
    既存厚み比 = max(0.05, 1 − κ × A)
    h = 既存厚み比 + 追加厚み比
    Rを同じdと新しいhで再計算
R ≥ 1 → 破断境界到達。以後この地点の保存値を固定
平常荷重比 / h > r_on → 自己持続する死角状態
```

介入は、その時点のhへ0.25を加えます。Aと既存厚みの損失は保持します。

| 目的 | 必要な条件 |
|---|---|
| 平常荷重による自己持続を解消する | 追加後のh ≥ 平常荷重比/r_on |
| 現在の荷重で直ちに蓄積を止める | 追加後のh ≥ 現在荷重比/r_on |

したがって、+0.25が常に十分とは限りません。自己持続を解消しても、現在の荷重が大きければAは増えます。その後、再び自己持続条件に入る場合もあります。

介入履歴のない既定例では、自己持続条件へ入った後も平常荷重が続くと、Aが増え、厚みが減り、Rがさらに上がって破断境界へ至ります。この例では厚み下限0.05が平常荷重比より小さいため、下限によってR=1への到達が妨げられません。

これはモデルをその条件で継続させた場合の進行です。一巡の終了時刻t=2400までに、すべての自己持続地点が到達するという意味ではありません。

追加厚みがある状態まで一般化するには、下限も確認する必要があります。合計の下限は0.05＋追加厚み比です。それが平常荷重比より大きければ、平常荷重だけによるRは1へ届きません。「自己持続しているから、あらゆる設定で必ず破断する」とは扱いません。

### 既定値と基準になる合成結果

| 項目 | 値 |
|---|---|
| r_on | 0.40 |
| κ | 0.0042 |
| 介入で加える厚み比 | +0.25 |
| 格子 | 41×41地点×6層 |
| 一巡 | t=2400 |
| 乱数の種 | 33 |

介入なしの初期選択点は電力層の座標(0.20,0.60)です。この合成モデルでは、死角区間はt=402.0から978.5まで、長さ576.5、その間のRの最大値は約0.9973になります。時間は模式上の単位であり、現実の秒数とは対応付けていません。

これらは式を実行して確認する合成結果です。コードの構文・計算・状態遷移の検証と、実画面の目視・クリック・端末操作の確認は別です。ブラウザでの実画面確認は、この整理時点では未検証です。

## 6. この2つの図で主張しないこと

- 現実の6つの物理ドメインに同じ支配方程式が成立すること。
- 同時到達が、層どうしの相関や因果を証明すること。
- r_on・κ・介入量が、現実の安全閾値や補修量として検証されていること。
- 実際の自律処理や機器を止めるFail-Closed制御が動作していること。
- 新しい試行の開始や合計厚みの増加が、元の構造の復元を意味すること。
