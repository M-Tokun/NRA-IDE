# 33 NRA-IDE 模式アニメーション 説明

対象ファイル：`33_nra_ide_blind_interval_JP.html`
題名：閾値の手前で決まるもの — 介入必須点と死角区間（模式）

> この図は**模式**です。数値はすべて式から作った合成値で、荷重の形と各パラメータは説明のために選んだものです。実測値でも、検証済みのモデルでもありません。

---

## 1. この図で伝えたいこと

> R が閾値 1.0 を超えるより前に、介入しなければ止まらなくなる点（**介入必須点**）が来ます。
> そこから **Fail-Closed点** までの間（**死角区間**）は、R を見ていても何も見えず、蓄積を見ていれば見えます。

監視の多くは「値が閾値を超えたか」を見ます。しかし、戻れなくなる分かれ目は、閾値を超えるより前にあります。転移点（R = 1.0）に着いてから気づくのでは遅く、その手前の**蓄積**の情報の方が重要だ、というのがこの図の主題です。

---

## 2. 言葉の定義

| 言葉 | 意味 |
|---|---|
| R | 境界接近比。R = δ / τ。1.0 で閾値に達する |
| δ | その地点にかかっている荷重（偏差） |
| τ | その地点の厚み（受け止められる幅）。図では元の厚み τ0 に対する比 τ/τ0 で表す |
| 平常荷重 | 何も起きていないときにも常にかかっている荷重 |
| r_on | 蓄積開始レベル。R がこれを超えている間だけ蓄積が進む |
| 蓄積 A | R が r_on を超えた分を時間で足し合わせた量。**減らない** |
| 介入必須点 | 平常荷重だけで R が r_on を超えるほど厚みが減った点。ここから先は、荷重が引いても蓄積が止まらない |
| 死角区間 | 介入必須点から Fail-Closed点までの期間。R は 1.0 未満のまま |
| Fail-Closed点 | R ≥ 1.0 に達した点。手動リセットまで保持する |
| 介入 | 厚みを外から加えること（溶接の例）。元の厚みは戻らない |

### 介入必須点と「不可逆」の違い

- **元の厚みが失われること**は、蓄積が始まった瞬間から不可逆です。介入しても元の厚みは戻りません。
- **介入必須点**は、「介入なしで止まる経路があるか」で決まる点です。介入（厚みの追加）で抜けられるので、不可逆性とは別の概念として扱います。

このため、図ではこの点を「不可逆点」とは呼んでいません。

## 3. 画面の読み方

### 3-1. 2面の地図（いちばん大事な部分）

同じ層・同じ時刻を、2つの見方で並べています。

| 左：R だけを見た場合 | 右：蓄積を見た場合 |
|---|---|
| 閾値監視の見え方 | 状態の見え方 |
| 灰色の濃淡＝R の大きさ | 茶〜橙＝蓄積の進み（介入必須点に近いほど明るい） |
| 赤＝R ≥ 1.0 だけ | 紫＝死角区間 |
| | 赤＝Fail-Closed（死角区間を経由） |
| | 薄い朱＝Fail-Closed（直接到達：急な荷重） |
| | 青緑の枠＝介入済み |

**見どころ**：右に紫が現れても、左は灰色のままです。左が赤くなるのは、Fail-Closed点に達したときが初めてです。この「右にだけ映っている時間」が死角区間です。

地図をクリックすると、その地点が選択され、下の「選択地点の推移」に表示されます。

### 3-2. 選択地点の推移（時系列）

| 線・印 | 意味 |
|---|---|
| 白い実線 | R |
| 水色の破線 | 厚み比 τ/τ0 |
| 橙の破線 | r_on |
| 赤の破線 | R = 1.0（閾値） |
| 紫の網掛け | 死角区間 |
| 紫の縦線 | 介入必須点 |
| 赤の縦線 | Fail-Closed点 |
| 青緑の三角 | 介入した時点 |

下の文字欄には、死角区間の始まりと長さ、そして**その区間中の R の最大値**を表示します。この最大値が 1.0 未満であることが、「R だけを見ていると何も起きていない」ことの数値的な裏付けです。

初期表示の地点（電力層）では、死角区間は t = 402 から t = 979 まで（長さ 577）で、その間の R の最大値は 0.997 でした。

### 3-3. 厚みゲージ

左端が元の厚み（1.00）で、右へ進むほど薄くなります。

- 茶〜橙の帯：蓄積帯（介入必須点の手前）
- 紫の帯：死角帯（介入必須点から、平常荷重で Fail-Closed になる厚みまで）
- 暗い赤の帯：平常荷重でも R ≥ 1.0 になる厚み

白い三角が現在の厚みです。三角が紫の帯に入った時点で、その地点は介入必須点を越えています。

なお、Fail-Closed は荷重が大きいときにはもっと手前（左）でも起こります。ゲージの赤い帯の境目は「平常荷重の場合」の位置です。

### 3-4. 全6層の積層ビュー

6つの層（温度・圧力・電力・照度・流量・振動）の状態を重ねて表示します。選択中の層は濃く、他は薄く描きます。ドラッグで回転できます。どの層のどこで死角区間が生じているかを一望するための補助表示です。

### 3-5. 層の状態（右側のカード）

各層の色付きバーは、蓄積が起きた地点の内訳です（蓄積中・死角区間・Fail-Closed 経由・Fail-Closed 直接）。カードをクリックすると、その層が選択されます。

## 4. 操作

| 操作 | 内容 |
|---|---|
| 再生中 / 停止中 | 再生と一時停止 |
| 最初から | すべてを初期状態に戻す（手動リセット） |
| 速度 | ×0.25〜×16 のスライドバー |
| 介入ボタン | 死角区間にある全地点に厚み +0.25 を加える |
| 蓄積開始 r_on | 境目の調整。変更すると最初からやり直す |
| 減り方 κ | 蓄積に対して厚みが減る速さ。変更すると最初からやり直す |

- Fail-Closed に達しても、アニメーションは止まりません。
- 一巡（t = 2400）で終わると、約2.5秒後に最初から再生します。介入の記録もそこで消えます。
- r_on を平常荷重の最大値以下に下げると、警告が出ます。その設定では、平常荷重だけで蓄積が始まります。

## 5. おすすめの見方

1. 速度を ×4 のまま再生し、右の地図に**紫**が現れるのを待ちます（t ≈ 330〜400）。
2. そのとき左の地図が**灰色のまま**であることを確かめます。
3. 時系列で、荷重の山が過ぎた後も R がゆっくり上がり続けることを見ます。これは、厚みが戻らず、平常荷重だけで蓄積が続いているためです。
4. 左の地図が赤くなる瞬間（Fail-Closed）と、紫が現れた瞬間の差が死角区間の長さです。
5. 「最初から」でやり直し、紫が現れたところで**介入ボタン**を押します。蓄積は止まりますが、厚み比が 1.0 に戻らないことを確かめます。
6. 照度・振動の層も見てください。蓄積はしても介入必須点に達しない例です。

## 6. 計算の中身

各地点で、時間を 0.5 刻みで次を繰り返します。

```
荷重   d = 平常荷重 + 持続型の山（2つ）+ スパイク（1つ）
R      = d / 厚み比
R > r_on のとき：
    蓄積 A に (R − r_on) × 0.5 を加える（減らさない）
    厚み比 = max(0.05, 1 − κ × A) + 介入で加えた厚み
R ≥ 1.0 → Fail-Closed点（以後この地点は固定）
平常荷重 / 厚み比 > r_on → 介入必須点を越えている（死角区間）
```

### なぜ介入必須点を越えると必ず Fail-Closed に至るのか

これは後から足した規則ではなく、上の式から導かれます。

1. 介入必須点を越えると、平常荷重だけで R > r_on になります。
2. そのため蓄積が止まらず、厚みは減り続けます。
3. 厚みが減ると R = d / 厚み は上がり、蓄積はさらに速くなります。
4. やがて R は 1.0 に届きます。

ただしこれが成り立つのは、**平常荷重が続き、かつ介入がない場合**に限ります。

### 既定値

| 項目 | 値 |
|---|---|
| r_on | 0.40 |
| κ | 0.0042 |
| 介入で加える厚み | +0.25 |
| 格子 | 41 × 41 地点 × 6層 |
| 一巡 | t = 2400 |
| 乱数の種 | 33（同じ種なら毎回同じ動き） |

## 7. この図で扱わないこと

- x, y は模式空間の座標で、物理的な位置は定義していません。
- 6つの層の間に結合はありません。層どうしの相関や因果は示しません。
- Fail-Closed は表示上の状態です。何かを実際に停止させる制御は実装していません。
- 平均値・中央値・多数決は使っていません。層の状態は地点ごとの状態の数で示しています。
- 荷重の形とパラメータの値は、死角区間が見えるように選んだものです。理論や実測から決めた値ではありません。

---

## 8. まとめ

### 大事な部分

同じ地点を「R だけ」と「蓄積」の2面で並べると、介入必須点から Fail-Closed点までの死角区間は、片方にだけ映ります。閾値監視が気づく時点では、戻るための介入が必要な状態はすでに長く続いています。

### 要点

- 主役：死角区間（介入必須点 → Fail-Closed点）
- 介入必須点：平常荷重 / 厚み > r_on。式から導いた点
- Fail-Closed点：R ≥ 1.0。手動リセットまで保持
- 蓄積と元の厚み：介入しても戻らない
- 「必ず Fail-Closed」：平常荷重が続き、介入がない場合に限る
- 数値はすべて模式の合成値
