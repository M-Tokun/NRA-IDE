🧮 How Is It Different from Calculus?

Derivatives and differences are used as auxiliary computation in the double-fluctuation detection of the Secondary Formula (FORMULA §4.7) and in the complementary formula (§5). Classical theory is not denied (Thesis §6.1). What differs is that the subject of judgment is approach to the boundary, R, not the rate of change.

Conventional Mathematical Approach

Standard control theory relies on differential equations:

// Traditional PID Control function pidControl(error, dt) { // P: Proportional (Current error) const P = Kp * error; // I: Integral (Accumulated error) I += Ki * error * dt; // D: Derivative (Rate of change) const D = Kd * (error - prevError) / dt; return P + I + D; }

The Flaws:

  • Requires dt (time step) → Assumption of continuous time.
  • Derivatives are numerically unstable (noise sensitivity).
  • Integrals accumulate drift/error over time.

🔢 What Are Integer Steps? (Relation to Floating-Point)

The Floating-Point Trap

Floating-point operations suffer from cumulative precision errors:

// Floating-point precision issues let sum = 0.0; for (let i = 0; i < 1000000; i++) { sum += 0.1; } console.log(sum); // Expected: 100000.0 // Actual: 100000.00000133288 (Drift!)

A problem for safety-related judgment:

  • Accumulated drift → the judgment on either side of the boundary shifts.
  • Accumulating a decimal phase and then taking its integer part can shift the integer part itself.
  • Results change when the order of computation or the implementation changes.

NRA-IDE Design Principle: Integer Phase Lock

State steps are counted in integers; a remainder smaller than one step is not carried to the next state and is recorded. Not every quantity is limited to integers (Thesis §9.1).

// NRA-IDE: Integer Phase Lock Method let ticks = 0; // steps are counted in integers const STEPS_PER_PHASE = 100; function update() { ticks += 1; // integer addition: no accumulated drift // State step (integer part) const integerPhase = Math.floor(ticks / STEPS_PER_PHASE); // Remainder below one step: not carried to the next state; its value and source are recorded (structural disclosure log) const residual = (ticks % STEPS_PER_PHASE) / STEPS_PER_PHASE; return integerPhase; // 0, 1, 2, 3... } // Benefits: // - No floating-point drift enters the state steps // - Same input, same steps (deterministic) // - The remainder is recorded and traceable, not thrown away
