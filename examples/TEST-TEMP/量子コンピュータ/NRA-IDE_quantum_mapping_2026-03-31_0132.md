## 2. 整合性と相関の取り方

- 量子もつれの相関は因果ダイオード原理で方向性を固定する（A→B許可、B→A逆推論遮断）。
- 相関は「距離」ではなく「制約・エネルギー・張力」の3軸で記述する。
- 整合性チェックはPre-RNA → Post-RNA遷移直前に実施。整合性がない場合は「不能」を返す。

## 3. エスケープメント原理による誤差膨張防止

```
各量子ゲート操作の後にエスケープメントポイントを設置
    ↓
R = δ/τ を毎ゲート後に再計算
    ↓
R ≦ R_max → 次ゲートへ進む
R > R_max  → 現状態をログし操作をリセット
```

古典QECが事後訂正であるのに対し、NRA-IDEのアプローチは事前遮断。
誤差が生存可能領域を超える前に操作を止める。（時計の歯車）

## 4. 弱測定（Weak Measurement）の役割と限界

### 役割

重ね合わせを壊さずにR値の近似を取得するための「そっとのぞく」測定。
波動関数収縮を伴わない。無理な測定は誤差増幅のもと。

### 克服すべき欠点：解像度の低さ

誤差は広がらないが情報が薄い（ピントが甘い）。

### 克服の3方法

1. **多角測定の合成** ― X・Y・Z基底方向から各R近似を取得し合成する。
2. **区間管理** ― R値を点推定ではなく区間 R ∈ [下限, 上限] として管理し、「またぐ場合は保留」とする。
3. **時系列累積** ― 弱測定を少しずつ繰り返し、最低必要解像度に達した時点で判定を実行する。（コインの表裏の確定にこだわらない）

---

## 5. 解像度の非均一配置（歯車の「遊び」原理）

### 核心

> 解像度は境界付近にのみ集中させ、内部は「遊び」として粗く扱う。
> 常時高解像度の追求は状態を壊す設計の失敗。

### 3層構造

```
【層1】閾値境界帯（ナロー）
    高解像度・弱測定多回・区間を狭く

【層2】生存可能領域内部（ワイド）
    低解像度・測定最小限（「遊び」領域）

【層3】領域外（アウト）
    即遮断。因果ダイオードで止める
```

### エスケープメントとの接続

エスケープメントポイント = 閾値境界帯への到達検知のみ。
それ以外の時間は「遊び」領域で低解像度のまま走らせる。
「いつ確認するか」の設計こそがエスケープメントの本質。

## 6. 境界帯の幅の定義原則

> 幅を先に決めることは設計ミスの典型。
> 用途の許容損失を定義することが起点であり、幅はその事後的な結果。

```
用途の許容損失を定義する
    ↓
損失が発生し始める点 = 境界帯の外縁
まだ許容できる点    = 境界帯の内縁
    ↓
その差分が「幅」
```

