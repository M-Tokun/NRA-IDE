# NRA-IDE CABG Monitor
**心臓血管バイパス手術（CABG）向け動的TTFM波形監視ツール**
**〜 経過ログ機能搭載版 〜**

## 概要

このツールは、**NRA-IDEの二重ゆらぎ・動的τ・Fail-Closed**構造をCABG（冠動脈バイパス移植術）の術中監視に特化させた**単一HTMLファイル**です。

Transit-Time Flow Measurement（TTFM）の実臨床基準（Medistim VeriQ / Transonic）を再現しつつ、
- 動的血流波形（拡張期優勢パターン）
- Pulsatility Index（PI）、Mean Graft Flow（MGF）、Diastolic Filling %（DF%）
- 壁せん断応力・壁張力・接着性などの局所物理量

を**リアルタイム統合**し、**R ≥ 閾値**で自動Fail-Closedを発動します。

### 主な特徴（2026年3月時点）

- **動的TTFM波形アニメーション**（拡張期優勢を再現）
- **閾値スライダー**でPI上限・MGF下限・R Fail値を自由調整 → 破線（閾値ライン）が即時移動
- **状態変化を自動ログ記録**（タイムスタンプ＋パラメータ＋理由）
- **視覚フィードバック**：SAFE（緑）→ WARNING（黄）→ FAIL_CLOSED（赤点滅）
- **オフライン・ブラウザ単体**で動作（専用機不要）
- **教育・シミュレーション・術中第二意見**用途に最適

## 臨床基準（実データ反映）

| パラメータ          | 正常範囲（参考）          | 警告域                  | Fail域（吻合不良高確率）      | 出典                              |
|---------------------|---------------------------|-------------------------|--------------------------------|-----------------------------------|
| Mean Graft Flow (MGF) | ≥ 30–40 mL/min (LIMA)    | ≤ 25 mL/min            | ≤ 20 mL/min                   | Medistim VeriQ, AHA/ESC           |
| Pulsatility Index (PI) | ≤ 3.0（理想）            | ≥ 3.5–5.0              | ≥ 5.0                         | TTFMガイドライン                  |
| Diastolic Filling %   | ≥ 50–70%                 | < 50%                  | < 40%                         | 臨床研究（J Thorac Cardiovasc Surg） |
| R（統合リスク）       | < 0.8                    | 0.8–1.0                | ≥ 1.0（動的τ考慮）            | NRA-IDE独自基準                   |

## 使用方法

1. ファイルを保存 → ブラウザで開く（Chrome/Edge推奨）
2. **パラメータスライダー**で術中状況を再現（例：吻合直後のMGF低下、PI上昇）
3. **閾値スライダー**を動かすと、波形上の**破線（MGF下限・PI上限）**がリアルタイムで移動
4. 状態が変化すると**経過ログ**に自動記録（タイムスタンプ付き）
5. PI ≥ 閾値 または MGF ≤ 閾値 または R ≥ Fail閾値 → **FAIL_CLOSED**（赤点滅＋ログ）

## 画面構成

- **左側**
  - 上：血管断面アニメーション（壁張力で膨張、血流粒子）
  - 中：TTFM動的波形（拡張期優勢）＋破線（調整可能な閾値ライン）
  - 下：ライブ数値（MGF / PI / DF% / 状態）

- **右側**
  - パラメータ調整スライダー（P, T, Flow, Adh, Shear, Tension）
  - 閾値調整スライダー（PI上限, MGF下限, R Fail）

- **下部**
  - 経過ログエリア（状態変化を自動記録・スクロール）

## 注意事項（医療安全）

- **研究・教育・シミュレーション専用**です。**実臨床での単独判断には使用しないでください**。
- 実際のTTFM装置（Medistim VeriQなど）の**補助ツール**としてのみ活用。
- Fail-Closedは「シミュレーション上の停止」です。実際の手術では**臨床判断優先**。
- ログはブラウザ閉じると消えます（本番運用時はローカル保存機能追加推奨）。
