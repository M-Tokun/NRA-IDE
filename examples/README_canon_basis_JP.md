# examples 01〜20 の考え方と正典の根拠

各サンプルが正典のどこを起点に作られ、何が中心で何が補助かを示します。正典の条文はここに写さず、参照先だけを示します。参照先：[AXIOMS.md](../theory/AXIOMS.md)、[THEORY.md](../theory/THEORY.md)、[FORMULA.md](../FORMULA.md)、[Foundational Thesis](../theory/NRA-IDE_Foundational_Thesis_Bilingual.md)、[辞書](../dictionary/NRA-IDE_Dictionary_JP.md)。英語版：[README_canon_basis_EN.md](./README_canon_basis_EN.md)

## 1. 先に読むこと：このサンプル群の中心と補助

| 区分 | 内容 | 根拠 |
|---|---|---|
| 中心 | **整数の歩み（熱排出）。** 評価は1歯ずつ進み、歯と歯のあいだの端数は捨てずに記録する。 | Thesis §9.1（整数位相ロック）、AXIOMS §13（STRUCTURAL_DISCLOSURE_LOG） |
| 中心 | **R = δ/τ が判定の主語。** δ は評価前に固定した基準状態からの累積ズレ、τ は吸収厚み（＝遊び）。 | AXIOMS §3・§4・§5 |
| 中心 | **到達の固定（ラッチ）と履歴。** R≥1 に達した瞬間（値・時刻・チャネル）を残し、消さない。 | AXIOMS §9・§10.5 |
| 補助 | 平均・平滑化（EMA）・小数計算・残渣式・負債・R_total。**補助は判定を軽くも、覆しも、置き換えもしない。止める向きを早めることだけができる。** | AXIOMS §4.5、FORMULA §4 |
| 補助 | 他の評価対象の R を、自分の側別有効ゲート幅を**狭める**ためだけに使う。 | AXIOMS §14 |

「遊び」とは、構造が持つ吸収厚み τ のことです。遊びのない厳密さは崩れる（AXIOMS §3）。τ は自然には回復しない（AXIOMS §7）。画面で幅が戻って見えるものは、側別の有効ゲート幅で、τ の回復ではありません（THEORY 二重ゆらぎ式、FORMULA §4）。

**距離・微分積分は否定していません。** 距離データは消さず、微分積分も否定しません（THEORY、Thesis §6.1）。主軸が距離や微分でない、というだけです。

**各サンプルに共通する限界。** 数値・係数・基準値はすべてデモ用に宣言した値で、実測でも運用の根拠でもありません。理想化した例ですが、実験なしでも現実的な仮説として成り立つ範囲に留めています。

## 2. 各サンプルの根拠

各項目は「起点（正典のどこから作ったか）／中心／補助／勘違いしやすい点／主張しないこと」の順に書きます。

### #01 なぜ距離・微分積分・浮動小数点を使わないのか
| | |
|---|---|
| 起点 | AXIOMS §4（δ・τ）、Thesis §6.1・§9.1、THEORY（距離は否定しない） |
| 中心 | 基準状態からの累積ズレ δ（正の側のみ）、厚み τ、整数の歩み |
| 補助 | 距離・微分の比較表示（対比のための説明） |
| 勘違いしやすい点 | 「従来手法は誤り」と読むこと。違うのは主軸です。 |
| 主張しないこと | 医療などの実運用の優劣。計算式は説明用の簡略です。 |

### #02 誤差積算
| | |
|---|---|

| 勘違いしやすい点 | 「律環公理は誤差ゼロ」と読むこと。端数は消えず、記録されます。 |
