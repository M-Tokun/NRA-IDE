Assumptions and limits of this screen (caveats)
• The ion reference values, τ, and antagonism coefficients are not agronomic recommendations.
• The soil-profile difference (Andosol / general farmland) is also an illustrative setting.
• All reference values, limits, thresholds, and coefficients are demo-declared values, not an operational basis.
• An ion whose R reaches 1.0 is latched in SILENCE and released only by "New evaluation". "Reset" only returns the scenario and does not release the latch. Switching the soil profile changes the evaluation declaration, so it starts a new evaluation.
• The antagonism direction here is the plant / soil one (K⁺ excess inhibits Mg²⁺ uptake). In the human body the direction is reversed (Mg deficiency leads to hypokalemia), so do not confuse the two.
• Narrowing the Mg²⁺ τ (lower side) by the K⁺ R (excess side) is a path that uses another evaluation target's output only in the safe direction (narrowing) (AXIOMS §14). τ_Mg returns when R_K falls, so it is treated as a link of the side-specific effective gate width, not of the absorption thickness.
