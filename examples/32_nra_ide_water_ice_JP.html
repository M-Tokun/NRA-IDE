計算式の定義
静的τモデル（直線型）
δ = T − (−20) = T + 20　→　氷の基準温度(-20℃)からの蓄積ズレ
τ = 20　→　固定定数（結晶格子構造が保持できる総余裕）
R = δ / τ = (T + 20) / 20
R = 1.0 は T = 0℃ に正確に一致。グラフは直線。
温度スライダーを動かすと δ・τ・R がリアルタイム更新されます。 R ≥ 1.0 で Fail-Closed（水として構造確定）。R ≥ 0.75 で警告域（結晶構造の弛緩が始まる段階）。

凝固系との根本的な違い： 凝固系のδは「液体構造からのズレ（温度低下）」、 融解系のδは「固体結晶構造からのズレ（温度上昇）」です。 同じ0℃でも追跡している構造が別物のため、独立したシステムとして設計します。
