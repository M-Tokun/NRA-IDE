STRUCTURAL NOTES (100% Structure-Pure)

✓ What Domain Tuning IS:

  • Adjustment of boundary width (τ) and fracture threshold (R_op)
  • Structural calibration based on domain characteristics
  • Configuration of tolerance ranges (not performance optimization)
  • Human-only adjustment (AI cannot modify)

✗ What Domain Tuning is NOT:

  • Purpose selection (use case, application intent)
  • Performance optimization (speed, accuracy, naturalness)
  • Meaning-based adjustment (semantic quality)
  • Behavioral modification (AI personality, tone)
  • History-based learning (past performance data)

Zone Structure (No Semantic Value):

  • Zone A: R < 0.40 → PERMIT (structural stability)
  • Zone B: 0.40 ≤ R < 1.00 → PERMIT_WITH_CAVEAT (elastic fluctuation)
  • Zone C: R ≥ 1.00 → FAIL-CLOSED (fracture point)

Zones are structural classifications, not value judgments.
R = 0.39 is not "good" and R = 0.41 is not "bad".
They are simply different structural states.

Domain Independence:

  • All DOMAINs can traverse all Zones (A/B/C)
  • DOMAIN parameters (τ, R_op) determine boundary width only
  • No fixed correspondence: DOMAIN_A ≠ Zone A
  • A DOMAIN with narrow τ may still operate in Zone A if δ is small

Fail-Closed ≠ Failure:

  • Fail-Closed is structural correctness, not error
  • When R ≥ R_op or ω = 0: system maintains integrity by silence
  • ω > 0 during Fail-Closed → system is alive (structurally continuous)
  • ω = 0 → system death (strictly forbidden in NRA-IDE)
