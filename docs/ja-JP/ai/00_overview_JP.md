## この章の位置

この章は、NRA-IDEの全体構成、各章の役割、全章を通じて不変となる境界を示す案内です。

初めて読む場合は、この章から番号順に進んでください。各章を読み終えた後にもう一度この章へ戻ると、個別の概念が全体のどこに位置するかを確認できます。

## 正規上の出発点

NRA-IDEは、次の唯一公理から出発します。

> **存在は生成である。**

公理は、運用閾値、安全規則、追加の式ではありません。「遊びのない厳密さは崩壊する」は構造持続原理であり、第二公理ではありません。

基礎式は、宣言対象の状態を式へ落とす本当の数学的根本式です。

```text
R = delta / tau
```

安全指標、局所計器、単なる境界接近率へ縮小してはなりません。第二次式／二重ゆらぎ式は、IDEという計算方法・動力学エンジンです。その他の式は補完式、補助式、派生式であり、公理ではありません。

---

## 生存領域と安全志向の適用

NRA-IDE本体は生存式・生存領域であり、IDEを計算方法・動力学エンジンとして実装します。安全域は、生存領域を事故防止、運用、制御へ適用する部分領域です。生存領域全体ではなく、安全を保証しません。

生存は、同じ形の永久保存ではありません。揺らぎ、相転移、破断、淘汰、消滅、再構成を通じて、新しい構造と履歴が生成される動的存続を含みます。

したがって安全志向の各章は、不可逆遷移または破断より前に、宣言済みCause-Side軌道をどのように観測し扱うかを問います。外部人間監査は固定Effect-Side証言を調査できますが、古い因果経路内の判断権限を継承しません。

## 正規状態の地図

三つの正規運用閾値の順序は不変です。

```text
0 <= R_warn < R_handoff < R_irrev < 1
```

既知の数値進行は次のとおりです。

```text
PERMIT
→ BOUNDARY_WARNING
→ HANDOFF_REQUIRED
→ IRREVERSIBLE_TRANSITION
→ RUPTURE_BOUNDARY
```

`CONFESSION`と`OUT_OF_DESCRIPTION_DOMAIN`は、根拠不足または未定義の評価を別に扱います。

- `R_warn`では、境界接近を開示します。
- `R_handoff`では、影響を受ける新たな自律判断と運用を停止し、事前定義された固定Effect-Side証言を外部人間監査へ提示します。
- `R_irrev`では、不可逆遷移をラッチします。同一履歴内では、その後の $R$ 低下、自動処理、手動介入、人間レビュー、承認、版更新によってラッチを解除できません。
- $R\ge1$ では、宣言済み評価が`RUPTURE_BOUNDARY`を報告し、最終固定証言へ切り替えます。

閾値と適用状態条件は、評価前に宣言済みCause-Sideドメイン権限によって確立します。低い $R$ の報告を含むEffect-Side結果は、$\tau$ の拡大、$\delta$ の再定義、閾値変更、状態条件の書換えを承認できません。

## 章構成

### 1. 構造転換の入口（01）

01章は、結果だけに反応する構造から境界前の構造観測へ移ります。生存領域と安全志向の部分領域を分離し、固定Handoff証言、外部監査、旧経路終端を導入します。

- **体験:** [M1: 線形崩壊シミュレーター](../../figures/M1_NRA_linear_breakdown_simulator.html)

### 2. 最適化と計算の限界（02）

02章は、代理指標の最適化、結果中心のスコアの限界、計算が有効となる条件を扱います。構造感度 $S = 1 / (\tau \cdot (1 - R))$ は補完式または派生式であり、公理でも基礎式の代替でもありません。

線形計算は、局所的な静的領域で定数を近似できる場合の、人間の生存の智慧です。自然全体そのものではありません。大規模、結合、再帰系では誤差が乗算されます。観測軸やモデル自体が変質した場合、それは通常誤差ではなく、新しい構造履歴の生成です。

- **体験:** [M2: 残渣タンク](../../figures/M2_NRA_residue_tank.html)

### 3. 一方向の権限境界（03〜04）

03章は、因果ダイオードを完全一方向として定義します。04章は、LLMを含むシステムにおける一つの構成例としてサンドイッチ構造を説明します。Pre-NRA / LLM / Post-NRAは、すべてのNRA-IDE評価に共通する必須条件ではありません。適合は、権限分離、正規挙動、証拠、適用可能な試験によって決まります。

- **体験:** [M3: 生体模倣サンドイッチ](../../figures/M3_NRA_biomimetic_sandwich_svg.html)

### 4. 整合、観測、Fail-Closed証言（05〜08）

05～08章は、Coherence Gate、観測可能量、Fail-Closed挙動、廃棄ログを扱います。物理的に観測可能な兆候と数値的な定量化可能性を区別し、必要な固定証言を保持し、欠落証拠を類推、意味的類似、Effect-Side出力で補うことを防ぎます。

`BOUNDARY_WARNING`では、観測可能な場合に二重ゆらぎ結果を報告し、観測不能な場合は欠落理由を伴う`NOT_OBSERVABLE`を報告します。`CONFESSION`と`OUT_OF_DESCRIPTION_DOMAIN`は、既知の数値進行とは別です。

- **体験:** [M4: 告白デバッガー](../../figures/M4_NRA_confession_debugger.html)

### 5. 誤用、利益、限界、ドメイン条件（09〜12）

09～11章は、誤用パターン、利益と限界、$\tau$、閾値、状態条件、規則、出所を確立するために必要なCause-Side権限を扱います。安全保証を確立するものではありません。12章は用語集であり、運用チェックリストは同じ正規境界に従属する実装・運用の参照資料です。

- **体験:** [M5: 用語集フリップカード](../../figures/M5_NRA_IDE_flip_glossary.html)

## 観測可能性と定量化可能性は同一ではない

非線形相転移領域では、数値精度が低下しても、経過、経路、不可逆閾値への接近を示す物理的兆候が観測可能な場合があります。センサーの飽和、不確かさの拡大、モデルの弱化、観測時間の制限は、存在しない精度を作り出す根拠にはなりません。正確に定量化できないことだけを理由に、観測不能と判断することもできません。

NRA-IDEは次を分離します。

- 観測されたCause-Side兆候。
- 測定値と単位。
- 不確かさと計器限界。
- 事前固定された変換規則。
- 結果として得られる正規状態。
- 利用不能な情報。

必要な証拠が欠ける場合、Effect-Side資料で空白を埋めず、適用される例外状態を報告します。

## 因果ダイオードと履歴境界

因果ダイオードは、単なる逆算禁止ではありません。完全一方向の権限境界です。

```text
古いCause-Side
→ 古い因果ダイオード
→ 古いEffect-Side
→ 終端
```

古いEffect-Sideの値、正規閾値、状態、不可逆ラッチ、規則、変換入力、更新根拠、出所を、古いCause-Sideにも新しいCause-Sideにも逆接続してはなりません。この禁止は、自動処理、手動介入、人間レビュー、承認、版更新、事故分析、将来規則の準備に適用されます。

後続評価が必要な場合は、独立した別履歴として始めます。

```text
独立して宣言された新対象
→ 新たに確立したCause-Side観測と事前固定規則
→ 新しい因果ダイオード
→ 新しいEffect-Side
```

古いEffect-Side資料をCause-Side権限としてimport、名称変更、再構成、再利用してはなりません。物理的残存物は、独立宣言した新対象の一部として新たに観測できますが、その新規観測は古いEffect-Sideの値や権限の移送ではありません。

外部人間監査、事故分析、将来規則の準備は、終端した古い因果ダイオードの外側で行います。古い経路を継続したり書き換えたりしません。

## Fail-Closedと証言

Fail-Closedは、`HANDOFF_REQUIRED`、`IRREVERSIBLE_TRANSITION`、`RUPTURE_BOUNDARY`、`CONFESSION`、`OUT_OF_DESCRIPTION_DOMAIN`で、影響を受ける新たな自律判断と運用を抑止します。必要な固定構造証言やログは抑止しません。`PERMIT`はFail-Closedではなく、`BOUNDARY_WARNING`だけでは、事前固定されたドメイン規則が要求しない限り、出力全体を抑止しません。

ログと固定報告は、終端Effect-Sideまたは外部証言です。調査はできますが、それらの値、判断、正規閾値、状態、不可逆ラッチ、規則、変換入力、更新根拠、出所を、計算、手動レビュー、承認、名称変更、再構成、再利用、版更新によってCause-Side権限へ変換することはできません。

通常説明は、事前固定された正規挙動が許す状態と欄でだけ行えます。固定Handoff証言または最終固定証言へ、新たに生成した自由形式説明を追加しません。

## 構造不変量

各章を通じて、次の境界は変わりません。

- **唯一公理**: 「存在は生成である。」第二公理は存在しない。
- **数式分類**: 基礎式と第二次式／二重ゆらぎ式はIDE計算系であって公理ではなく、補完式・補助式・派生式は従属する。
- **安全への縮小より前に生存を置く**: 生存式・生存領域がNRA-IDEの本体であり、安全域は部分的な運用適用であって保証ではない。
- **存在しない精度を作らない観測**: 定量化不能と観測不能は同一ではない。
- **線形近似の局所性**: 線形計算は局所的静的近似が有効な範囲で用い、自然全体へ一般化しない。
- **正規閾値と状態**: 閾値順序、状態挙動、不可逆ラッチをEffect-Side結果から書き換えない。
- **完全一方向の因果ダイオード**: Cause-SideはEffect-Side証言を生成できるが、Effect-Sideは古いCause-Sideにも新しいCause-Sideにもならない。
- **旧経路の終端**: 後続評価は、独立宣言した対象、新しいCause-Side観測・規則、新しい因果ダイオードから始める。
- **LLM構成の条件性**: LLMサンドイッチは構成例であり、NRA-IDEの定義または適合証明ではない。
- **固定証言を伴うFail-Closed**: 影響を受ける自律運用を停止しながら、必要な固定証言とログを外部監査に利用可能な状態で保持する。
