## この章の位置

この章は、NRA-IDEの全体構成、各章の役割、共通する設計原則を示す案内です。

初めて読む場合は、この章から番号順に進んでください。各章を読み終えた後にもう一度この章へ戻ると、個別の概念が全体のどこに位置するかを確認できます。

---

## 文書の構成と哲学

この文書は、一つの問いを追う構造になっています。

**「AIを含む動的なシステムが不可逆域へ接近したとき、限界を超えた出力を続けず、人間へ判断を委譲できるか。」**

NRA-IDEは「存在は生成である」という設計上の前提から出発します。IDEは、ゆらぎ $\delta$、それを吸収する構造の厚み $\tau$、その比率 $R = \delta / \tau$ を計算原理として、構造状態を記述します。公理と計算原理は異なる層にあります。

---

## 章構成

### 1. 構造転換の入口（01）

出力後に意味やスコアで安全性を判断する方式と、出力前後の構造状態を扱う方式の違いを示します。NRA-IDEが置く三つの設計上の決断を確認します。

- **体験:** [M1: 線形崩壊シミュレーター](../../figures/M1_NRA_linear_breakdown_simulator.html)

### 2. 最適化の限界と計算原理（02）

最適化目標が安全判定へ与える問題を整理します。また、構造感度 $S = 1 / (\tau \cdot (1 - R))$ を導入し、$R$ が相転移境界へ接近するときに感度が発散する構造を確認します。

- **体験:** [M2: 残渣タンク](../../figures/M2_NRA_residue_tank.html)

### 3. 隔離の構造（03〜04）

結果から原因を逆算する Π⁻¹ を遮断する「因果ダイオード」と、Pre-NRA / LLM / Post-NRAの責務を分離する「サンドイッチ構造」を解説します。

- **体験:** [M3: 生体模倣サンドイッチ](../../figures/M3_NRA_biomimetic_sandwich_svg.html)

### 4. 誠実な沈黙（05〜08）

比率 $R$ による状態区分、観測可能量、Fail-Closed、廃棄ログを扱います。ドメイン固有の不可逆域接近点で自律出力を停止し、人間へ判断を委譲する構造を示します。$R = 1.0$ は通常の委譲点ではなく、構造が成立しなくなる相転移境界です。

- **体験:** [M4: 告白デバッガー](../../figures/M4_NRA_confession_debugger.html)

### 5. 実践と限界（09〜11）

誤用パターン、保証できる範囲、$\tau$ と動作閾値のドメインチューニングを扱います。12章は用語集、運用チェックリストは実装・運用時の確認資料として使用します。

- **体験:** [M5: 用語集フリップカード](../../figures/M5_NRA_IDE_flip_glossary.html)

## 構造不変量（不変の原則）

各章を通じて、以下の六つの原則は変わりません。

- **非意味（Non-Semantic）**: 出力の自然さや意味上の正しさではなく、Cause-Sideの観測量と構造状態を扱う。
- **非最適化（Non-Optimization）**: 中心やスコアを最適化目標として置かず、構造境界を定義する。
- **因果ダイオード（Π⁻¹禁止）**: 結果（評価値）から原因（入力）を逆算しない。
- **三層分離**: Pre-NRA / LLM / Post-NRAの境界を峻別する。
- **Fail-Closed**: ドメイン固有の不可逆域接近点で自律出力を停止し、人間へ判断を委譲する。委譲点の値は場面に応じて定めるが、$R = 1.0$ の相転移境界より前に委譲する原則は変えない。
- **ログの証言化**: 停止時に用いた観測量、判定、廃棄内容を記録し、次の計算には使用しない。
