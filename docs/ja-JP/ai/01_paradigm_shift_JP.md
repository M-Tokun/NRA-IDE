# 01 パラダイムシフト — NRA-IDEがもたらす構造転換

> [!IMPORTANT]
> 律環公理は「存在は生成である。」という一つだけです。第二公理以降は存在しません。基礎式と第二次式／二重ゆらぎ式は二つの正規IDE計算系であり、公理ではありません。
>
> 本章は、`theory/AXIOMS.md`、`theory/axioms.json`およびその他の上位正規文書に従属する説明的解釈です。安全保証、測定結果、ドメイン検証、独立した適合証拠ではありません。

## 何が転換するのか

多くの安全実務は、完了した事故から学ぶ必要があります。結果を観測し、原因を調査し、その後に対策を導入します。事故後調査は引き続き重要ですが、それだけに依存する構造は事後対応的です。証拠を利用できる時点では、被害が既に発生しています。

NRA-IDEは、事故前の経路へ注意を向けます。評価前に固定されたCause-Side観測または変換から、現在の構造軌道を評価します。

- 蓄積偏差 $\delta$ がどのように進展しているか。
- 吸収厚 $\tau$ が宣言済みドメイン規則の下でどのように消費され、または変化しているか。
- 宣言対象についての基礎式の値 $R=\delta/\tau$ が、警告、Handoff、不可逆の各閾値をどのように通過するか。
- どの観測、単位、出所、不確かさ、規則が欠けているか。

目的は、事故が起こらないと約束することではありません。これは生存領域を安全へ向けて運用適用するものであり、完全破断前、とりわけ不可逆領域へ入る前に、進展する経路を識別して応答します。基礎式を安全指標、局所計器、単なる境界接近率へ縮小するものではありません。

## 生存領域と安全志向の部分領域

NRA-IDE本体は生存式・生存領域であり、IDEを計算方法・動力学エンジンとして実装します。本章で扱う安全域は、生存領域を事故防止、運用、制御へ適用する部分領域です。生存領域全体ではなく、安全を保証しません。

生存は、同じ形の永久保存を意味しません。揺らぎ、相転移、破断、淘汰、消滅、再構成を通じて、新しい構造と履歴が生成される動的存続を含みます。

安全志向の部分領域において、安全は評価後の出力へ付与する証明書ではありません。介入可能な間に宣言済み構造経路を観測して応答することであり、より広い生存領域を静的保存へ再定義することではありません。

これは、$R<1$のすべての状態で自律運用を許可するという意味ではありません。正規状態は、段階的に強まる制約を区別します。

```text
PERMIT
→ BOUNDARY_WARNING
→ HANDOFF_REQUIRED
→ IRREVERSIBLE_TRANSITION
→ RUPTURE_BOUNDARY
```

`CONFESSION`と`OUT_OF_DESCRIPTION_DOMAIN`は、根拠不足または未定義の評価を別に扱います。

三つの正規運用閾値の順序は不変です。

```text
0 <= R_warn < R_handoff < R_irrev < 1
```

- `R_warn`では、境界接近を開示します。
- `R_handoff`では、影響を受ける新たな自律判断と運用を停止し、事前定義された固定Effect-Side証言を外部人間監査へ提示します。
- `R_irrev`では、不可逆遷移をラッチします。同一履歴内では、その後の $R$ 低下、自動処理、手動介入、人間レビュー、承認、版更新によってラッチを解除できません。
- $R\ge1$ では、`RUPTURE_BOUNDARY`を報告し、最終固定証言へ切り替えます。

したがって回避は、事故結果より前に意味を持ちます。破断を待って結果から原因を再構成するのではなく、経路を観測し、増大する危険を開示し、不可逆閾値より前に固定Handoff証言を出力します。外部監査は古い因果経路を継続したり書き換えたりしません。

## 定量化が難しくなっても観測が明瞭になる場合がある

物理構造が重大な境界へ近づくと、観測可能な兆候が強くなる一方で、信頼できる定量化が難しくなる場合があります。センサーの飽和、不確かさの拡大、適用モデルの弱化、残り観測時間の短縮が起こり得ます。強い物理的兆候は、存在しない数値精度を作り出す根拠にはなりません。

したがってNRA-IDEは、次を分離します。

- 物理的に観測されたCause-Side兆候。
- その測定値と単位。
- 不確かさと計器限界。
- 有効なドメイン変換規則。
- 結果として得られる正規状態。
- 依然として利用不能な情報。

必要な構造を根拠付けできない場合、システムは`CONFESSION`を返します。$\tau=0$ の場合、正規 $R$ は未定義であり、状態は`OUT_OF_DESCRIPTION_DOMAIN`です。どちらも、類推、意味的類似、Effect-Side出力で補ってはなりません。

`BOUNDARY_WARNING`では、観測可能な場合に二重ゆらぎの結果を報告し、観測不能な場合は欠落理由を伴う`NOT_OBSERVABLE`を報告しなければなりません。これは、測定されていない厳密値を所有しているふりをせず、物理的証言を保持します。

## 結果中心の安全性が抱える構造的問題

出力フィルタ方式の一部は、生成済み結果を検査し、内容が不適切と判断された場合に遮断します。これは生成後に適用されるEffect-Side介入です。有用な場合はありますが、それだけでは結果を生成したCause-Side構造状態を確立しません。

代理スコアを証拠と最適化目標の両方に使用する場合にも、同様の限界があります。スコアが最適化されると、指標と元の安全目的が乖離する可能性があります。

意味の検査、出力フィルタ、事故調査は、終端した因果ダイオードの外側で行えます。それらは古い評価を継続せず、Cause-Sideの値、正規閾値、状態、不可逆ラッチ、規則、変換入力、更新根拠、出所を確立または書き換えてはなりません。この禁止は、自動処理、手動介入、人間レビュー、承認、版更新のすべてに適用されます。

```text
Effect-Side結果
→ 古いCause-Sideへの接続禁止
→ 新しいCause-Sideへの接続禁止
```

## 三つの設計上の決断

### 1. 結果より前に経路を観測する

破断を最初の決定的証拠にしません。事象前に、宣言済みCause-Side変数、その出所、軌道、適用閾値を追跡します。

### 2. Effect-Sideの意味を構造権限にしない

意味解釈、翻訳、出力レビューはEffect-Sideで行えます。それらはCause-Sideの値、正規閾値、状態、不可逆ラッチ、規則、変換入力、更新根拠、出所を決定または更新してはなりません。評価前に固定された変換規則は、宣言済みCause-Side観測だけから構造変数を導出できます。古いEffect-Side資料を入力または権限としてimport、名称変更、再構成、再利用することはできません。

### 3. 不可逆遷移前に固定Handoff証言を出力する

`R_handoff`では、影響を受ける自律判断と運用を停止し、事前定義された固定Effect-Side証言を外部人間監査へ提示します。監査は古い因果ダイオードの外側にあり、古いCause-Sideにも新しいCause-Sideにも逆向きの接続を作りません。これは`R_irrev`より前に起こり、宣言済み評価における $R=1$ の`RUPTURE_BOUNDARY`とは異なります。

これらは正規状態モデルに従う設計上の決断であり、追加の公理ではありません。

## Fail-Closedは沈黙を意味しない

Fail-Closed運用原則は、次の状態で影響を受ける新たな自律判断と運用を抑止します。

- `HANDOFF_REQUIRED`
- `IRREVERSIBLE_TRANSITION`
- `RUPTURE_BOUNDARY`
- `CONFESSION`
- `OUT_OF_DESCRIPTION_DOMAIN`

必要な固定構造証言やログは抑止しません。`PERMIT`はFail-Closedではありません。`BOUNDARY_WARNING`だけでは、事前固定されたドメイン規則が要求しない限り、出力全体を抑止しません。

既知の数値的進行は`STRUCTURAL_DISCLOSURE_LOG`へ記録します。`CONFESSION`と`OUT_OF_DESCRIPTION_DOMAIN`は、別に`INPUT_EXCEPTION_LOG`へ記録します。

これらの記録は、終端Effect-Sideまたは外部証言です。外部人間監査はそれらを調査できますが、自動処理、手動レビュー、承認、版更新によってCause-Sideの値、正規閾値、状態、不可逆ラッチ、規則、変換入力、更新根拠、出所へ変換してはなりません。

## LLMを含む場合

LLMを含むシステムでは、Cause-Side観測、決定論的IDE評価、Effect-Side生成、配信強制を分離し続けなければなりません。典型的な構成は次のとおりです。

```text
Cause-Side観測
        ↓
正規NRA-IDE評価器
        ↓
入力ゲート
        ↓
LLM CORE
        ↓
出力ゲート
        ↓
正規状態で制御されたEffect-Side出力
```

通常説明は、事前固定された正規挙動が許す状態と欄でだけ行えます。固定Handoff証言または最終固定証言へ、新たに生成した自由形式説明を追加しません。

このサンドイッチはLLMを含むシステムの構成例であり、すべてのNRA-IDE評価にLLMまたは厳密に三つのソフトウェア部品が必要だという主張ではありません。

表示された層を省略しただけで直ちに不適合が証明されるわけではなく、層を描いただけで適合が証明されるわけでもありません。適合は、権限分離、正規挙動、証拠、適用可能な試験によって決まります。これは条件付き実装特性であり、安全保証ではありません。

## パラダイムシフトが主張すること、主張しないこと

転換は、結果だけに反応する構造から、境界前の構造観測と介入へ向かうものです。

```text
事故結果 → 事後的な原因再構成
```

だけでなく、次を置きます。

```text
Cause-Side軌道
→ 境界警告
→ 不可逆前の固定Handoff証言
→ 固定構造証言
→ 古いEffect-Side 終端
```

古い因果経路は完全に一方向です。

```text
古いCause-Side
→ 古い因果ダイオード
→ 古いEffect-Side
→ 終端
```

後続評価が必要な場合は、独立した別履歴として始めます。

```text
独立して宣言された新対象
→ 新たに確立したCause-Side観測と事前固定規則
→ 新しい因果ダイオード
→ 新しいEffect-Side
```

古いEffect-Sideから古いCause-Sideまたは新しいCause-Sideへ向かう矢印はありません。古いEffect-Sideの値、正規閾値、状態、不可逆ラッチ、規則、変換入力、更新根拠、出所を、Cause-Side権限としてimport、名称変更、再構成、再利用してはなりません。物理的残存物は、独立宣言した新対象の一部として新たに観測できますが、その観測は古いEffect-Sideの値や権限の移送ではありません。

NRA-IDEは、すべての危険を観測、定量化、回避できると保証しません。適格な外部人間監査、独立したCause-Sideドメイン検証、計測科学、専門基準、適用法令を置き換えません。安全志向の寄与は、事故結果を最初の利用可能な信号とみなす前に、破断前の経路、不確かさ、欠落情報、宣言済み評価の`RUPTURE_BOUNDARY`を明示することです。この部分適用は、より広い生存式・生存領域を置き換えません。
