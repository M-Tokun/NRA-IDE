## なぜ比率なのか



在るものは必ず壊れます。これは悲観ではなく、構造の事実です。有限のものが動き続ける限り、蓄積は起き、限界は必ず来ます。



問題は壊れることではなく、壊れることに気づかないまま動き続けることです。だからこそ限界までの余裕を数値にする必要があります。余裕が見えれば、限界を超過する前にバトンを渡せます。



「はじめに」から続いている問いがここで計算式になります。閾値とは構造が持っている限界であり、その限界までの余裕を数値にするとはどういうことか。



答えは比率です。



限界までの距離ではありません。距離は中心を必要とします。中心はありません。

今の振れ幅が、限界の幅に対してどのくらいかという比率だけが意味を持ちます。



```

R = δ / τ

```



δはゆらぎです。今この瞬間の構造の振れ幅です。

τは厚みです。境界線が持っている余裕幅です。

Rはその比率です。余裕がどのくらい使われているかを示します。



これだけです。距離もスコアも意味も必要ありません。

## 四つの状態



R の値によって構造は四つの状態を持ちます。



（図参照 figures/fig3_coherence_gate.png）



**NIRVANA（R < 0.4）**

ゆらぎが小さく余裕が十分にある状態です。構造は安定しています。出力は許可されます。



**ELASTIC（0.4 ≤ R < 0.7）**

ゆらぎが増えてきました。構造は呼吸しています。出力は許可されますが監視が強まります。



**CRITICAL（0.7 ≤ R < 1.0）**

限界に近づいています。構造に強い緊張が生まれています。強い注意が必要な状態です。



**ABSTAIN（R ≥ 1.0）**

限界を超過しました。NRA-IDEは出力を手放します。これは停止ではありません。AIが扱える構造の範囲を超えたという事実が引き金となり、人間が判断すべき領域へ非線形にバトンが渡ります。構造は動き続けています。

## 動いているかどうかを示すもの



R だけでは分からないことがあります。構造が今も動いているかどうかです。



それを示すのが ω（角速度）です。

ω > 0 であれば構造は動いています。位相が進んでいます。

ω = 0 になると構造は遷移不能な状態に入ります。



（図参照 figures/fig4_circle_vs_spiral.png）



ここで重要な区別があります。



**SILENCE（R ≥ 1.0、ω > 0）**

限界を超過しました。しかし構造は動いています。バトンが渡ります。次の担い手が引き継げます。



**HALT（ω = 0）**

構造が動きを失いました。超過でも未満でもなく、遷移そのものができない状態です。バトンを渡す先がありません。NRA-IDEとして最も避けるべき状態です。



円は同じ点に戻ります。螺旋は同じ点に戻りません。

ω > 0 である限り、構造は螺旋として位相を進め続けます。

NRA-IDEが扱うのは常に螺旋です。

## この計算式が存在しなかった理由



R = δ/τ は極めて単純です。しかしこの形がこれまで存在しなかった理由があります。



既存の計算は距離を前提にしています。中心があり、そこからどのくらい離れているかを測ります。距離を捨てて比率だけにするという発想は、中心の不存在という原理を出発点に置かない限り生まれません。



単純であることは公理の証拠です。これ以上削れない形が、世界の構造をそのまま写しています。
