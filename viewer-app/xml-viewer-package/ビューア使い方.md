# XML Viewer 使い方

**対象ファイル:** `xml-viewer.html`  
**作成日:** 2026年10月19日（修正版）

## 1. 起動方法

1. `xml-viewer.html` をブラウザ（Chrome / Edge など）で開きます。
2. 上部の「ファイルを開く」からXMLファイルを選択するか、「フォルダを開く」からXMLが含まれるフォルダを指定します。
3. XMLファイルを画面にドラッグ＆ドロップすることもできます。

対応拡張子: `.xml`, `.xsd`, `.xsl`, `.xslt`, `.svg`, `.xhtml`, `.html`, `.txt` など。

## 2. 基本操作

### タブ
- 複数のXMLを同時に開けます。上部のタブをクリックして切り替えます。
- タブ右の × で閉じます（`Ctrl + W` でもアクティブなタブを閉じることが可能（ブラウザにキーが先取りされる環境ではブラウザタブが閉じるため、画面内の×を推奨））。
- 最後のタブを閉じると初期画面に戻ります。
- 別のフォルダを開くと、既存のタブはクリアされます。

### ツリー表示
- 要素は展開・折りたたみ可能です（▾ / ▸ をクリック）。
- 「すべて展開」「すべて折畳」ボタンで一括操作できます。
- 深い階層（level > 2）は初期状態で折りたたまれています。
- 検索やXPath、要素ナビゲーションでノードを選択した際は、該当ノードの親階層が自動展開されます。

### ノード選択
- 要素をクリックすると選択され、青枠で強調されます。
- サイドバー「選択ノード」欄にタグ名、属性、テキスト概要が表示されます。

## 3. サイドバー機能

| セクション | 内容 |
| --- | --- |
| ファイル | フォルダを開いた場合のXML一覧。絞り込み可能。 |
| 要素ナビゲーション | 出現する要素名の一覧。クリックで該当箇所を選択（自動展開）。 |
| 選択ノード | 選択中の要素の詳細とコピーボタン。 |
| XPath | XPath式の評価と結果一覧。 |

サイドバー幅は境界（スプリッター）をドラッグして変更できます（220〜720px、表示領域により上限縮小。幅820px以下の画面ではドラッグ不可）。ダブルクリックすると初期値（360px）に戻ります。

## 4. コピー機能

- **コピー**（ヘッダー）: 文書全体をXMLとしてクリップボードにコピー（テキストの空白やCDATAを保護するため整形インデントは追加しません。XML宣言や文書型宣言はコピー対象外）。
- **ノードをコピー**: 選択中の要素（サブツリー含む）をXMLとしてコピー（自動インデントなし）。
- **XPathをコピー**: 選択中の要素の簡易XPath（位置指定付き）をコピー。属性ノードやテキストノード選択時も対応。

## 5. 検索とXPath

### 文書内検索
- `Ctrl + F` または「検索」ボタンで検索バーを表示。
- タグ名とテキストを対象にインクリメンタル検索し、▲▼または `Enter` / `Shift + Enter` で前後の一致箇所へ移動します。
- 一致したノードが折りたたまれている場合は、親階層を自動展開してフォーカスします。

### XPath
1. サイドバー「XPath」欄に式を入力します。
2. Enterキーで評価します。
3. 一致件数と一覧が表示されます。
4. 一覧の項目をクリックすると、該当ノード（属性・テキスト指定時は親要素）がハイライトされ、親階層が自動展開されます。

名前空間付きXMLでは `//*[local-name()='要素名']` の形式を推奨します。

## 6. キーボードショートカット

| キー | 機能 |
| --- | --- |
| `Ctrl + F` | 文書内検索バーの開閉 |
| `Enter`（検索バー内） | 次の一致箇所へジャンプ |
| `Shift + Enter`（検索バー内） | 前の一致箇所へジャンプ |
| `Ctrl + W` | 現在のタブを閉じる |
| `Escape` | 検索バー・画像拡大ポップアップを閉じる |

## 7. その他

- **ダーク / ライト**: テーマを切り替えます（設定はブラウザに保存）。
- **戻る / 進む**: ビューア内のファイル切り替え履歴を移動します（ブラウザ履歴ではありません）（単独ファイルオープン時も追従）。
- **?**: 簡易ヘルプを表示します。

元のXMLファイルは変更されません。表示専用です。

## 8. リンク・画像・数式・コード

- **リンク**: テキスト中の `http(s)://` URL、属性値のURLはクリックで開きます。フォルダ内の相対XMLパスや `#id` 参照もビューア内でジャンプします。
- **画像**: フォルダを開いた場合、`src` / `href` が画像を指す要素はインライン表示され、クリックで拡大します。
- **数式（LaTeX）**: `latex` / `tex` 属性、または `formula` / `equation` / `math` 要素の内容を KaTeX で描画します。
- **コード**: `code` / `source` / `pre` / `script` 要素に `lang` または `language` 属性があるとシンタックスハイライトされます。

数式とコード色分けにはCDN（KaTeX / highlight.js）への接続が必要です。オフライン時はキャッシュ状態により利用できない場合があります。XMLツリー表示そのものはCDNなしでも利用可能です。

## 9. 同梱サンプルで練習する

1. ZIPを展開し、`xml-viewer.html` をChromeまたはEdgeで開きます。
2. **フォルダを開く** で `サンプル` フォルダを指定します（画像と相対リンクを使うため、ファイル単体よりこちらを推奨）。
3. `01_操作ガイド.xml` を開き、ツリー展開、要素選択、属性確認、コピーを実行します。
4. 検索で `境界` を入力し、XPath欄で `//feature[@status='ready']` を実行します。
5. `chapters/advanced.xml` へのリンクをクリックし、タブや戻る/進む、階層表示を試します。
6. `images/diagram.svg` の画像表示と拡大、数式、コード色分けを確認します。

**制約**: XMLとして解析するため、任意のHTML・プレーンテキストがそのまま正常に表示できるとは限りません。XSDの妥当性検証、XSLT変換、XML編集・保存機能はありません。検索は表示文字列と要素名が対象で、属性値の網羅検索や正規表現検索を保証しません。相対リンクはフォルダから開いたファイル同士に限ります。

**注意**: ZIP内の `サンプル` フォルダ構造は変えないでください。ブラウザ側のファイル閲覧権限を許可する必要があります。
