# Image / HTML Viewer 使い方

1. `image-html-viewer.html` をChromeまたはEdgeで開きます。インストールは不要です。
2. 「ファイルを開く」でPNG・JPEG・SVG・HTMLを複数選択するか、「フォルダを開く」で関連CSS・JSを含むフォルダを選択します。ドラッグ＆ドロップにも対応します。
3. 上部タブをクリックして切り替え、×で閉じます。
4. 画像は＋/−、ホイール、ドラッグ移動、画面に合わせる、100%を使用できます。表示の2K上限は設けていません。画像サイズはそのまま保ち、表示倍率を調整します。
5. HTMLは隔離されたフレームで表示します。「HTML停止」でフレームを破棄し、「HTML再読み込み」で再度読み込みます。

**注意：HTML表示ではJavaScriptが実行される場合があります。信頼できるファイルのみ開いてください。**

## サンプル

`sample` フォルダを選択すると、SVGとHTMLアニメーションをタブで表示できます。`animation.html` は `assets/style.css` と `assets/demo.js` を参照しています。

## 制限事項

- SVGは静止画像用の`img`要素として表示するため、SVG内のJavaScriptは実行しません。
- HTMLは `sandbox=allow-scripts` に限定して表示し、親ビューアとは異なるオリジンとして隔離します。ネットワーク接続・フォーム送信・ポップアップ等は制限していますが、完全な安全性を保証する仕組みではありません。
- フォルダ参照では静的なCSS・JS・画像の基本的な相対パスを補助します。ES Modules、`fetch()`、Worker、動的import、深いCSS @import、HTMLからの相対ページ遷移等は保証しません。
- CDNを利用するHTML、複雑なWebGL・アニメーションではブラウザ設定や環境に依存します。
- HTMLの停止はフレームの破棄です。すべての非同期通信や外部側への影響を取り消せる意味ではありません。
- ファイルの編集・保存機能はありません。
