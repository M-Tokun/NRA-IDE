# MD Viewer タブ対応版 — 取扱説明書

**対象ファイル:** `md-viewer-tabs-2026_1018_1824.html`  
**説明書作成:** 2026年10月18日（JST）  
**構成:** HTMLファイル1個＋この説明書。インストーラーは不要です。

## 1. 起動方法

1. `md-viewer-tabs-2026_1018_1824.html` をブラウザ（Chrome / Edge等）で開きます。
2. 上部の「ファイルを開く」からMarkdown文書を選ぶか、「フォルダを開く」から文書のあるフォルダを指定します。

> **ネット接続:** Markdown、数式、コードハイライト、Mermaidの描画に使うライブラリをCDNから読み込むため、初回を含め読み込み時はネット接続が必要です。オフラインでの完全動作は保証していません。

## 2. タブを使う

- **ファイルを追加:** 上部「ファイルを開く」を押して別の `.md` 等を選びます。既存のタブは残り、新しいタブが追加されます。
- **タブを切り替える:** 画面上部のファイル名タブをクリックします。元のタブへ戻ると閲覧位置も復元されます。
- **タブを閉じる:** 各タブ右の **×** をクリックします。現在のタブを閉じた場合、ほかのタブがあればそのタブに切り替わります。最後のタブを閉じると初期表示に戻ります。
- **同じファイルを再度選ぶ:** 同一のファイルオブジェクトとして認識された場合は既存のタブへ移動します。ただし、ブラウザから選び直したファイルが常に同一判定されるとは限りません。
- **編集済みの印:** ファイル名の前に **●** が表示される場合は、そのタブの本文が読み込み時から変更されています。閉じるときは確認画面が出ます。

**重要:** タブを閉じてもPC上の元ファイルは削除されません。閉じる操作はビューア内でその文書を閉じるだけです。

## 3. ファイルを開く方法

| 方法 | 操作 | 備考 |
| --- | --- | --- |
| 単独ファイル | 「ファイルを開く」 | 現在の実装ではファイル選択欄に`multiple`指定がないため、通常は1回の選択につき1ファイル。追加したい場合は繰り返します。 |
| フォルダ | 「フォルダを開く」 | フォルダ内のMDと画像の相対参照、ファイル一覧、全文検索等を利用できます。**新しいフォルダを開く際、従来のタブはクリアされます。** |
| ドラッグ＆ドロップ | MDファイルを画面にドロップ | 複数の対応MDが渡された場合は順番に開きます。 |
| 本文中のリンク | フォルダに含まれる別のMDへの相対リンクをクリック | リンク先が認識されている場合にビューア内で開きます。 |

対応する文書拡張子: `.md`, `.markdown`, `.mdown`, `.mkd`, `.txt`。

## 4. 主な画面機能

- **目次:** 左サイドバーに見出しを表示。見出しジャンプ・展開・折畳・絞り込みに対応します。
- **画面幅調整:** サイドバー境界をドラッグして幅を変更。編集モードでは本文との境界をドラッグできます。
- **編集:** 上部「編集」でMarkdownソースを表示・変更し、プレビューへ反映します。
- **検索:** 「検索」から文書内検索、フォルダを開いている場合はフォルダ全文検索を利用できます。
- **表示:** 文字サイズと本文の最大幅を調整できます。
- **JP⇄EN／対訳:** フォルダ内に対応する日本語・英語文書が検出された場合に有効になります。
- **表:** 対応する表の並べ替え、絞り込み、CSV/TSVコピーが利用できます。
- **数式・図:** KaTeX数式とMermaidの表示、画像拡大に対応します（外部ライブラリ読込が必要）。
- **リンク検査:** フォルダを開いた場合、相対リンクなどを検査します。
- **ダーク:** テーマ切替。
- **HTML 保存:** **現在表示中の文書をHTML形式で書き出す**機能です。
- **印刷:** ブラウザの印刷画面を開きます。

## 5. 編集と保存の重要な違い

1. 「編集」では、ビューアが保持するMarkdownテキストを変更できます。
2. **元の `.md` ファイルを自動的に書き換える機能ではありません。**
3. 上部の **「HTML 保存」** は、表示内容をHTML文書として書き出します。Markdown原本の保存・上書きではありません。
4. 未保存のタブを閉じる際は確認が出ます。ただし**フォルダの開き直し、ページ再読み込み、ブラウザ終了時まで編集内容が完全に保護されるとは限りません。** 大切な原文の編集には元MDを編集できるエディタ（例: VS Code）を使ってください。

## 6. キーボード操作

| 操作 | ショートカット |
| --- | --- |
| 文書内検索 | `Ctrl + F`（編集欄にフォーカスがある場合はブラウザ標準検索） |
| フォルダ全文検索 | `Ctrl + Shift + F` |
| 次の検索結果 | `Enter` / `F3` |
| 前の検索結果 | `Shift + Enter` / `Shift + F3` |
| 検索欄を閉じる | `Esc` |
| 閲覧履歴の戻る・進む | `Alt + ←` / `Alt + →` |

Macでは一部の`Ctrl`操作を`Command`で代用できる実装ですが、ブラウザの標準ショートカットとの競合には注意してください。

## 7. 困ったとき

**Markdownが表示されない:** ネット接続を確認し、CDNからのJavaScript読み込みがブロックされていないか確認してください。

**画像や別MDへのリンクが解決しない:** 単独ファイルではブラウザが周辺ファイルへ自由にアクセスできません。関連文書・画像を含むフォルダを「フォルダを開く」で選んでください。

**タブが消えた:** 別のフォルダを開いた場合は従来タブがクリアされます。閉じる操作や再読み込みではタブ一覧の永続復元を保証していません。

**編集したMDが元ファイルに反映されない:** 仕様です。「HTML 保存」はHTML出力専用であり、元MDの上書きは行いません。
