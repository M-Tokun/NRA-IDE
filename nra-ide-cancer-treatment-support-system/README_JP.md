## 1. プロジェクト概要 (Project Overview)



**NRA-IDE**（Nomological Ring Axioms - Intensional Dynamics Engine）は、指定条件下の単一細胞の狭窄通過について、未検証モデル内の決定論的な計算結果を返す研究用エンジンです。患者の転移リスクは判定しません。



従来の医療AIが数百万人の「統計（平均）」に依存するのに対し、本システムは目の前の患者一人の「物理（実測値）」に依拠します。

モデルで仮定した抵抗応力と駆動圧の関係を示します。現実の通過可否や治療計画の妥当性は、この計算だけでは確定できません。



### 従来のAIとの違い



| 従来の医療AI | NRA-IDE |
|-------------|---------|
| 数百万人の統計データに依存 | **目の前の一人の患者の物理データ** |
| 確率的予測 | **決定論的判定** |
| ブラックボックス | **透明な物理式** |



> **決定論は再現性の保証であり、正しさの保証ではありません。**

> 同じ入力に常に同じ出力を返しますが、モデルやパラメータが誤っていれば、安定して誤り続けます。本システムの妥当性は `検証プロトコル_マイクロ流路試験.md` に基づく実験によって検証されるべきものであり、現時点で未完了です。

## 2. 判定の対象（適用範囲）



本システムが答える問いは、次の一点に限定されます。



> **指定入力が、単一細胞の狭窄通過モデルの判定境界のどちら側にあるか。**

これは未実験検証モデル内の計算であり、現実の通過事象や患者の転移を予測・確認したものではありません。



| 問い | 本システム |
|:---|:---|
| 指定条件がモデルの通過境界のどちら側か | **モデル内で計算する** |
| 薬剤が腫瘍間質へ浸透できるか | **判定しない**（§5 の背景で述べる動機であり、判定対象ではない） |



薬剤到達は多孔質媒体中の流体輸送（Darcy 則・拡散）であり、支配則もパラメータも本モデルとは異なります。両者を同じ式・同じ判定語彙で扱ってはなりません。



### 出力語彙



| 出力 | 物理的意味 |
|:---|:---|
| `BLOCKED` | モデル上、抵抗応力が駆動圧を上回る。現実の通過不能は未確認 |
| `PASSABLE` | モデル上、抵抗応力が駆動圧以下。現実の通過は未確認 |



**`SAFE` / `DANGER` の語は使用しません。** 「モデル上で抵抗応力が優位」と「投薬してよい」は別の命題です。一語に畳むと、計算結果が治療の許可として読まれ、Gate Axiom（決定権は医師にある）に反します。

## 3. 核心哲学：律環公理 (Nomological Ring Axioms)



本システムの全ての設計判断は、以下の3つの公理に従っています。



### 1. **Physics First (物理第一主義)**

判定の根拠はすべて物理式で説明可能であり、ブラックボックスを排除する。



### 2. **Fail-Closed (ギアメカニズム)**

通信、計算、入力に異常があれば、エラーを出して判定を `INVALID` とし、通過可否を分類しません。リスクを否定できないまま処置判断へ進めないことが安全側の扱いです。エラーを伴う `o_is_jammed = 0` は有効な `PASSABLE` ではありません。



### 3. **Gate Axiom (ゲート公理)**

システムは計算機に徹する。最終的な「治療の断行」は、**倫理的責任を負う医師が決定する**。

## 5. 背景：「効いていない」ではなく「届いていない」



> **本節はプロジェクトの動機であり、現行システムの判定対象ではありません。**

> 薬剤到達の可否を判定する機能は実装されていません。



従来のがん治療は「薬が効いているか」を評価しますが、実際には次の問題があります。



* がん組織内では**高間質圧（IFP）**が発生し、**中心部への薬剤到達が困難**

* **低灌流領域**では、**静脈内投与薬剤が血流とともに押し返され、局所浸潤や再発の温床**となる

* 子宮体腫瘍では**リンパ節と連動した分岐流路**があり、**方向性を伴わない拡散薬物動態**が起きやすい



「届いていない領域」を数値で評価する術が乏しい——この問題意識から出発し、まず単一細胞の狭窄通過について**検証前の応力比較モデル**を構成しました。現実の脱出可否は未確認であり、薬剤到達側のモデル化も今後の課題です。

## 6. 物理モデル（律環公理に基づく判定）



本モデルでは、**抵抗応力** $\sigma_{resist}$ と**駆動圧** $\Delta P$ の比較で判定語を定めます。現実の通過可否は実験で未確認です。



$$\sigma_{resist} = (E + B)\cdot\frac{D-d}{D} \;+\; \frac{12\,\eta\,v\,D}{1000\,d^{2}} \;>\; \Delta P \implies \text{BLOCKED}$$



### パラメータ説明



| 記号 | 意味 | 単位 |
|:---:|:---|:---:|
| $E$ | 細胞のヤング率（弾性率） | kPa |
| $B$ | 薬剤による硬化補強分 | kPa |
| $D$ | 細胞直径 | μm |
| $d$ | 隙間サイズ（Pore） | μm |
| $(D-d)/D$ | **圧縮歪み（無次元）** | – |
| $\eta$ | 細胞質および周囲水分の粘性 | Pa·s |
| $v$ | 変形速度 | μm/s |
| $\Delta P$ | 血流駆動圧 | kPa |



右辺第1項が弾性抵抗、第2項が孔内粘性抵抗です。**全項が kPa に揃っており、両辺は同次元です。**



* 粘性がゼロの入力 → **Error 0x03**（生体では起こり得ず、測定系の異常を意味する）

* 細胞直径が隙間より小さい → **Error 0x01**（そもそも変形せずに通過する）



詳細は `jp/.../00_Documentation/PHASE_2_Mesoscale_Physics.md` を参照してください。

## 7. ジャミングマップ（判定境界の可視化）



NRA-IDEは、指定入力を参照モデルで計算し、硬化分 $B$（投与量ではない）と駆動圧 $\Delta P$ の平面上にモデル内の判定境界を描きます。



| 領域 | 条件 | 意味 |
|:---|:---|:---|
| 🟩 BLOCKED | $\sigma_{resist} > \Delta P$ | モデル上の抵抗優位。現実の通過不能は未確認 |
| 🟥 PASSABLE | $\sigma_{resist} \le \Delta P$ | モデル上の駆動圧優位。現実の通過は未確認 |



描画されるのは参照モデルの判定境界であり、現実の生物学的境界ではありません。



> **境界近傍のマージン評価（旧 BORDER 相当）は未実装です。** 現行の出力は二値であり、「境界にどれだけ近いか」は判定に含まれません。臨床上はこのマージンこそ重要になるため、今後の課題です。

## 8. クイックスタート (Quick Start)



導入と運用の詳細は **[jp/ディレクトリ](./jp/)** 内のドキュメントを参照してください。



```bash

cd jp/NRA-IDE_Cancer_Treatment_Support_System/20_Software_Host

pip install -r requirements.txt
# 実機FPGA / UART を使う場合のみ: pip install -r requirements-hardware.txt



# 自己診断（FPGA 未接続でも参照実装で動作する）

python main.py --test



# 一括検証（7ケース）

cd ../30_Test_Data && python run_validation.py



# 研究用シミュレーション（レポートとジャミングマップを出力。臨床使用不可）

cd ../20_Software_Host

python main.py --data ../30_Test_Data/sample_patient_data.json --out ./output

```



| コマンド | 状態 |
|:---|:---|
| `python main.py --test` | **動作する**（FPGA 非接続時は参照実装で判定） |
| `python run_validation.py` | **動作する**（7/7 PASS） |
| `python main.py --data <path> [--out <dir>]` | **動作する**（レポート .txt とマップ .png を出力） |



入力が Phase 4 の範囲外の場合、計算は行わず `_REJECTED.txt` として却下の記録だけを残します（Fail-Closed）。
