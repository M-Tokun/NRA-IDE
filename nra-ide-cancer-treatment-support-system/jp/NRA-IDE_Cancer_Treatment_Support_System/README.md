## 1. プロジェクト概要 (Project Overview)



**NRA-IDE**（Nomological Ring Axioms - Intensional Dynamics Engine）は、癌細胞の物理的特性を解析し、転移リスクを決定論的に判定する研究用の計算エンジンです。



従来の医療AIが数百万人の「統計（平均）」に依存するのに対し、本システムは目の前の患者一人の「物理（実測値）」に依拠します。

物理法則（構造力学）によって計算される「転移が不可能な条件」を特定し、治療計画の検討を支援します。



> **決定論は再現性の保証であり、正しさの保証ではありません。** モデルやパラメータが誤っていれば、安定して誤り続けます。妥当性は `検証プロトコル_マイクロ流路試験.md` に基づく実験で検証されるべきものであり、現時点で未完了です。



## 2. 判定の対象（適用範囲）



本システムが答える問いは、次の一点に限定されます。



> **癌細胞が血管内皮の隙間（Pore）を通り抜けられるか。**



薬剤が腫瘍間質へ浸透できるか（後述の「届いていない」問題）は、多孔質媒体中の流体輸送であり支配則が異なります。**本システムは判定しません。**



### 出力語彙



| 出力 | 物理的意味 |
|:---|:---|
| `BLOCKED` | 抵抗応力が駆動圧を上回り、細胞は隙間を通過できない |
| `PASSABLE` | 細胞は変形して通過しうる（転移経路が開いている） |



**`SAFE` / `DANGER` の語は使用しません。** 「細胞が封鎖されている」ことと「投薬してよい」ことは別命題であり、一語に畳むと Gate Axiom に反します。



## 3. 核心哲学：律環公理 (Nomological Ring Axioms)



1. **Physics First (物理第一主義):** 判定の根拠はすべて物理式で説明可能であり、ブラックボックスを排除する。

2. **Fail-Closed (ギアメカニズム):** 通信、計算、入力のいずれかに 1ビットでも不確実性があれば、システムは安全側に倒れ、警告（Error）を発する。ここでいう安全側とは、**転移リスクが有るとみなす側（`PASSABLE`）** である。

3. **Gate Axiom (ゲート公理):** システムは計算機に徹する。最終的な「治療の断行」は、倫理的責任を負う医師が決定する。



## 4. 技術アーキテクチャ (Technical Architecture)



* **Compute Layer (FPGA):** Intel Cyclone V / Xilinx Artix-7 上で動作する専用演算回路。Q8.8 固定小数点演算により、OSの介入を排した決定論的計算を実行。

* **Control Layer (Python):** 医師の入力を物理的に検証し、FPGA とバイナリプロトコルで通信。臨床レポートとジャミングマップを生成。

* **Verification Layer:** 物理シミュレーションに基づく期待値（Oracle）を用いた自動診断機能を備え、稼働前の健全性を証明。



判定式は `20_Software_Host/nra_core_model.py`（参照実装）と `10_Hardware_Design/src/10_BioCalibrator_TypeA.v`（FPGA）が**ビット単位で同一**です。可視化もこの参照実装だけを判定根拠とします。

## ⚠️ 2. 問題提起：「効いていない」ではなく「届いていない」



> **本節はプロジェクトの動機であり、現行システムの判定対象ではありません。**



### 🔴 問題点



* がん組織内では**高間質圧（IFP）**が発生し、**中心部への薬剤到達が困難**

* **低灌流領域**では、**静脈内投与薬剤が血流とともに押し返され、局所浸潤や再発の温床**となる

* 子宮体腫瘍では**リンパ節と連動した分岐流路**があり、**方向性を伴わない拡散薬物動態**が起きやすい



この問題意識から出発し、まず**物理的に扱いが確定している「細胞の脱出可否」**を定式化したのが本システムです。薬剤到達側のモデル化は今後の課題です。

## ⚙️ 3. NRA-IDEの手法：構造力学 × 判定エンジン



![図4: NRA-IDE対応構造図イメージ](src/おおまかな単なる概要参考図7.png)



NRA-IDEは、**癌細胞が血管の隙間を「通れる/通れない」**を以下のように**物理モデルで定式化**します。



### 🧠 抵抗モデル（律環公理に基づく判定）



$$\sigma_{\text{resist}} = (E + B)\cdot\frac{D-d}{D} \;+\; \frac{12\,\eta\,v\,D}{1000\,d^{2}}$$



| 記号 | 意味 | 単位 |
|:---:|:---|:---:|
| $E$ | 細胞のヤング率（弾性率） | kPa |
| $B$ | 薬剤による硬化補強分 | kPa |
| $D$ | 細胞直径 | μm |
| $d$ | 隙間サイズ（Pore） | μm |
| $(D-d)/D$ | **圧縮歪み（無次元）** | – |
| $\eta$ | 細胞質および周囲水分の粘性 | Pa·s |
| $v$ | 変形速度 | μm/s |



### ✅ 判定基準



$$\sigma_{\text{resist}} > \Delta P \implies \text{BLOCKED（細胞は通過できない）}$$



全項が kPa に揃っており、両辺は同次元です。応力に乗じるのは変位ではなく**歪み（無次元）**であることに注意してください。



* 粘性がゼロの入力 → **Error 0x03**（生体では起こり得ず、測定系の異常を意味する）

* 細胞直径が隙間より小さい → **Error 0x01**（変形せずに通過する）

## 🧪 4. 応用：ジャミングマップ（判定境界の可視化）



NRA-IDEでは、**入力パラメータ（細胞硬度・粘性・血流圧・細胞径・隙間径）**をFPGAによりリアルタイム処理し、薬剤量 $B$ と血流圧 $\Delta P$ の平面上に判定境界を描きます。



| 領域 | 条件 | 意味 |
| :--- | :--- | :--- |
| 🟩 BLOCKED | $\sigma_{resist} > \Delta P$ | 細胞は隙間を通過できない |
| 🟥 PASSABLE | $\sigma_{resist} \le \Delta P$ | 細胞は変形通過しうる |



描画される境界線は近似ではなく、**FPGA の判定境界そのもの**（同一の Q8.8 演算）です。



> **境界近傍のマージン評価（旧 BORDER 相当）は未実装です。** 現行の出力は二値であり、境界にどれだけ近いかは判定に含まれません。
