## 1. 物理的設置チェック (Physical Infrastructure)



医療現場における物理的安定性を確保するための確認事項です。



* [ ] **電源の安定性:** FPGAボードおよびホストPCが、医療用アイソレーション電源または安定したコンセントに接続されているか。

* [ ] **通信経路の固定:** USB-UARTケーブルが確実に奥まで差し込まれ、振動等で脱落しないよう固定されているか。

* [ ] **冷却環境:** FPGAチップのヒートシンク周囲に十分な空間があり、排気が妨げられていないか。

* [ ] **LED視認性:** 操作者からボード上の LED 0 (Green) / LED 1 (Red) が常時確認できる位置に配置されているか。



## 2. システム・インテグリティ (System Integrity)



論理回路とソフトウェアが「正解」の状態にあるかの確認です。



* [ ] **ビットストリーム検証:** FPGAに書き込まれた回路が、最新の「3バイト・レスポンス」および「Type B非線形LUT」を含む正式リリース版（v1.1）であるか。

* [ ] **ポート認識:** ホストPCにおいて、シリアルポート（`/dev/ttyUSB0` 等）が正しく認識され、アクセス権限が付与されているか。

* [ ] **自己診断の実施:** コマンド `python main.py --test` を実行し、**「Hardware Integrity Verified」** が表示されたか。

* [ ] **時計同期:** ホストPCの時刻が正しく設定されており、レポートのタイムスタンプが JST (UTC+9) であるか。



## 3. 臨床安全確認 (Clinical Safety / Ritsukan Axiom)



律環公理（NRA）に基づいた、運用の最終確認です。



* [ ] **不連続性の排除:** 入力データが Phase 4 の有効範囲（Q8.8 Domain）内にあり、バリデータがエラーを吐いていないか。

* [ ] **因果ダイオードの遵守:** 判定結果を得るために、物理パラメータ（Stiffness等）を恣意的に操作していないか。

* [ ] **ゲート公理の再確認:** 本システムは「物理的予測値」を提供する計算機であり、最終的な治療決定権と責任は担当医師にあることを、操作者全員が承知しているか。
