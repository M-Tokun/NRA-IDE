# NRA-IDE 検証プロトコル：マイクロ流路ジャミング試験

**版数:** 2.0 (2026-07-28) — PHASE_2 Rev 2.0 に同期。Type A/B 定義の訂正を含む。

**目的:** FPGAが算出する「ジャミング（物理的封鎖）閾値」と、実実験における細胞通過現象の整合性を検証する。



---



## 1. 検証の目的



本システム「NRA-IDE (Bio-Calibrator)」は、物理法則に基づく決定論的シミュレータである。

本プロトコルは、計算機上の予測結果（In silico）が、現実の物理実験（In vitro）において再現されることを確認し、システムの物理的信頼性を証明することを目的とする。



### 1.1 検証対象の限定



本プロトコルが検証するのは **Type A（単一細胞ジャミングモデル）のみ** である。



| モデル | 内容 | 本プロトコル |

|:---|:---|:---|

| **Type A** | 単一細胞が隙間を通過できるか | **検証する** |

| **Type B** | 細胞集団（クラスター）のスクラム効果 | 対象外。別途クラスター試験プロトコルを要する |

| 薬剤到達モデル | 腫瘍間質への浸透 | 未実装。対象外 |



> **⚠ 版数1.0からの訂正:** 旧版は細胞株を「Type A（柔軟/高転移）」「Type B（高剛性/低転移）」と記載していたが、これは誤りである。**PHASE_2 における Type A / Type B は細胞数の軸（単一細胞 / 細胞集団）による分類であり、硬さによる分類ではない。** 旧版の記載どおりに実験を行うと、単一細胞試験の結果を集団モデルの検証と取り違えることになる。



---



## 2. 実験セットアップ



### 2.1 物理モデル（血管模倣環境）



* **デバイス:** PDMS（ポリジメチルシロキサン）製マイクロ流路チップ

* **構造定義:**

    * **メイン流路:** 幅 50μm（細動脈相当）

    * **狭窄部（ポア）:** 幅 5μm, 8μm, 10μm, 12μm（可変・血管内皮隙間を模倣）

    * **流路高さ:** 細胞直径と同等（10-20μm）とし、3次元的な自由度を制限する。



狭窄幅はいずれも Phase 4 の `pore_size` 範囲（5.0–15.0 μm）に収まる。



### 2.2 ターゲット（細胞）



いずれも**単一細胞**として導入し、Type A モデルを検証する。硬さの異なる2株を用いるのは、判定境界の両側を踏むためである。



| 株 | 性質 | 想定される判定 |

|:---|:---|:---|

| **MDA-MB-231**（ヒト乳癌由来） | 柔軟・高転移能（$E$ 小） | `PASSABLE` 側 |

| **MCF-7**（ヒト乳癌由来） | 高剛性・低転移能（$E$ 大） | `BLOCKED` 側 |



* **物性測定:** 実験前にAFM（原子間力顕微鏡）等を用い、対象細胞集団の以下の分布データを取得する。



| 測定量 | 記号 | 単位 | 手段 |

|:---|:---:|:---:|:---|

| ヤング率 | $E$ | kPa | AFM |

| 細胞直径 | $D$ | μm | 顕微鏡 |

| 細胞質粘性 | $\eta$ | Pa·s | マイクロレオロジー等 |

| 変形速度 | $v$ | μm/s | 高速度カメラの追跡から算出 |



> $\eta$ と $v$ は旧版の入力表から欠落していた。粘性項 $12\eta v D/(1000 d^2)$ の算出に必要であり、測定できない場合は Phase 4 の標準値（$\eta$ は株ごとの文献値、$v = 200$ μm/s）を用い、**その旨を記録に残すこと。**



### 2.3 駆動システム



* **圧力制御:** 精密圧力ポンプ（制御範囲: 100〜1000 Pa ＝ 0.1〜1.0 kPa）

* **観測系:** 倒立顕微鏡 + 高速度カメラ（1000 fps以上推奨）



駆動圧は Phase 4 の `flow_dp` 範囲（0.0–5.0 kPa）内にあり、Q8.8 の分解能は 0.0039 kPa（約4 Pa）である。ポンプの設定分解能がこれより粗い場合、判定境界近傍では設定値そのものが誤差要因になる。

## 3. 検証手順 (Step-by-Step)



### Step 1: FPGAによる事前予測



実験条件をNRA-IDEに入力し、判定させる。**実験前に予測を記録し、後から書き換えないこと**（因果ダイオード）。



* **入力パラメータ:**

    * ヤング率 $E$: AFM測定値の中央値 [kPa]

    * 細胞直径 $D$: 顕微鏡測定値 [μm]

    * 狭窄サイズ $d$: チップ設計値 [μm]

    * 細胞質粘性 $\eta$: 測定値または文献値 [Pa·s]

    * 変形速度 $v$: 追跡値または標準値 200 [μm/s]

    * 駆動圧力 $\Delta P$: ポンプ設定値 [kPa]

    * 薬剤硬化分 $B$: 未処理なら 0

* **出力予測:** `BLOCKED`（通過不能）または `PASSABLE`（変形通過）



### Step 2: 物理実験の実行



1. マイクロ流路に細胞懸濁液を導入する。

2. Step 1で設定した一定圧力 ($\Delta P$) を印加する。

3. 細胞が狭窄部に到達してから、通過完了（または完全停止）するまでの挙動を録画する。



### Step 3: 結果の照合判定



| FPGA予測 | 実験結果 (物理現象) | 判定 | 評価 |

| :--- | :--- | :--- | :--- |

| **BLOCKED** | 細胞が狭窄部で停止、60秒以上不動 | **整合 (TP)** | ✅ モデルの正確性を支持 |

| **PASSABLE** | 細胞が変形し、5秒以内に通過 | **整合 (TN)** | ✅ モデルの正確性を支持 |

| **BLOCKED** | 細胞がすり抜けた | **不整合 (FP)** | ❌ 抵抗を過大評価。係数の再検討が必要 |

| **PASSABLE** | 細胞が詰まった | **不整合 (FN)** | ❌ 抵抗を過小評価。安全側への倒れ方が逆 |



**FN は FP より重大である。** FN は「通過する」と予測した細胞が実際には詰まる場合であり、本システムの Fail-Closed の向き（疑わしきは `PASSABLE`）が実験に対して安全側でないことを意味する。

## 4. 薬剤応答性（キャリブレーション）の検証



NRA-IDEが提示した「適合値」の有効性を確認する。



### 4.1 手順



1. **シナリオ:** 現状では通過してしまう条件を設定する。

2. **処方算出:** FPGA（または参照実装 `nra_core_model.required_boost()`）により、`BLOCKED` を成立させる最小の硬化分 $B$ を算出する。

3. **薬剤処理:** 細胞骨格調整試薬（Jasplakinolide等）を用い、細胞硬度を実測で $B$ だけ上昇させる。

4. **再実験:** 同一圧力下で実験を行い、**「予言通りに細胞が詰まる」**ことを確認する。



### 4.2 算出例（現行モデルによる）



軟らかい高転移株を想定した条件での計算例を示す。



| 条件 | 値 |

|:---|---:|

| ヤング率 $E$ | 0.5 kPa |

| 細胞直径 $D$ | 18.0 μm |

| 狭窄サイズ $d$ | 10.0 μm |

| 粘性 $\eta$ | 0.05 Pa·s |

| 変形速度 $v$ | 200 μm/s |

| 駆動圧 $\Delta P$ | 0.5 kPa（500 Pa） |



| 算出量 | 値 |

|:---|---:|

| 弾性抵抗 $\sigma_{el}$ | 0.219 kPa |

| 粘性抵抗 $\sigma_{v}$ | 0.020 kPa |

| 合計 $\sigma_{resist}$ | 0.238 kPa |

| 判定 | `PASSABLE`（0.238 ≤ 0.5） |

| **必要な硬化分 $B$** | **+0.60 kPa** |



> **⚠ 版数1.0からの訂正:** 旧版は同条件で「+1.5 kPa」としていたが、これは次元不整合のあった旧式（$k\cdot\Delta x$）に基づく値であり誤りである。現行の応力比較形では **+0.60 kPa** となる。



狭窄を 12 μm に広げると必要硬化分は +0.98 kPa、駆動圧を 0.3 kPa に下げると +0.14 kPa となる。**実験計画時には、Jasplakinolide 等で実現可能な硬度変化幅に対して、必要 $B$ が現実的な範囲に入る条件を選ぶこと。**

## 5. 判定基準と反証条件



### 5.1 合格基準



本プロトコルに基づく実験において、FPGA予測と実験結果の一致率が **90%以上** であることをもって、本システムの研究用ツールとしての妥当性を担保する。



### 5.2 決定論と統計の層について



本システムは決定論的モデルであるが、その**妥当性の検証には統計を用いる**。これは矛盾ではなく、層が異なる。



| 層 | 性質 |

|:---|:---|

| モデル内部 | 決定論。同じ入力に常に同じ出力 |

| モデルの妥当性検証 | 統計。実験の一致率で評価する |

| 入力パラメータ | 分布を持つ実測値。中央値を採る時点で統計が介在する |



「統計に依存しない」と主張できるのはモデル内部の演算についてのみである。入力と検証には統計が不可避であり、これを隠してはならない（告白の公理）。



### 5.3 反証条件



次のいずれかに該当した場合、**現行の Type A モデルは棄却される。**



1. 一致率が 70% を下回る

2. FN（`PASSABLE` 予測に対し実際は閉塞）が全試行の 10% を超える

3. 判定境界の位置が実験値に対して系統的にずれ、単一の係数補正で説明できない



棄却された場合、係数の微調整で取り繕ってはならない。支配方程式の形（弾性項と粘性項の構成、歪みの定義）に立ち返ること。
