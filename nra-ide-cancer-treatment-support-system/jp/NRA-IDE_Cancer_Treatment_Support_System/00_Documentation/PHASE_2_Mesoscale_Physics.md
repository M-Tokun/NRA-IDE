# Phase 2: Mesoscale Physics Protocol



## 0. 適用範囲 (Scope)



本モデルが答える問いは、次の一点に限定される。



> **癌細胞が血管内皮の隙間（Pore）を通り抜けられるか。**



「薬剤が腫瘍間質へ浸透できるか」は、多孔質媒体中の流体輸送（Darcy 則・拡散）であり、支配則もパラメータも本モデルとは異なる。**本システムはこれを扱わない。** README における薬剤到達の記述は、本プロジェクトの動機・背景であって、判定エンジンの対象ではない。



### 出力語彙



判定結果は `BLOCKED` / `PASSABLE` で表現する。



| 出力 | 物理的意味 |

|:---|:---|

| `BLOCKED` | 抵抗応力が駆動圧を上回り、細胞は隙間を通過できない |

| `PASSABLE` | 細胞は変形して通過しうる（転移経路が開いている） |



**`SAFE` の語は使用しない。** 「細胞が封鎖されている」ことと「投与してよい」ことは別命題であり、一語に畳むと臨床判断を誤らせる（Gate Axiom 違反）。

## 1. Governing Equation (支配方程式)



細胞が隙間を通過できるか否かは、細胞が発生させる**抵抗応力** $\sigma_{resist}$ と、血流の**駆動圧** $\Delta P$ の闘争で決まる。



$$\sigma_{resist} > \Delta P \implies \text{BLOCKED}$$



### Type A: Jamming Model (Single Cell)



$$\sigma_{resist} = (E + B)\cdot\underbrace{\frac{D-d}{D}}_{\text{歪み}} \;+\; \frac{12\,\eta\,v\,D}{1000\,d^{2}}$$



| 記号 | 意味 | 単位 |

|:---:|:---|:---:|

| $E$ | 細胞のヤング率（弾性率） | kPa |

| $B$ | 薬剤による硬化補強分 | kPa |

| $D$ | 細胞直径 | μm |

| $d$ | 隙間サイズ（Pore） | μm |

| $(D-d)/D$ | **圧縮歪み（無次元）** | – |

| $\eta$ | 細胞質および周囲水分の粘性 | Pa·s |

| $v$ | 変形速度 | μm/s |

| $\Delta P$ | 血流駆動圧 | kPa |



右辺第1項は弾性抵抗、第2項は孔内粘性抵抗（Stokes 抗力を孔断面 $\pi d^2/4$ で正規化したもの）である。係数 $1/1000$ は Pa → kPa 換算。**全項が kPa に揃っており、両辺は同次元である。**



### ⚠ 改訂理由（Rev 1.0 からの変更）



旧版は $F_{resist} = (k+B)\cdot\Delta x + \eta\cdot dv/dt$ としていたが、次の2点で次元が閉じていなかった。



1. $k$ をヤング率（応力 [kPa]）と定義しながら、ばね定数 [N/m] のように変位 $\Delta x$ [μm] を直接乗じていた。**応力に乗じるべきは変位ではなく歪み（無次元）である。**

2. ダンパー抵抗は速度に比例する $\eta v$ であり、加速度 $dv/dt$ ではない。



この誤りにより、実装（Phase 10）では弾性項が駆動圧より数桁大きくなり、幾何エラー以外は常に `BLOCKED` へ張り付いていた。Rev 2.0 の応力形では、Phase 30 の検証ケース全7件が期待値どおりに再現される。

## 2. Critical Rule: Viscosity



**「水分の粘性（ $\eta$ ）をゼロにしてはならない」**



静的な硬さ（ $E$ ）だけでなく、急激な血圧変動に耐えるには粘性抵抗（ダンパー効果）が不可欠である。



ただし本改訂により、 $\eta = 0$ は**数学的な特異点ではなくなった**（旧・可視化モデルでは $\eta$ が分母にあったため発散した）。応力形では $\eta = 0$ は単に減衰項が消えるだけで、計算自体は成立する。



したがって Error `0x03` は演算上の必然ではなく、**入力の物理的妥当性を却下する規範的判断**である。生体組織で $\eta = 0$ はあり得ず、そのような測定値は測定系の異常を意味する。ホスト側バリデータと FPGA の双方で検出し、計算を実行せずに却下する（Fail-Closed）。

## 3. Type B: Collective Model (Multi-Cell)



$$\sigma_{collective} = \sigma_{single}\cdot N\cdot(1 + \alpha\sqrt{N})$$



* $N$: 細胞数（クラスターサイズ）

* $\alpha\sqrt{N}$: 集団による非線形スクラム効果（ $\alpha = 0.5$ を仮定）



**注意: 本項は未検証の現象論モデルである。** $\sqrt{N}$ 則の物理的根拠は Phase 60 の文献では裏付けられておらず、増幅係数 $\alpha$ も実測されていない。Type A の実験検証（`検証プロトコル_マイクロ流路試験.md`）が完了するまで、Type B の判定結果を臨床的解釈に用いてはならない。



なお Type A / Type B は**細胞数の軸**による分類であり、細胞の硬さによる分類ではない。硬さで分類している記述（検証プロトコル §2.2 等）は誤りであり、別途訂正を要する。
