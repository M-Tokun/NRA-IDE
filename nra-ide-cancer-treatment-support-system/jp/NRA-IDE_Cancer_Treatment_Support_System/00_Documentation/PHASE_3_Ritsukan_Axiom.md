# Phase 3: Nomological Ring Axioms (Safety Rules)



## 1. Causal Diode (因果ダイオード)

**「結果から原因を逆算してはならない」**

* 禁止: 「SAFEになりたいから、パラメータを少しイジろう」

* 許可: 「パラメータを入れたらDANGERだった。では薬剤（Boost）を足すとどうなるか計算しよう」

システムは常に「入力 → 出力」の一方通行（順方向）のみを許可する。



## 2. Gear Mechanism (ギアメカニズム)

**「疑わしきは止める（Fail-Closed）」**

歯車が一つでも噛み合わない（データ欠損、範囲外、通信エラー）場合、システムは無理に動こうとせず、安全側に倒れて「DANGER（エラー）」を出力する。

* 幾何学的矛盾（直径 < 隙間） → DANGER (Error 0x01)

* 粘性ゼロ（$\eta=0$） → DANGER (Error 0x03)



## 3. Gate Axiom (ゲート公理)

**「決定権は人間にある」**

システムが出力するのは「物理的な計算結果」のみである。「治療せよ」という命令はしない。

最終的なGo/No-Goの判断（ゲートを開くか否か）は、倫理的責任を負える医師のみが行う。
