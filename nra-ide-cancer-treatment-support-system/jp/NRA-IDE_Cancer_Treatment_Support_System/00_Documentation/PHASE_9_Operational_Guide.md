# Phase 9: Operational Guide



## 1. Daily Operation Flow

1.  **起動:** FPGA電源ON → ホストPCで `main.py` 起動。

2.  **自己診断:** `python main.py --test` を実行し、ハードウェア健全性を確認。

3.  **測定:** 患者の測定データ（超音波・MRI等）を用意。

4.  **入力:** 数値を入力し、Enter。

5.  **判定:** 瞬時にSAFE/DANGERが表示される。

6.  **レポート:** 生成されたPDF/テキストをカルテに添付。



## 2. Safety Check

* **違和感:** 「臨床実感と違う」と感じたら、直ちにシステム利用を中止し、従来法で診断する。

* **責任:** システムはあくまで「計算機」である。最終判断は医師が行う。



## 3. Maintenance

* **月次:** 30_Test_Data のバリデーションセットを実行し、結果が変わっていないか確認。

* **年次:** 端子接点の清掃、PCのセキュリティアップデート。
