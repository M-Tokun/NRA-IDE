# Phase 1: Philosophy Protocol (Why NRA-IDE?)



## 1. Core Concept

**「統計（占い）」ではなく「物理（計算）」で癌を制圧する。**



既存の医療AI（統計的学習）は「平均的な患者」には有効だが、「例外的な個人」には無力である。

NRA-IDEは、目の前の患者個人の物理パラメータ（硬度・粘性・圧力）を測定し、構造力学シミュレーションによって「物理的に転移不可能な条件」を算出する。



## 2. Axiom: Physics First

* **決定論的アプローチ:** 同じ入力なら、常に同じ出力（BLOCKED/PASSABLE）を返す。

* **ブラックボックスの排除:** なぜその判定になったか、全て物理式（応力比較。詳細は PHASE_2）で説明できる。

* **人命の重み:** 入力・通信・計算に異常がある場合、システムはエラーを出して `INVALID` とし、通過可否の分類を行わない（Fail-Closed）。



## 3. The Role of FPGA

なぜ汎用PCやGPUではなく、専用回路（FPGA）なのか？

* **完全な再現性:** OSの割り込みやドライバの遅延による「計算の揺らぎ」を物理的に排除するため。

* **リアルタイム保証:** 血流の拍動（〜1Hz）に遅れることなく、瞬時に判定を下すため。
