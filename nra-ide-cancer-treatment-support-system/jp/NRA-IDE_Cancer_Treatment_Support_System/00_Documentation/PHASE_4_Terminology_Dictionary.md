# Phase 4: Complete Terminology Dictionary



## 1. Parameters & Ranges (Q8.8 Fixed Point)



| Variable | Symbol | Unit | Range | Q8.8 Hex (Min-Max) | Note |
|:---|:---:|:---:|:---:|:---:|:---|
| `cell_stiffness` | $E$ | kPa | 0.1 - 10.0 | `0x0019` - `0x0A00` | **ヤング率（応力）**。ばね定数ではない |
| `cell_viscosity` | $\eta$ | Pa·s | 0.01 - 1.0 | `0x0002` - `0x0100` | **0禁止** |
| `cell_diameter` | $D$ | μm | 5.0 - 30.0 | `0x0500` - `0x1E00` | 大きさ |
| `pore_size` | $d$ | μm | 5.0 - 15.0 | `0x0500` - `0x0F00` | 隙間 |
| `flow_dp` | $\Delta P$ | kPa | 0.0 - 5.0 | `0x0000` - `0x0500` | 血圧差（駆動圧） |
| `drug_boost` | $B$ | kPa | 0.0 - 10.0 | `0x0000` - `0x0A00` | 薬剤による硬化補強分（ $E$ と同次元） |
| `deform_velocity` | $v$ | μm/s | 0.0 - 255.0 | `0x0000` - `0xFF00` | 変形速度。標準値 200.0 (`0xC800`) |



### 1.1 導出量



| 量 | 定義 | 単位 | 備考 |
|:---|:---|:---:|:---|
| 歪み | $\varepsilon = (D-d)/D$ | **無次元** | 0 ≤ ε < 1。Q0.8 で保持 |
| 弾性抵抗応力 | $\sigma_{el} = (E+B)\cdot\varepsilon$ | kPa | |
| 粘性抵抗応力 | $\sigma_{v} = 12\eta v D/(1000 d^{2})$ | kPa | 係数 1/1000 は Pa→kPa 換算 |
| 判定 | $\sigma_{el} + \sigma_{v} > \Delta P$ | – | 真なら `BLOCKED` |



### 1.2 単位に関する注意



* $E$ と $B$ は**応力**であり、これに乗じるのは歪み $\varepsilon$ （無次元）である。変位 $\Delta x$ [μm] を直接乗じてはならない（Phase 2 Rev 2.0 参照）。

* $v$ の Q8.8 表現上限は 255.99 μm/s である。毛細血管内の細胞移動速度がこれを超える条件を扱う場合、スケール変更が必要になる。

* $\sigma_{v}$ の全応力に占める割合は標準条件で約 4% である。 $v$ を測定できない運用では、システム定数 200.0 μm/s の固定使用を許容し、その旨をレポートに明記すること。

## 2. Error Codes



| Code | Name | Description | 生成元 | Action |
|:---:|:---|:---|:---:|:---|
| `0x00` | ERR_NONE | 正常（BLOCKED/PASSABLE 判定有効） | – | - |
| `0x01` | ERR_GEOMETRIC | すり抜け（ $D < d$ ） | FPGA | 手術検討 |
| `0x02` | ERR_RANGE | 入力が本表の範囲外 | FPGA / Host | 再測定 |
| `0x03` | ERR_ZERO_VISC | 粘性ゼロ（律環公理違反） | FPGA / Host | 再測定 |
| `0x04` | ERR_OVERFLOW | 演算オーバーフロー | FPGA | システム点検 |
| `0x05` | ERR_COMM | 3回再送後も応答不正 | Host のみ | 結線・電源点検 |
| `0x06` | ERR_UNSUPPORTED | 未実装の癌腫タイプ（Type B） | FPGA / Host | Type A で再評価 |

※ `0x04 ERR_OVERFLOW` について: Phase 4 の有効入力範囲内では理論最大でも
σ_total ≈ 5200（20.3 kPa）であり、16bit Q8.8（上限65535）を大きく下回るため、
正常な入力に対しては**実質的に到達不能**なエラーコードである（PHASE_6 §1.1
参照）。回路の防御的実装として残しているが、テストケースにも到達例は存在しない。



### 2.1 判定順序



複数の異常が同時に成立しうるため、FPGA 内での評価順序を次に固定する。



```text
0x03 (η = 0)  →  0x02 (範囲外)  →  0x01 (幾何)  →  正常演算
```



$\eta = 0$ は範囲外（0.01 未満）でもあるが、律環公理の明示的違反として `0x03` を優先する。



### 2.2 改訂理由（Rev 1.0 からの変更）



* `0x02` は旧版で「負の物理量」と定義されていたが、Q8.8 は符号なしであり、ホスト側 `nra_core_model.to_q88()` が負値を 0 にクランプするため**発生不能なコードだった**。「範囲外」に再定義することで、クランプ結果（0）を含めて検出可能になる。

* `0x04` はホスト側 `fpga_interface.py` が通信エラーに流用しており、辞書定義（オーバーフロー）と二重定義になっていた。通信エラーを `0x05` として分離する。

* エラーの生成元（FPGA / Host）を明示し、自己診断で期待できるコードを一意にした。

## 3. Judgement Vocabulary



| 語 | 意味 | 使用箇所 |
|:---|:---|:---|
| `BLOCKED` | 抵抗応力 > 駆動圧。細胞は隙間を通過できない | FPGA 出力 `o_is_jammed = 1` |
| `PASSABLE` | 抵抗応力 ≤ 駆動圧。細胞は変形通過しうる | FPGA 出力 `o_is_jammed = 0` |



**`SAFE` / `DANGER` は本システムの出力語彙から廃止する。** 「細胞が封鎖されている」ことと「投薬してよい」ことは別命題であり、同一語で表すと Gate Axiom（決定権は医師にある）に反する。臨床的可否の判断は、医師が `BLOCKED`/`PASSABLE` と他の所見を併せて行う。
