【重要】Rev 1.0 の記録は破棄した

旧版は F_elastic = (k + B) * (D - d) を直接 flow_dp と比較しており、
次元が閉じていなかった（応力 kPa に変位 μm を乗じていた）。
そのため F_total = 559,616 が Flow Force = 39,168 を大幅に上回り、
常に JAMMED と判定されていた。これはモデルの結論ではなく、式の誤りである。

PHASE_2 Rev 2.0 では応力比較形に改めた。応力に乗じるのは変位ではなく
歪み (D-d)/D（無次元）である。以下は改訂後の値である。
═══════════════════════════════════════════════════════════════════


入力値（Q8.8）
  細胞硬度   E   = 0x0180  (1.500 kPa)
  細胞粘性   eta = 0x000C  (0.047 Pa·s)   ※ 0.05 の切り捨て量子化
  細胞径     D   = 0x0C00  (12.000 um)
  孔径       d   = 0x0800  ( 8.000 um)
  流路圧差   dP  = 0x0099  ( 0.598 kPa)   ※ 0.6 の切り捨て量子化
  変形速度   v   = 0xC800  (200.000 um/s) ※ 下記の訂正を参照
  薬剤硬化   B   = 0x0000  ( 0.000 kPa)

  【訂正】Rev 1.0 は変形速度を 0x3200 と記し「200.0」と対応づけていたが、
          0x3200 は Q8.8 で 50.0 である。200.0 の正しい表現は 0xC800。
          同じ誤りが 10_Testbench_BruteForce.v にもあった（修正済）。

定数ROM（PHASE_6 §3）
  rom_recip[D>>6 = 48] = 5461   (1/12.0 を Q0.16)
  rom_kvisc[d>>6 = 32] = 3145   (0.012/8.0^2 を Q0.24)

パイプライン各段の値
  Stage 1  dx = D - d                    = 0x0400  (4.000 um)
  Stage 3  strain = (dx * recip) >> 16   = 85      (0.332 — 無次元)
  Stage 3  q1 = (eta*v * kvisc) >> 24    = 115     (Q0.16)
  Stage 4  sigma_el = ((E+B)*strain)>>8  = 127     (0.496 kPa)
  Stage 4  sigma_v  = (q1 * D) >> 16     = 5       (0.020 kPa)
  Stage 5  sigma_total                   = 132     (0.516 kPa)
           flow_dp                       = 153     (0.598 kPa)

判定  132 > 153 は偽  ->  PASSABLE（細胞は変形して通過しうる）

BLOCKED を成立させるのに必要な最小 Boost: +0.25 kPa

同期タイミング

  UART受信完了 (T=0)  : 14バイト目の受信完了と共に rx_valid が立ち上がり、
                        内部レジスタにパラメータがロードされる。
  計算開始   (T+1)    : calc_trigger が立ち上がり Stage 1 が開始する。
  完了       (T+6)    : 5段パイプラインを経て o_out_valid が立ち上がる。
  送信開始   (T+7)    : Top_Module が tx_start を発行し、3バイトの応答
                        （Header / (Error<<1)|Jammed / Checksum）を返す。

  ※ Rev 1.0 は「3クロック後」「判定結果 0xFF を出力」と記していたが、
     パイプラインは5段であり、応答は3バイト形式である。0xFF を返す
     プロトコルは存在しない。

  ※ 2026-07-29 に Icarus Verilog 11.0 でシミュレーション検証を実施した。
     10_Testbench_Integration.v により、14バイト送信 → 3バイト応答の全経路が
     Phase 30 の7ケースで期待値と一致することを確認済み（8/8 PASS、
     チェックサム異常時の無応答を含む）。実機ボーレート 115200 でも同結果。
     演算コア単体は 10_Testbench_TypeA_Cases.v で 7/7 PASS。

     なお合成・タイミング解析（Vivado / Quartus）は未実施である。

このロジックを再検証するための Python スクリプト

# Phase 10 Logic Verification Script (Rev 2.0)
# 20_Software_Host/nra_core_model.py と同一の演算

def verify_nra_logic():
    ROM_RECIP = [0 if n < 20 else 262144 // n for n in range(128)]
    ROM_KVISC = [0 if n < 20 else 3221225 // (n * n) for n in range(128)]

    # 入力値 (Q8.8 固定小数点)
    E = 0x0180; eta = 0x000C; D = 0x0C00
    d = 0x0800; dP = 0x0099; B = 0x0000; v = 0xC800

    # Stage 1: Geometry
    if D < d:
        print("ERR_GEOMETRIC (0x01)"); return
    dx = D - d

    # Stage 3: 歪み（無次元）と粘性係数
    strain = (dx * ROM_RECIP[D >> 6]) >> 16      # Q0.8
    q1     = ((eta * v) * ROM_KVISC[d >> 6]) >> 24  # Q0.16

    # Stage 4: 応力の各項（Q8.8）
    sigma_el = ((E + B) * strain) >> 8
    sigma_v  = (q1 * D) >> 16

    # Stage 5: 合算と比較
    total = sigma_el + sigma_v
    jammed = total > dP

    print(f"strain      (Q0.8) : {strain}  ({strain/256:.3f})")
    print(f"sigma_el    (Q8.8) : {sigma_el}  ({sigma_el/256:.3f} kPa)")
    print(f"sigma_v     (Q8.8) : {sigma_v}  ({sigma_v/256:.3f} kPa)")
    print(f"sigma_total (Q8.8) : {total}  ({total/256:.3f} kPa)")
    print(f"flow_dp     (Q8.8) : {dP}  ({dP/256:.3f} kPa)")
    print(f"Result             : {'BLOCKED' if jammed else 'PASSABLE'}")

verify_nra_logic()

  sigma_total (Q8.8) : 132  (0.516 kPa)
