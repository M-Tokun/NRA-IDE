# Jamming Map Visualization Guide



## 1. Overview



`safety_map_visualizer.py` が生成する PNG は、現在の患者の状態が**判定境界**に対してどこに位置するかを可視化する。



描画されるのは `nra_core_model.py` による**未検証モデル内の判定境界**である。実機FPGAは変形速度 $v=200$ μm/s を固定使用するため、別の $v$ を指定した図を実機結果として扱ってはならない。図は現実の細胞通過を示さない。



## 2. Axis Definitions



* **X-Axis (Horizontal): Drug Boost $B$ [kPa]**

  * 薬剤投与によって補強される細胞硬度。

  * 右へ行くほど細胞が硬くなり、通過しにくくなる。

* **Y-Axis (Vertical): Flow Pressure $\Delta P$ [kPa]**

  * 血流による推進力。

  * 上へ行くほど圧力が高まり、細胞が押し込まれやすくなる。



他のパラメータ（ $E$, $\eta$, $D$, $d$, $v$ ）は指定入力に固定される。図はその入力に対するモデル計算であり、実測・患者固有の妥当性を示さない。



## 3. Zones



| 表示 | 条件 | 物理的意味 |
|:---|:---|:---|
| 🟩 **BLOCKED** (green) | $\sigma_{resist} > \Delta P$ | モデル上の抵抗優位。現実の通過不能は未確認 |
| 🟥 **PASSABLE** (red) | $\sigma_{resist} \le \Delta P$ | モデル上の駆動圧優位。現実の通過は未確認 |



$$\sigma_{resist} = (E + B)\cdot\frac{D-d}{D} + \frac{12\,\eta\,v\,D}{1000\,d^{2}}$$



境界は $B$ について直線になる（ $\Delta P = (E+B)\varepsilon + \sigma_v$ ）。



### ⚠ 語彙について



旧版は同じ領域を `SAFE` / `DANGER` と表記していたが、**この語は廃止した。**



`BLOCKED` は「モデル上で抵抗応力が優位」であることのみを意味し、現実の封鎖や「投薬してよい」ことを意味しない。図の下部にも未検証モデルの出力である旨を表示する。



## 4. Error Display



入力異常、未実装のType B、通信異常、FPGAと参照実装の不一致では**判定図を生成しない**。レポートでは `INVALID` とエラーコードを明示し、無効な入力を `PASSABLE` の計算結果として着色しない。



| コード | 表示 | 条件 |
|:---|:---|:---|
| `0x01` | ERR_GEOMETRIC | 細胞直径 < 隙間サイズ |
| `0x02` | ERR_RANGE | 入力が Phase 4 の範囲外 |
| `0x03` | ERR_ZERO_VISC | 粘性ゼロ |



## 5. Current State Marker



黒丸＋白十字が現在の $(B, \Delta P)$ を示す。軸の端（ $B = 0$ 等）でも欠けないよう描画される。



マーカーが緑側ならモデル上で抵抗応力が優位、赤側ならモデル上で駆動圧が優位である。現実の封鎖・通過を示すものではない。赤側では `required_boost()` がモデル内の境界到達に必要な最小 $B$ を返す。



## 6. Usage



研究者はこの図から、指定した駆動圧（Y）に対するモデル内の判定境界と硬化分（X）の関係を確認できる。現実の封鎖や投与量の決定には使用しない。



> **境界近傍のマージン評価（旧 BORDER 相当）は未実装である。** 現行の出力は二値であり、境界からの距離は判定に含まれない。境界のすぐ近くにある点は、測定誤差だけで反対側へ移りうる。Q8.8 の分解能は 0.0039 kPa であり、これより小さい差は表現できない。図を読む際はこの点に留意すること。
