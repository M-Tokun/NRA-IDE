# Jamming Map Visualization Guide



## 1. Overview



`safety_map_visualizer.py` が生成する PNG は、現在の患者の状態が**判定境界**に対してどこに位置するかを可視化する。



描画される境界線は近似ではなく、**FPGA の判定境界そのもの**である。可視化は独自の式を持たず、`nra_core_model.py`（RTL のビット単位再現）だけを判定根拠とする。図と装置が食い違うことがあってはならない。



## 2. Axis Definitions



* **X-Axis (Horizontal): Drug Boost $B$ [kPa]**

  * 薬剤投与によって補強される細胞硬度。

  * 右へ行くほど細胞が硬くなり、通過しにくくなる。

* **Y-Axis (Vertical): Flow Pressure $\Delta P$ [kPa]**

  * 血流による推進力。

  * 上へ行くほど圧力が高まり、細胞が押し込まれやすくなる。



他のパラメータ（$E$, $\eta$, $D$, $d$, $v$）は当該患者の測定値に固定される。したがって本図は**その患者専用**であり、他の患者に流用してはならない。



## 3. Zones



| 表示 | 条件 | 物理的意味 |

|:---|:---|:---|

| 🟩 **BLOCKED** (green) | $\sigma_{resist} > \Delta P$ | 細胞は隙間を通過できない |

| 🟥 **PASSABLE** (red) | $\sigma_{resist} \le \Delta P$ | 細胞は変形して通過しうる |



$$\sigma_{resist} = (E + B)\cdot\frac{D-d}{D} + \frac{12\,\eta\,v\,D}{1000\,d^{2}}$$



境界は $B$ について直線になる（$\Delta P = (E+B)\varepsilon + \sigma_v$）。



### ⚠ 語彙について



旧版は同じ領域を `SAFE` / `DANGER` と表記していたが、**この語は廃止した。**



`BLOCKED` は「細胞が物理的に封鎖されている」ことのみを意味し、「投薬してよい」ことを意味しない。両者は別の命題であり、一語に畳むと計算結果が治療の許可として読まれ、Gate Axiom（決定権は医師にある）に反する。図の下部にもその旨を常時表示する。



## 4. Error Display



入力異常時は判定を行わず、**全面を PASSABLE（赤）** とし、タイトルにエラーコードを表示する。転移リスクが有る側へ倒すのが Fail-Closed の向きである。



| コード | 表示 | 条件 |

|:---|:---|:---|

| `0x01` | ERR_GEOMETRIC | 細胞直径 < 隙間サイズ |

| `0x02` | ERR_RANGE | 入力が Phase 4 の範囲外 |

| `0x03` | ERR_ZERO_VISC | 粘性ゼロ |



## 5. Current State Marker



黒丸＋白十字が現在の $(B, \Delta P)$ を示す。軸の端（$B = 0$ 等）でも欠けないよう描画される。



マーカーが緑側にあれば現状で封鎖が成立、赤側にあれば通過しうる状態である。赤側にある場合、`required_boost()` が境界到達に必要な最小 $B$ を返す。



## 6. Usage



医師はこの図から「現在の血流圧（Y）に対して、細胞を封鎖するにはどれだけの硬化（X）が必要か」を読み取る。



> **境界近傍のマージン評価（旧 BORDER 相当）は未実装である。** 現行の出力は二値であり、境界からの距離は判定に含まれない。境界のすぐ近くにある点は、測定誤差だけで反対側へ移りうる。Q8.8 の分解能は 0.0039 kPa であり、これより小さい差は表現できない。図を読む際はこの点に留意すること。
