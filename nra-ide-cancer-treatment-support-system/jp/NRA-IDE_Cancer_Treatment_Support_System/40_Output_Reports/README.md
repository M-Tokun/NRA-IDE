# Phase 40: Output Reports



## 1. Report Types

* **Text Report (.txt):** カルテ保存用。全パラメータと判定根拠を記載。

* **Safety Map (.png):** 患者説明用。現在のリスク状態を視覚化。



## 2. Interpretation Guide

* **SAFE (Green):** 物理的封鎖が成立している状態。

* **DANGER (Red):** 転移リスクが高い（細胞が通過可能）状態。

* **ERROR:** 入力値の異常（粘性ゼロなど）。



## 3. Gate Axiom Notice

レポートには必ず以下の免責事項が含まれる：

> "本システムは物理的根拠を提示するのみであり、最終的な治療方針は医師が決定する。"
