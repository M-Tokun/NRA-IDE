## 2. Interpretation Guide



| 表示 | 意味 |

|:---|:---|

| **BLOCKED** (green) | 抵抗応力が駆動圧を上回り、細胞は隙間を通過できない |

| **PASSABLE** (red) | 細胞は変形して通過しうる（転移経路が開いている） |

| **INVALID / ERROR** | 入力値または通信の異常。判定は行われていない |



### ⚠ SAFE / DANGER の廃止



旧版は BLOCKED を `SAFE`、PASSABLE を `DANGER` と表記していたが、**この語は廃止した。**



`BLOCKED` は「細胞が物理的に封鎖されている」ことのみを意味し、「投薬してよい」ことを意味しない。両者は別の命題である。さらに旧 README（ルート）では同じ不等式を薬剤到達の文脈で用い、`抵抗 > 圧力` を `DANGER` と逆向きに表記していた。同一の式に反対の意味のラベルが付いていたため、語彙ごと置き換えた。



## 3. 判定根拠の記載義務



テキストレポートには `[Computation]` 節（歪み・弾性応力・粘性応力・合計・駆動圧）を必ず含める。判定の根拠を示さないレポートは Physics First（ブラックボックスの排除）に反する。



入力値は **Q8.8 量子化後の値**を表示する。入力した 0.05 が 0.047 と表示されることがあるが、これは誤りではなく、装置が実際に用いた値である。



## 4. 検証層



FPGA から得た判定と参照実装（`nra_core_model.py`）の判定が食い違った場合、レポートに `[!] DISCREPANCY` 節が出力される。この節があるレポートを臨床判断に用いてはならない。



## 5. 来歴表記 — 配布テンプレートゆえの要件



**本リポジトリは配布テンプレートである。** 生成されたレポートはリポジトリから切り離されて単独で流通する。カルテに添付され、転送され、印刷される。その時点で README も Phase 文書も付いてこない。



したがって成果物は**紙1枚で自己完結**していなければならない。全てのレポートに `[Provenance]` 節を出力する。



| 欄 | 内容 |

|:---|:---|

| `Model` | どの物理モデル・どの版で計算したか |

| `Validation` | 実験検証を経ているか。現在は **未検証**（マイクロ流路試験プロトコル 未実施） |

| `Source` | FPGA / 参照実装 / バリデータ却下 のいずれで判定したか |

| `Template` | 本テンプレートの名称と所在 |



定義元は `20_Software_Host/nra_core_model.py` の定数である。



### 5.1 なぜ必要か



1. **数値の桁数は精度の印象を作る。** 「0.516 kPa」と書かれた紙は、研究用途と断ってあっても根拠のある値として読まれる。実測値ではなくモデルの計算結果であることを、数値と同じ紙面で述べなければならない。

2. **フォークが権威の器を継承する。** 物理式を差し替えても、見出しと `[Computation]` の体裁はそのまま残る。テンプレートは任意の中身に権威の足場を貸してしまう。だから成果物自身が自らを名乗る必要がある。

3. **ライセンスが要求している。** `LICENSE_JP.txt` は、著作権表示・特約事項・許諾表示を「本テンプレートのすべての複製または重要な部分」に記載することを求めている。生成物はテンプレートの重要な部分を具現化したものである。

4. **SOUP 宣言が下流に義務を課している。** 特約事項2 により、利用者は自身の責任で V&V・リスク管理・規制申請を行う義務を負う。この義務の前提は「上流で V&V が行われていない」ことであり、それをレポートが明示しなければ、下流は自分の義務を判断できない。



### 5.2 改変して配布する者への指示



* 物理式を改変した場合、`MODEL_VERSION` を必ず変更すること

* 実験検証を経ていない状態で `VALIDATION_STATUS` を書き換えてはならない

* `[Physician's Gate]` 節の著作権・ライセンス表示を削除してはならない



詳細は `NRA_IDE_Report_Template.txt` 末尾を参照。



## 6. Gate Axiom Notice

>

> 表示された数値は物理モデルの計算結果であり、実測値ではない。

> 本モデルは実験による検証を経ていない。

> 本テンプレートは薬機法上の医療機器ではなく、研究・教育目的に限る。

> IEC 62304 の文脈では SOUP（由来不明ソフトウェア）に分類される。

> 医療機器開発に用いる場合、V&V・リスク管理・規制申請は利用者の責任に属する。
