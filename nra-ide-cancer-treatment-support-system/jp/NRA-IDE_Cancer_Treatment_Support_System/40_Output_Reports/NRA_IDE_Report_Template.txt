【本テンプレートについて】

* 生成元: 20_Software_Host/clinical_report_generator.py
* 来歴表記の定義元: 20_Software_Host/nra_core_model.py
* 実際の出力例: NRA_IDE_Report_Sample.txt（コードで生成した実物）


■ 書式の約束

* 入力値は Q8.8 量子化後の値を表示する。判定はこの値で行われるため、
  入力した 0.05 が 0.047 と表示されることがある。これは誤りではなく、
  装置が実際に用いた値である。
* [Computation] 節は必須である。判定の根拠を示さないレポートは
  Physics First（ブラックボックスの排除）に反する。
* エラー時は [Computation] と [Reference] を出力せず、判定を INVALID とする。
* [Provenance] 節と [Physician's Gate] 節は、どの経路でも必ず出力する。


■ 本テンプレートを改変して配布する者への指示

本レポートはリポジトリから切り離され、単独で流通する。カルテに添付され、
転送され、印刷される。その時点で README も Phase 文書も付いてこない。
したがって、成果物は紙1枚で自己完結していなければならない。

1. 物理式を改変した場合、nra_core_model.py の MODEL_VERSION を必ず変更する。
   変更しなければ、改変版が本テンプレートの検証状態を騙ることになる。

2. 実験検証を経ていない状態で VALIDATION_STATUS を書き換えてはならない。
   検証が完了した時点で、その旨と実施日・一致率をこの欄に記す。
   検証手続きは 検証プロトコル_マイクロ流路試験.md に定めてある。

3. [Physician's Gate] 節の著作権表示・ライセンス表示を削除してはならない。
   LICENSE_JP.txt は、著作権表示・特約事項・許諾表示を「本テンプレートの
   すべての複製または重要な部分」に記載することを求めている。

4. レポートの見出しと [Computation] の体裁は、内容に権威の外観を与える。
   中身を差し替えたまま体裁だけを流用すると、根拠のない数値が根拠ある
   ものとして読まれる。改変時は Model 欄で自らを名乗ること。
