01 — 根幹定義式（不変）
R = δ / τ
δ 蓄積ズレ
Accumulated Deviation
累積負荷・履歴として蓄積
τ 吸収厚み
Absorption Thickness
構造的許容余裕・時間と独立
R 構造比率
Structural Ratio
境界への接近度・無次元
R < 1.0 → 安定領域・継続  │  R = 1.0 → 警告・通知  │  R ≥ 1.0 → Fail-Closed 沈黙・人間に委ねる

▸ 「内側が揺らいで吸収する」ゼリー構造。
▸ 主導権はここにある。 古典層が沈黙しても継続する。

03 — NRA-IDE 公理との対応
公理 応用式での実現
距離は結果であって原因ではない r は応答の結果として計算される。直接入力として使わない。F_IDE が根本を保持する。
閾値での正直な告白 G(r) が小さいとき古典層は沈黙する。介入していない事実を隠さない。
不可逆性への敬意 速度ẋを経由した連続更新。状態の直接上書き禁止。遷移を崩さない。
整数位相ロック 各ステップで残差を排出（熱として）。持ち越し禁止。各遷移が構造的に完結する。
Fail-Closed R ≥ 1.0 で出力を停止。G(r) も F_IDE も判断しない。人間に委ねる。
04 — なぜ根本は崩れないのか Why the Foundation Holds
✗ 古典計算が「主導」した場合
前ステップの自分の出力が次の入力になる。
誤差が雪だるま式に蓄積する。
大規模・非線形系で計算爆発する。
概要（全体像）を失ってから破綻に気づく。
✓ IDE層が「根本を保持」した場合
古典層の入力は「IDEが安定させた現在状態」。
誤差爆発が防がれる決定的な理由がここにある。
古典層はズレだけを計算して力として返す。
概要（全体像）を常時追跡し続けられる。
古典計算の入力が「自分の前の出力」ではなく「IDEが安定させた現在状態」である点が
誤差爆発を防ぐ構造的・決定的な違いである。
