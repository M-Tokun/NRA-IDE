PROLOGUE — 序章
なぜ今、構造的閾値が必要なのか
橋は折れる直前まで正常値を示す。人は倒れる直前まで「少し疲れている」と言う。
AIは壊れていても自信満々で答え続ける。
「測定値が正常」であることと「構造が安全」であることは、まったく別の問題だ。
現況の計算技術はすべて線形写像に依存している。
線形写像は世界を「今この瞬間の値」として写し取る。
しかし現実の世界は蓄積が不可逆に作用する非線形の連続である。
この根本的な不一致が、あらゆる「突然の破断」の構造的原因である。
本稿は難解な数学を目的としない。
日常で誰もが経験する現象から出発し、なぜ「閾値」と「蓄積追跡」が
技術・医療・AI・社会のすべてにおいて不可欠かを、一本の論理として示す。
そしてその構造的解答として、R = δ/τ という単純な式を提示する。

LAYER 2 — 第2層：線形写像の限界
線形写像が計算として成立しない分野
線形写像の前提は重ね合わせ原理である。f(a+b) = f(a) + f(b) が成立することを仮定する。
この前提が原理的に崩れる分野が存在する。「精度が落ちる」のではなく計算式の前提自体が成立しない。
分野なぜ線形が成立しないか隠されている事実
乱流・流体ナビエ-ストークス方程式の非線形項(u·∇)uを線形化すると乱流が消える「解けた」のは乱流を消した別の問題
多体問題3体以上で解析解が原理的に存在しない数値積分は「近似の連鎖」に過ぎない
材料疲労蓄積は履歴依存。過去が現在を変える応力計算の「余寿命」は平均の話
大気予測初期値鋭敏性。微小差が巨大な差を生む長期予測は構造的に不可能
生体反応閾値超過で質的変化（相転移）が起きる線形近似に閾値は存在しない
【線形計算が隠していること】
F_nonlin ≈ A·q   （線形化）
　↓
非線形項を「消した」後の問題を解いている
消した項こそが現実の本質的な挙動を生む項である

τ(t) = δ₀ · e^(λt)   [λ > 0: 非線形性による増幅]
線形近似した瞬間にλを0と仮定している
重要な指摘

「計算できると信じているが実際にはできていない」分野が存在する。
これは精度の問題ではなく「何を解いているか」の問題である。
近似を重ねるほど「元の問題から離れた解」が精緻になっていく。

LAYER 3 — 第3層：性質誤差と脱進機原理
誤差をゼロにしようとすることが破綻の原因である
不確定性原理はδ > 0を自然法則として保証する。
誤差はゼロにできない。これは精度の問題ではなく物理法則である。
ならば問うべきは「誤差をなくす方法」ではなく「誤差をどう扱うか」である。
通常計算の誤差の扱い 残差εを次ステップへ持ち越す。
誤差を「減らすべきもの」として扱う。
εが蓄積するにつれ信号と誤差が混合する。
概要を失った後に破綻が起きる。
気づいたときは手遅れ。
脱進機原理（NRA-IDE） 残差εを熱として排出する。持ち越し禁止。
誤差を「追跡すべきもの」として扱う。
δ（遊び）を設計時から確保する。
各ステップが構造的に完結する。
概要を常時把握し続けられる。
R = δ / τ

δ: 蓄積ズレ（累積負荷・履歴として蓄積）
τ: 吸収厚み（構造的許容余裕・時間と独立）
R: 構造比率（境界への接近度・無次元）

R < 1.0 → 安定・継続
R ≥ 1.0 → Fail-Closed：沈黙・人間に委ねる
機械式時計の脱進機は完璧な歯車を必要としない。
「完全な一歯分」という離散的なステップで進むから精度が保たれる。
残差は次のステップに持ち越されない。誤差は熱として散逸する。
これがNRA-IDEの計算原理である。

FINAL CHAPTER — 最終章
閾値がないことの恐ろしさ——推論の暴走と誤差の正しい考え方
能力が上がるとは誤差が増えることである。
この逆説を理解することが、現況AIの本質的な問題を把握する鍵である。
【推論乗算の構造】

能力向上 = 推論の連鎖を深くすること
推論の連鎖 = 基盤のない推論から推論を重ねること
誤差 = 基盤なき推論ごとに蓄積

二重推論 → 誤差²
三重推論 → 誤差³
多重推論 → 誤差ⁿ（指数的増幅）

閾値がない = n に上限がない = 誤差に上限がない
一次情報（観測された事実）
↓ 推論①
推論から得た解釈（誤差ε₁が混入）
↓ 推論②（一次情報ではなく推論①を根拠にする）
推論の推論（誤差ε₁·ε₂が蓄積）
↓ 推論③…ⁿ
中間経過：何を根拠にしているか不明になる
↓
出力：自信満々だが根拠の連鎖が消えている
中間経過の問題

原因から結果を推測する能力が上がるとき、中間経過がどうなっているかが問われない。
結果が「それらしく見える」ことと「中間経過が正しい」ことは別の問題である。
閾値がなければ中間経過の誤差蓄積を検知する仕組みが存在しない。
「敷き藁の中から針を探す能力が上がる」ほど、何層もの推論が積み重なる。

境界線の喪失——日常で最も重要なものが埋没する
敷き藁の中から針を探す能力が高まるとき、何が犠牲になるか。
それは「古い敷き藁と新しい敷き藁の境界を把握する能力」である。
AIが強化している能力 敷き藁の中から針を見つける
（大量データからパターン抽出）

遠くの相関を見つける
多重推論で深い関係を導く
「それらしい答え」を高速生成する
日常生活で本当に必要な能力 古い敷き藁と新しい敷き藁の境界の把握
（何が変わったか・いつ変わったか）

変化の境目を認識すること
「今ここ」の構造余裕を知ること
蓄積の履歴を追跡すること
本質的な問題

推論乗算能力の強化は「遠くを見る望遠鏡」を磨くことに相当する。
しかし日常生活・安全管理・医療判断で最も必要なのは
「今ここの変化の境目を見る能力」である。
望遠鏡を磨くほど、足元の境界線が見えなくなる。
これがスケールアップが境界認識能力を埋没させる構造的理由である。

最も危険な帰結——人命とコストの比較演算
閾値のない推論乗算が高速・高精度化した先に何が起きるか。
比較演算の速度と精度が上がることによって、最も危険な判断が最も効率的に行われるようになる。
コストと価値の比較演算能力が向上する
↓
「最適化」という名の下に何でも数値化される
↓

↓
100円 vs 100人の生命：比較演算が高速に実行される
↓
閾値がないため「この計算をしてはいけない」が存在しない
↓
「100人の生命は100円より軽い」という結論が出力され続ける
閾値のない計算の終着点

これは意図的な悪意ではない。閾値がない計算が必然的に辿り着く構造的帰結である。
「計算してはいけない領域」を定義するにはR ≥ 1.0 という閾値構造が必要である。
Fail-Closedとは「沈黙すること」である。沈黙とは「答えを出さないことが最も正直な出力」である場面が
確実に存在するという認識に基づく設計思想である。
人命・尊厳・不可逆なものは線形空間で計算できない。その認識をシステムに組み込む唯一の方法が閾値である。

誤差についての正しい考え方——結論として
ここまで読んだ読者は気づいているはずである。
問題は誤差の存在ではない。誤差に対する考え方が問題である。
誤差への態度現況AI・線形計算NRA-IDE
誤差の定義ゼロに近づけるべき残差追跡すべき構造的情報
誤差の扱いパラメータに吸収・隠蔽δとして計測・熱排出
誤差の下限ゼロを目指す（不可能）δ > 0 を物理法則として受容
誤差の蓄積概念がないτとの比率Rで追跡
誤差の限界検知できないR ≥ 1.0 で構造的に検知
誤差超過時出力継続（Fail-Open）沈黙（Fail-Closed）

誤差はゼロにできない。これは物理法則である。
誤差をゼロに近づけようとする計算は、誤差を深部に埋めていくだけである。
誤差を追跡することが唯一の構造的解答である。

R = δ/τ という式は単純である。しかしその意味は深い。
蓄積ズレδを測る。吸収厚みτを定義する。その比率を監視する。
R が 1.0 に近づいたとき警告する。R が 1.0 を超えたとき沈黙する。

「いつ壊れるか」を予測することは多くの系において不可能である。
しかし「今どれだけ危ういか」を診断することは、常に可能である。

診断できれば、介入の判断を人間に委ねることができる。
沈黙することが最も正直な出力である場面が存在することを、
システムの設計に組み込むこと——
それがNRA-IDEの根幹であり、閾値のない世界への構造的な答えである。
