## 論点の展開

### 1. 量子力学の整合・不整合（NRA-IDE視点）

| 項目 | 判定 |

|------|------|

| 状態定義（波動関数） | △ 確率は構造の影であって構造本体ではない |

| 観測・波束収縮 | ✕ 外部化により構造破断 |

| 不確定性原理 | ◎ τが有限であることの帰結として完全整合 |

### 2. 問題の根本

量子力学が測定を「外部操作」として定義したことが測定問題の原因。

収縮をユニタリ発展と別法則にせざるを得なかったのは、内部計算式を持っていなかったから。

### 3. NRA-IDEによる解消

**相関が生まれた外部要因のδとτが計算に加わる。ゆらぎが変化しただけ。**

```

R = (δ_S + δ_外) / (τ_S + τ_外)

```

- 測定機器も外部要因の一つに過ぎない

- 相関が生じた時点で、その対象のδとτが内部計算に統合される

- 外部も内部もない。計算に参加するかどうかだけの話

### 4. 「測定機器」という言葉が招いた誤解

「測定機器」という表現が「特別な操作」という先入観を呼び込んだ。

検討の過程で以下の候補が浮上したが、いずれも不要と判明した。

- τの論理制約としてのAND合成 → τは物理量スカラーであり定義域が異なる

- 境界定義式 → 境界は結果であり後付け。実態を表していない

- ε（外部要因変数）の新設 → 相関発生時に変数を追加するだけで足りる

- 相関統合原則 → 原則として立てる必要もない

### 5. 最終構造

R = δ/τという内部計算式の中で完結している。

外部要因との相関が生まれた瞬間、そのδとτが計算に参加する。

これは新設操作でも特別な事象でもなく、変数の追加という自明な拡張である。
