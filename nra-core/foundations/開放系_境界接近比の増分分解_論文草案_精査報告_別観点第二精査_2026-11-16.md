## 3. 第一視点：意味、ドメイン、正典上の整合性

論文草案の核心（式3・式4・式5）は、一次式 $R=\\delta/\\tau$ と `FORMULA.md` §0.5, §4.7 の定義のみから導かれる代数恒等式であり、新たな仮定を一切追加していない。これは論文草案 §0・§28 が主張する位置付けと一致する。

- **式3（増分4経路分解）**：`FORMULA.md` §4.7 の一次式増分分解 $\\frac{\\Delta\\delta_n}{\\tau_n}+\\delta_{n-1}\\bigl(\\frac{1}{\\tau_n}-\\frac{1}{\\tau_{n-1}}\\bigr)$ に $\\Delta\\delta_n=\\Delta q_n+\\Delta p_n$ と $\\delta_{n-1}\\bigl(\\tfrac{1}{\\tau_n}-\\tfrac{1}{\\tau_{n-1}}\\bigr)=R_{n-1}\\tfrac{-\\Delta\\tau_n}{\\tau_n}$ を代入し、$\Delta\\tau_n$ を劣化分・構成変化分に二分したもの。第4項（構成変化項）のマイナス符号は正しく、検算スクリプトと一致。
- **式4（戻る分と戻らない分）**：$R_n = q_n/\\tau_n + p_n/\\tau_n$。$p_n$ は減らず、$\\tau_n$ は付加がない限り増えないので $R_{\\mathrm{res},n}$ は構造要素の付加がない限り減らない。正典整合。
- **式5（閾値余白）**：$m_{\\theta,n}=\\theta\\tau_n-\\delta_n$。$R_{n+1}\\ge\\theta \\iff \\Delta\\delta_{n+1}-\\theta\\Delta\\tau_{n+1}\\ge m_{\\theta,n}$ の同値は $\\tau_{n+1}>0$ の下で厳密に導出可能。$\\theta=1$ では $m_{1,n}=M_\\tau$（残存吸収余白、`FORMULA.md` §2）と一致。正典整合。
- **$q^{\\mathrm{temp}}_n$（一時的な可逆成分）**：AXIOMS §7 解釈境界コメント・FORMULA §0.5.3・辞書「一時的な可逆成分」によれば、実効厚みから差し引かず、ズレの側（$a_n\\to q_n$）に計上する。論文草案 §3.1 L81 ではこの明示が省略されている。
- **不可逆ラッチと閾値余白**：$m_{\\theta,n}\\le0 \\iff R_n\\ge\\theta$ は代数的に正確（論文草案 L165）。ただし、一度 $R_{\\mathrm{irrev}}$ に達してラッチ $\\ell_n=1$ が掛かった後、$R_n$ が下がって $m_{R_{\\mathrm{irrev}},n}>0$ になってもラッチは自動解除されず正規状態は `IRREVERSIBLE_TRANSITION` のまま保持される（AXIOMS §10.4）。この区別の明示が不足。
- **$R_{n-1}=0$ の境界ケース**：劣化縮小項 $R_{n-1}(-\\Delta\\tau^{\\mathrm{deg}}_n)/\\tau_n$ は $0$ になり、器の縮小は分母 $\\tau_n$ と $m_{\\theta,n}$ の減少に現れる。未記載。
- **「述べないこと」（§7）**：不可逆遷移や破断の予測、宣言間での $R$ 比較、宣言した破断様式以外の壊れ方への備え、単一の式による自然現象記述を明示していないことは、AXIOMS §14 逆導出 B・FORMULA §0 と整合し、誤用防止として適切。

### 5.1 視角A：「不明」の置き場所（§4）と式3〜5の認識論的整合性

#### 比較ポイントと代数経過

論文草案 §4 は「不明」を4つの置き場所に分ける。

| 状況 | 扱い | 式との関係 |
|---|---|---|
| 事象が起こり、観測された | $\\mathrm{Ev}_n$ として式2へ入り、式3の四経路に計上される | 予見の有無は計上に影響しない |
| 観測チャネルから値が得られない | `NOT_OBSERVABLE` と欠損理由を出す。0・安定・安全で埋めない | $R_n$ は最後に観測できた更新までの値であると開示する |
| 対象・単位・時点・出所が不明 | `CONFESSION` とし、一次式へ入力しない | 影響する評価を止める |
| まだ起こっていない | 式に項を置かない | 式5の閾値余白が、受けられる大きさを示す |

#### 認識論的問題の因果経路

**問題A-1：「まだ起こっていない」事象と式5の関係**

論文草案 §4 の4行目では「まだ起こっていない → 式に項を置かない → 式5の閾値余白が、受けられる大きさを示す」と述べている。これは論文草案要旨3の「次の事象がどの大きさなら各閾値へ達するかは、現在の $\\delta$ と $\\tau$ だけで決まる（式5）。事象を予測せずに、受けられる大きさを示せる」と整合する。

しかし、式5b を代数展開すると：
$$R_{n+1}\\ge\\theta \\iff \\Delta\\delta_{n+1}-\\theta\\Delta\\tau_{n+1}\\ge m_{\\theta,n}$$
これは「次ステップの $\\Delta\\delta,\\Delta\\tau$ がどうあれば閾値に達するか」の**同値式**に過ぎない。現場の評価者はこれを「次の事象の大きさの予測」と暗黙に読み替えるリスクがある。論文草案 §7 では「不可逆遷移や破断がいつ起こるかの予測」を述べないと明記しているが、式5の提示方法だけでは「予測をしない」ことが十分に伝わらない。

**誤読の因果経路**：
1. 評価者が式5を読む → 「次の事象がどの大きさなら各閾値へ達するか」と理解
2. 「まだ起こっていない」事象について「式5で受けられる大きさを示す」と読む
3. 暗黙に「次にこれくらいの事象が来たら危険」という予測を抱く
4. これが「不可逆遷移や破断がいつ起こるかの予測」と矛盾する認識を生む

この誤読を防ぐには、式5が「次ステップの $\\Delta\\delta,\\Delta\\tau$ の組に対する同値条件」に過ぎず、事象そのものの大きさや発生時刻を予測するものではないことを、§4 または §3.5 で明示的に補足する必要がある。

**問題A-2：`NOT_OBSERVABLE` の場合の $R_n$ の整合性**

論文草案 §4 の2行目では「観測チャネルから値が得られない → `NOT_OBSERVABLE` と欠損理由を出す。$R_n$ は最後に観測できた更新までの値であると開示する」と述べている。

一次式 $R_n=\\delta_n/\\tau_n$ は $n$ 時点で定義される。観測不能の場合、$\\delta_n,\\tau_n$ が得られないので $R_n$ 自体を計算できない。「最後に観測できた更新までの値」とは、$R_{n-k}$（$k>0$）を指すのか、それとも $R_n$ を保持し続けるのかが不明確。辞書「NOT_OBSERVABLE」（AXIOMS §10.2, §11.1, §11.2）では「出所とともに欠損理由を出す。0・安定・安全で埋めない」とあるが、$R$ の開示方法までは規定していない。

**誤読の因果経路**：
1. 評価者が「$R_n$ は最後に観測できた更新までの値であると開示する」を読む
2. $R_n$ が更新停止しても最後の値を保持し続けると誤解
3. 実際には $\\delta_n,\\tau_n$ が得られないので $R_n$ は未定義だが、評価継続時に古い $R$ を使ってしまう
4. 式3〜5 の適用で古い $\\delta,\\tau$ を用い、誤った閾値余白を算出

#### 視角Aの結論
§4 の「不明の置き場所」は設計として優れているが、式3〜5との認識論的整合性（式5が予測ではないこと、`NOT_OBSERVABLE` 時の $R_n$ の扱い）について、現場の誤読リスクを防ぐ補足が不足。

### 5.2 視角B：$R_{\\mathrm{rev}}/R_{\\mathrm{res}}$ と不可逆ラッチ $\\ell_n$ の関係（止めても戻らない判断）

#### 比較ポイントと代数経過

論文草案 §3.4（式4）では：
$$R_n=\\underbrace{\\frac{q_n}{\\tau_n}}_{R_{\\mathrm{rev},n}}+\\underbrace{\\frac{p_n}{\\tau_n}}_{R_{\\mathrm{res},n}},\\qquad R_n\\ \\ge\\ R_{\\mathrm{res},n}$$
$R_{\\mathrm{res},n}$ は「いま作用をすべて除いたとしても残る接近分」。$p_n$ は減らず、$\\tau_n$ は付加がない限り増えないので、$R_{\\mathrm{res},n}$ は構造要素の付加がない限り減らない。

一方、不可逆ラッチ $\\ell_n$ は AXIOMS §10.4 で：
$$\\ell_n=\\ell_{n-1}\\lor\\mathbf{1}\\{R_n\\ge R_{\\mathrm{irrev}}\\}$$
一度 $R_{\\mathrm{irrev}}$ に達したら自動解除されず、正規状態は `IRREVERSIBLE_TRANSITION` のまま保持される。

#### 認識論的問題の因果経路

論文草案 §3.4 L141 は「$R_{\\mathrm{res},n}$ は構造要素の付加がない限り減らない」と述べる。しかし、式3の第4項（構成変化項）は $-R_{n-1}\\Delta\\tau^{\\mathrm{comp}}_n/\\tau_n$ であり、構造要素の付加（$\Delta\\tau^{\\mathrm{comp}}_n>0$）により $R$ は下がる。このとき $R_{\\mathrm{res},n}=p_n/\\tau_n$ も $\\tau_n$ の増加により**減少する**（$p_n$ は不変でも分母が増えるため）。

つまり「$R_{\\mathrm{res},n}$ は構造要素の付加がない限り減らない」という記述は、厳密には「$p_n$ 自体は減らない」ことを意味し、「$R_{\\mathrm{res},n}=p_n/\\tau_n$ は構造要素付加で減りうる」という区別が不明確。

さらに深刻なのは、ラッチ $\\ell_n=1$ の状態で $R_n$ が $R_{\\mathrm{irrev}}$ 以下に下がった場合：
- $m_{R_{\\mathrm{irrev}},n}=R_{\\mathrm{irrev}}\\tau_n-\\delta_n>0$（閾値余白は正）
- しかし $\\ell_n=1$ は解除されず、正規状態は `IRREVERSIBLE_TRANSITION` のまま

評価者が「$R_{\\mathrm{res}}$ が下がった／$m_{\\theta,n}>0$ になったので安全になった」と誤読し、ラッチの存在を忘れるリスクがある。

**誤読の因果経路**：
1. 評価者が式4と式5を併記して読む
2. 「$R_{\\mathrm{res}}$ が下がった」「$m_{\\theta,n}>0$」を「安全に戻った」と解釈
3. 不可逆ラッチ $\\ell_n=1$ の存在を忘れる、または「ラッチは $R$ の値で自動制御される」と誤解
4. 実際にはラッチは解除されず、評価状態は `IRREVERSIBLE_TRANSITION` のまま

#### 視角Bの結論
式4の $R_{\\mathrm{res},n}$ の「減らない」性質と、構造要素付加による $R_{\\mathrm{res},n}$ の実際の減少（$\\tau_n$ 増加による）との区別、および $m_{\\theta,n}>0$ でもラッチが解除されないこと（AXIOMS §10.4）の明示が不足。現場で「戻った」と誤認するリスク。

### 5.3 視角C：式5の閾値余白の運用上の落とし穴（$\\Delta\\tau<0$ の場合）

#### 比較ポイントと代数経過

論文草案 §3.5（式5b）では：
$$R_{n+1}\\ge\\theta \\iff \\Delta\\delta_{n+1}-\\theta\\Delta\\tau_{n+1}\\ge m_{\\theta,n}$$
左辺の $-\\theta\\Delta\\tau_{n+1}$ は「厚みの減少が $\\theta$ 倍の重みで効く」ことを示す（論文草案 L167）。

$m_{\\theta,n}=\\theta\\tau_n-\\delta_n$ は「現在の $\\delta_n,\\tau_n$ に基づく閾値余白」であり、$m_{\\theta,n}>0$ は「現時点で $R_n<\\theta$」を意味する。

しかし、$\\Delta\\tau_{n+1}<0$（厚みが減る、劣化など）の場合、$-\\theta\\Delta\\tau_{n+1}>0$ となり、左辺が増える。つまり「厚みが減るほど、同じ $\\Delta\\delta$ でも閾値に達しやすくなる」。

#### 認識論的問題の因果経路

論文草案 §3.5 は「起こった事象が $\\delta$ をどれだけ増やし $\\tau$ をどれだけ減らせば各閾値へ届くかを、現在の観測値だけから述べる」と述べており、これは代数的に正確。しかし、現場の評価者は「$m_{\\theta,n}>0$ だからまだ余裕がある」と判断しがち。

実際には：
- 次イベントで劣化（$\Delta\\tau^{\\mathrm{deg}}<0$）が起きれば、$\\tau$ が減少し、$-\\theta\\Delta\\tau>0$ となり、$m_{\\theta,n}$ を上回って閾値に達しうる
- $m_{\\theta,n}$ は「現時点での余白」であり、「次ステップの劣化分を考慮した余白」ではない

**誤読の因果経路**：
1. 評価者が式5と $m_{\\theta,n}>0$ を読む
2. 「閾値余白が正なので安全」と判断
3. 次イベントで劣化（$\\Delta\\tau<0$）が発生し、$-\\theta\\Delta\\tau>0$ により左辺が増加
4. $m_{\\theta,n}$ を上回り、閾値に達する（$R_{n+1}\\ge\\theta$）
5. 「余白があったのになぜ閾値に達したのか」という混乱と、対応の遅れ

#### 視角Cの結論
式5は「現在の観測値だけから述べる」と明記しているが、次ステップの $\\Delta\\tau<0$（厚み減少）が $m_{\\theta,n}$ を食いつぶす仕組みについて、運用上の説明が不足。現場で「余白がある=安全」と誤読するリスク。
