## 第2章：普遍的構造

---

### 2.0 この章の目的

本章では、スケールの異なる四つの自然現象を観察する。

目的は一つである——それらが同一の構造原理で記述できることを示すことだ。

数式は次章で与える。ここでは観察のみを行う。

### 2.1 地震——地球スケールの構造管理

**観察**

プレートは動き続ける。その動きは止まらない。

しかし二つのプレートが接する断層では、摩擦によって動きが一時的に止まる。

動こうとする力は消えない。断層の内部に静かに蓄積されていく。

この蓄積には限界がある。断層が持つ構造的な摩擦限界——それを超えた瞬間、

蓄積されたエネルギーは一気に解放される。地震である。

地震の後、断層はリセットされ、次のサイクルが始まる。

**構造の対応**

```

δ（蓄積偏差）= プレート運動による応力蓄積量

τ（許容幅）  = 断層の構造的摩擦限界

位相跳躍    = 地震（瞬間的エネルギー解放・リセット）

```

**注目すべき点**

地震は「異常」ではない。

蓄積が限界に達したときの構造的な必然である。

地球はこのサイクルを40億年繰り返している。崩壊ではなく、維持である。

### 2.2 骨の疲労骨折——見えない蓄積

**観察**

ランナーが毎日走る。一回の走行で骨が折れることはない。

しかし骨の内部では、走るたびに微細な亀裂が蓄積されている。

これは目に見えない。痛みもない。構造の内部で静かに進む。

ある日、走り始めた直後に骨折する。

その日の走行は昨日と何も変わらない。

しかし蓄積が構造の許容限界を超えていた。

**構造の対応**

```

δ（蓄積偏差）= 微細亀裂の累積量（走行ごとに増加）

τ（許容幅）  = 骨の構造的強度（疲労で徐々に縮小する）

位相跳躍    = 疲労骨折（突然の構造破断）

```

**注目すべき点**

破断は「突然」に見える。しかし突然ではない。

蓄積のプロセスは一貫して進んでいた。見えなかっただけである。

構造の状態は、表面上の静けさとは独立して変化し続ける。

静かであることは、安全であることを意味しない。

### 2.3a 水の沸騰——位相跳躍の基本形

**観察**

水を加熱する。温度は上昇する。

しかし水は「少しずつ気体になる」のではない。

99℃では液体のままである。100℃に達した瞬間、沸騰が始まる。

液体から気体への転換は連続的ではない。

蓄積された熱エネルギーが構造的な限界に達した瞬間に起きる、

離散的な状態遷移である。

**構造の対応**

```

δ（蓄積偏差）= 加えられた熱量の蓄積

τ（許容幅）  = 液体構造が維持できる限界温度

位相跳躍    = 沸騰（液体→気体・相転移）

残差の排出  = 蒸気として熱が外部へ放出される

```

**注目すべき点**

物理学はこの現象を「相転移」と呼び、長く研究してきた。

しかしその構造原理を一般式として記述する試みは、これまでなかった。

### 2.3b 凍結と融解——閾値の非対称性

水と氷の関係性は初等教育では「0℃を境に凍る・溶ける」と

可逆的に教えられることが多い。

しかし実際には、凍結と融解は対称的な現象ではない。

融解は、外部から加えられた熱エネルギーによって氷の結晶格子が壊され、

分子の運動が自由になる方向へ進む。

これはエントロピーが増大する過程であり、既存の構造が崩れていく現象である。

一方、凝固は液体中の水分子が無秩序な状態から特定の幾何学的配置をとり、

結晶格子を形成する過程である。

これは新しい秩序構造が生まれる現象であり、融解とは異なる物理的メカニズムに基づいている。

また、凝固には核生成という過程が必要であり、

十分な核が形成されない場合には水は0℃を下回っても凍らず、

過冷却状態になることがある。

これに対して、融解では氷の表面から格子が壊れ始めるため、

過熱された氷が存在することは通常ない。

このように、凍結と融解は「0℃を境に可逆的に切り替わる」単純な現象ではなく、

それぞれ独立した非対称なプロセスとして理解する必要がある。

**構造の対応**

```

融解（上方向）:

  δ = 加えられた熱エネルギー

  τ = 格子構造の崩壊限界（急峻・明確）

  → 閾値に達すれば必ず起きる

凝固（下方向）:

  δ = 除去された熱エネルギー

  τ = 核生成に必要な条件（遅延あり・不確定）

  → 同じ温度でも起きない場合がある

```

**核心**

自然界の閾値は、本質的に非対称である。

上方向と下方向に、同じ値を使うことはできない。

これは例外ではない。原則である。

---

### 2.4 睡眠圧——行動スケールの強制移行

**観察**

人は起きている間、アデノシンという物質が脳内に蓄積される。

覚醒時間が長くなるほど蓄積量は増える。眠気はこの蓄積の表れである。

ある限界を超えると、人間は意識的に覚醒を維持できなくなる。

眠ることを「選ぶ」のではない。構造が強制的に移行させる。

睡眠中、アデノシンは分解・排出される。朝、リセットされた状態で目覚める。

**構造の対応**

```

δ（蓄積偏差）= アデノシン蓄積量（覚醒時間とともに増加）

τ（許容幅）  = 神経系の覚醒維持限界

位相跳躍    = 強制入眠（本人の意志に関わらず発生）

残差の排出  = 睡眠中のアデノシン分解・消去

```

**注目すべき点**

意志の力で眠気を無視することはできない。

できると思っている人も、限界を超えれば必ず眠る。

構造は意志より強い。

限界に達したシステムは、自律的な判断を停止し、外部プロセスに委ねる。

これは失敗ではない。構造的な必然であり、次のサイクルへの準備である。

---

**三つの共通性**

**共通性1：蓄積は見えない**

いずれの現象も、蓄積のプロセスは外部から観察しにくい。

地震も骨折も眠気も、表面は静かである。しかし内部は変化し続けている。

静かであることは、安全であることを意味しない。

**共通性2：位相跳躍は突然に見える**

外部から見ると「突然」起きる。しかし内部の蓄積は一貫して進んでいた。

「突然」は観測者の情報不足であり、構造の問題ではない。

起きるべくして起きた必然である。

**共通性3：跳躍の後にリセットがある**

地震の後に断層はリセットされる。

沸騰の後に水は新しい平衡へ移行する。

睡眠の後に覚醒状態に戻る。

骨折の後に骨は修復を始める。

跳躍は終わりではない。次のサイクルの始まりである。

地球はこの繰り返しによって40億年の安定を維持してきた。

---

**補足：非対称性について**

2.3bで示したように、閾値は方向によって異なる。

上昇と下降に同じτを使うことは、現実の近似に過ぎない。

この非対称性が、第3章で定式化するτの動的定義の根拠となる。
