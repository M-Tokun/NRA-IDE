## 第3章：定式化

---

### 3.0 この章の目的

第2章では、スケールの異なる四つの現象が同一の構造原理を持つことを観察した。

本章では、その構造を一つの式として定義する。

定義にあたって、三つの量を厳密に確定させる。

δ（蓄積偏差）、τ（許容幅）、そしてR（構造比率）である。

---

### 3.1 一次式——基本構造比率

$$R = \frac{\delta}{\tau}$$

**各量の定義**

**δ（デルタ）：蓄積偏差**

構造の内部に履歴として蓄積された偏差の量。

δは非負の実数であり、構造の状態遷移とともに更新される。

δを「誤差」と呼ばない。誤差は除去すべきものだが、δは追跡すべき軌跡である。

第2章の事例との対応：

```

地震      → 断層内の応力蓄積量

疲労骨折  → 微細亀裂の累積量

水の相転移 → 熱量の蓄積

睡眠圧    → アデノシンの蓄積量

```

**τ（タウ）：許容幅**

構造が蓄積偏差を吸収できる余裕の量。

τは正の実数であり、設計時または構造の性質から定まる。

ここで一つ明確にしなければならないことがある。

τは時定数ではない。

時定数は時間軸上で定義される量だが、τは時間軸と独立した構造パラメータである。

断層の摩擦限界は時間とは関係なく断層の物性から決まる。

骨の構造強度は時間ではなく骨の物質的性質から決まる。

τは「時間がどれだけ経ったか」ではなく「構造がどれだけ余裕を持っているか」を表す。

**R：構造比率**

δとτの比率。Rは無次元の実数であり、構造限界への接近度を示す。

**判定基準**

| Rの値 | 構造状態 | 系の動作 |

|---|---|---|

| R < 1 | 安定領域 | 通常動作を継続 |

| R = 1 | 構造閾値 | 位相跳躍の臨界点 |

| R > 1 | 閾値超過 | 位相跳躍・リセット |

Rが1.0に達した瞬間、系は位相跳躍する。

これは第2章で観察した全ての現象に共通する動作である。

### 3.2 τは静的な単一値ではない——動的τの定義

第2章2.3bで確認した。

凍結と融解は対称的ではない。同じ0℃でも、方向によって全く異なる現象が起きる。

これは自然界に普遍的な原則を示している。

**上方向と下方向でτは異なる。**

この非対称性を記述するために、動的τを定義する。

**上側EMA（拡大方向のゆらぎ）**

$$\mathrm{EMA_{upper}}(n) = \alpha_u \cdot \delta_u + (1 - \alpha_u) \cdot \mathrm{EMA_{upper}}(n-1)$$

拡大方向の偏差 $\delta_u$ を平滑化する。

$\alpha_u$ は上側の平滑化係数（ $0 < \alpha_u \leq 1$ ）。

**下側EMA（縮小方向のゆらぎ）**

$$\mathrm{EMA_{lower}}(n) = \alpha_l \cdot \delta_l + (1 - \alpha_l) \cdot \mathrm{EMA_{lower}}(n-1)$$

縮小方向の偏差 $\delta_l$ を平滑化する。

$\alpha_l$ は下側の平滑化係数（ $0 < \alpha_l \leq 1$ ）。

**動的τの非対称定義**

$$\tau_{upper} = \tau \cdot (1 + \beta_u \cdot \mathrm{EMA_{upper}})$$

$$\tau_{lower} = \tau \cdot (1 - \beta_l \cdot \mathrm{EMA_{lower}})$$

$\beta_u$ 、 $\beta_l$ は非対称調整係数。

**この定義が意味すること**

```

拡大方向（上側）:

  ゆらぎが大きくなるとτも広がる

  = 構造が余裕を持って吸収しようとする

  = 水の融解における「格子崩壊の連続性」

縮小方向（下側）:

  ゆらぎが大きくなるとτが縮む

  = 構造が敏感に反応する

  = 凝固における「核生成の不確定性」

```

静的なτは現実の近似である。

動的τは現実の構造を記述する。

### 3.3 三つの設計原則

R = δ/τ を計算するシステムには、三つの設計原則が伴う。

これらは付加的な制約ではなく、式の論理的帰結である。

---

**原則1：整数位相錠定（Integer Phase Lock）**

R = δ/τ の計算において、割り算の余り（残差ε）が発生する。

この残差を次のサイクルへ持ち越してはならない。

残差は熱として排出し、次サイクルの計算はゼロから始める。

```

R = δ/τ の計算:

  商の整数部 → 次の状態判定に使用

  残差ε     → 排出（次サイクルへの持ち越し禁止）

  キャリーオーバー → 禁止

```

なぜか。

残差を持ち越すとは、前サイクルの誤差が次サイクルの入力になることを意味する。

これが誤差の乗算である。地震の後に「前回の応力の残り」が次のサイクルに加算されれば、

断層は永遠に安定しない。

地球はそのように動いていない。

この原則は機械式時計の脱進機と同一の論理である。

脱進機は歯車の動きを一歯ずつ確実に区切り、残差を持ち越さない。

それによって時計は長期間にわたって精度を維持する。

---

**原則2：Fail-Closed設計**

R ≥ 1.0 に達したとき、システムは自律的な判断・補正・探索を行わない。

構造状態の情報のみを提示し、沈黙する。

```

R < 1.0  → 通常動作

R = 1.0  → 警告・通知

R ≥ 1.0  → 沈黙・外部への委譲

```

これは「停止」ではない。「構造状態を維持したまま出力を抑制する」設計である。

睡眠圧の事例がこれを示している。

人間は覚醒限界に達したとき、「どうすれば起きていられるか」を探索しない。

構造が強制的に移行させる。これは失敗ではなく、次のサイクルへの移行である。

Fail-Closedの意義は、機械が判断を継続することによる

構造破断のリスクを排除することにある。

機械は診断する。判断は外部に委ねる。

---

**原則3：告白の公理（Transparency Obligation）**

近似計算を使用した場合、その事実を開示することを義務とする。

近似は禁止されていない。

隠蔽が禁止されている。

```

開示が必要なケース:

  浮動小数点演算を使用した場合

  → 「線形近似による歪みが発生している」と報告

  静的τを使用した場合（動的τの代わりに）

  → 「非対称性を近似している」と報告

```

なぜこれが原則として必要か。

近似を使った計算の結果を、そうでないかのように提示することは、

利用者が適切な判断を下すために必要な情報を奪うことである。

Fail-Closedと組み合わせることで、システムは「自分の限界を知り、それを伝える」

存在として機能する。

### 3.4 既存理論との関係——対立ではなく補完

本式は既存の理論を否定しない。

観点が異なる。

**微積分・連続力学との関係**

連続力学は「系がどのように変化するか」を記述する。

本式は「系が構造限界にどれだけ近いか」を評価する。

前者は軌跡の記述、後者は接近度の診断である。補完関係にある。

**PID制御との関係**

PID制御は偏差をゼロに戻すことを目的とする。

本式は構造限界への接近度を評価することを目的とする。

| 観点 | PID制御 | 本式 |

|---|---|---|

| 目的 | 偏差をゼロへ（最適化） | 限界への接近度（診断） |

| τの意味 | 存在しない | 構造的許容幅（時間と独立） |

| 残差の扱い | 積分項として累積 | 熱として排出 |

| 出力の形式 | 連続的な制御量 | 離散的な状態判定 |

τはPID制御の時定数ではない。

τは時間軸と独立した構造パラメータである。

この違いは根本的である。

**統計・確率論との関係**

統計的手法は「平均的な挙動」を集合論的に推定する。

本式は「個別の構造の現在状態」を個体論的に評価する。

前者は分布を扱い、後者は個体を扱う。目的が異なる。

---

### 3.5 この式が意味すること

R = δ/τ は単純な比率式である。

しかしその意味は「正しい値を計算する」ことではない。

「系が今どれだけ危ういか」を評価し、

限界に達した瞬間に沈黙する——

これだけを行う式である。

第2章で観察した現象はすべてこの動作をしている。

地球は40億年、この計算を実行し続けている。

第4章では、この式が工学の現場でどのように機能するかを確認する。
