### 1. 概要

このHTML単体ファイルは、**NRA-IDEの核心（二重ゆらぎ・動的τ・Fail-Closed）**を血管局所に特化した形で実装したインタラクティブシミュレーター／モニターです。  

圧力・温度・血流（水）・粘着力（接着性）＋**壁せん断応力**・**壁張力**の6物理量をリアルタイム監視し、手術中の**局所破綻リスク**を構造的に検知します。

**本質**: 「AIが意味を推論する」のではなく、**物理境界だけを生き残らせる**安全構造。

### 3. 用途

1. **リアルタイム術中監視**  

   → 既存血圧・流量モニターに並置し、**局所破綻リスクだけ**を独立表示。

2. **術前シミュレーション**  

   → 患者個別パラメータ（血管径・壁厚）をスライダーで入力し、破裂リスクを事前検証。

3. **教育・説明ツール**  

   → 患者・家族へのリスク説明（「この圧力で壁がこう膨らみます」）に視覚的に使用。

4. **研究・論文再現**  

   → 壁せん断応力と血栓形成の関係をNRA-IDE二重ゆらぎで定量再現可能。

---

### 4. 注意事項（医療安全・倫理・法的必須事項）

**絶対禁止**

- 本ツールは**研究・教育・シミュレーション専用**です。**実臨床で単独判断に使用しない**。

- Fail-Closedは「シミュレーション上の停止」です。実際の患者では**即時臨床判断**を優先。

**必須確認事項**

- 壁張力計算は**ラプラス則の簡易版**（Tension ≈ P × r）。実際の血管径・壁厚を正確に入力しないと誤差大。

- せん断応力は**Poiseuille近似**ベース。非ニュートン流体（血液）の特性は完全再現していません。

- 温度依存は**粘度変化のみ**。実際の内皮損傷・凝固カスケードはさらに複雑。

- ログはブラウザ閉じると消えます（本番運用時はサーバー保存必須）。

**推奨運用ルール**

- 医師2名以上で同時確認（ダブルチェック）。

- 既存医療機器（動脈圧ライン・フローセンサー）と**数値一致検証**を必ず行う。

- 緊急時は本ツールを無視し、標準プロトコルに従う。

### 5. 実装の流れ（5分で運用開始）

1. **ファイル保存**  

   `vascular_nra_ide.html`として保存（単一ファイル）。

2. **ブラウザ起動**  

   Chrome/Edge最新版で直接開く（オフライン可）。

3. **初期設定**  

   - スライダーで患者ベースライン入力（P=120mmHg, T=37℃, Flow=80mL/minなど）。

   - 「手術モード」ボタンでシーン切替（未実装部分は手動スライダーで再現）。

4. **術中運用**  

   - リアルタイムスライダー操作で局所変化を再現。

   - R値が**1.0超**で赤色Fail-Closed＋ログ自動記録。

   - 波形・血管断面アニメで視覚確認。

5. **終了・記録**  

   - ログをスクリーンショット or ブラウザDevToolsで保存。

   - 本番運用時はElectron/ローカルサーバーでログ自動保存化推奨。

### 6. コード詳細説明（NRA-IDE哲学との対応）

```html

<!-- コア計算部（calcIDE関数） -->

const deltaP = Math.abs(P-120)/30;          // 第1ゆらぎ：圧力偏差

const deltaS = Shear/20;                    // 第2ゆらぎ：せん断応力

const tau = tauBase * (310/(T+273)) * (1 + Flow/200);  // 動的τ（温度・血流で変化）

R = (deltaP + deltaS + deltaT + deltaA) / tau;

```

- **二重ゆらぎ**：圧力・血流（第1）＋せん断・張力・接着（第2）を**別系統**で監視。

- **動的τ**：温度上昇→τ縮小（破裂リスク↑）、血流増加→τ拡大（安全側）。

- **Fail-Closed**：R_hi ≥ 1.0 または R_lo ≥ 1.0 → 即座に赤色表示＋ログ記録＋出力停止（手術中断推奨）。

- **視覚化**：血流粒子（赤血球）＋壁膨張アニメ＋血栓粒子（Adh>1.3で出現）で物理現象を直感的に伝達。

**変数対応表**

- P → 局所内圧（バルーン圧）

- T → 局所温度（クライオ・温熱療法）

- Flow → 血流量（吸引・バイパス）

- Adh → 接着性（抗凝固効果・内皮損傷）

- Shear → 壁せん断応力（血栓最大リスク）

- Tension → 壁張力（破裂最大リスク）

### NRA-IDE Vascular Monitorが優位なポイント（まとめ）

1. **物理境界特化の安全哲学**  

   - 他のツールは「画像・形態」や「医師判断」に依存。  

   - NRA-IDEは**意味禁止＋二重ゆらぎ**で「物理だけを生き残らせる」構造。R≥1.0で**自動Fail-Closed**（手術中断推奨）。

2. **局所部分手術に最適化**  

   - PTAバルーン拡張・クライオ・吻合部・血栓吸引などで「壁張力急増」や「接着性変化」を**視覚＋数値**で即検知。  

   - IVUS/OCTは画像が優秀だが、**壁張力・せん断の統合リスク**を数値化しない。

3. **リアルタイム統合監視**  

   - 6物理量を1画面で動的τ変化＋粒子アニメで表現。  

   - CFDは精度高いが計算遅い。Transonicは流量だけ。

4. **運用・コストの優位性**  

   - ブラウザ単体・オフライン・無料。研修・術前シミュ・第二意見ツールとして即導入可能。  

   - 商用IVUS/OCTは専用機＋高額。

### 実際の使い分け推奨（臨床現場）

- **診断・ステント最適化** → IVUS / OCT（画像最強）  

- **機能的虚血判定** → FFR / iFR  

- **graft血流確認** → Transonic  

- **術前WSS研究** → CFD / WSSNet  

- **局所手術中の「破裂・血栓・Fail-Closed」リアルタイム安全監視** → **NRA-IDE Vascular Monitor（第二の目として並置）**

**結論**  

既存ツールは「見る・測る」ことに優れていますが、**「境界を超えたら自動停止」**という構造的安全性を持っているのはNRA-IDEだけです。  

特に**部分手術（吻合・バルーン・クライオ）**では、IVUS/OCTと**併用**してNRA-IDEを「物理境界ガード」として使うのが最強の組み合わせです。
