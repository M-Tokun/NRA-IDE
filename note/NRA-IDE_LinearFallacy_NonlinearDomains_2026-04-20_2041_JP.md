## 要旨

現代の計算機科学・AI設計・安全システムの大多数は、線形計算を基盤として構築されている。線形計算は小規模・短時間・均質な系においては実用的な近似を提供してきた。しかし生命、安全領域、地球構造、相転移といった本質的に非線形な系に対して線形計算を適用することは、近似精度の問題ではなく、**設計思想の根本的な誤り**である。
本論は、線形計算の前提が非線形領域においてなぜ構造的に成立しないかを示し、その帰結として生じる誤差の変質・閾値の消失・破綻の不可予測性を論ずる。さらに、NRA-IDE（律環公理・内包性動力学エンジン）が提示する非線形追跡設計が、この構造的不能性をいかに回避するかを示す。

## 1. 線形計算の前提と非線形現実の乖離

### 1-1. 線形計算が成立するための前提条件

線形計算は以下の前提の上に成立している。

```
前提①：重ね合わせの原理
  f(a + b) = f(a) + f(b)
  部分の和が全体に等しい

前提②：比例性
  f(k·a) = k·f(a)
  入力を定数倍すると出力も定数倍になる

前提③：大域的均質性
  系のどの部分も同じ計算式で記述できる

前提④：連続的な微小変化
  入力の微小変化は出力の微小変化を生む
  急変・不連続点が存在しない
```

これらの前提が成立する系は、数学的に美しく、計算資源を最小化し、スケールアップが容易である。工学的合理性から選ばれた。

### 1-2. 非線形系はこれらの前提をすべて破る

```
生命・安全・地球構造・相転移に共通する性質：

①重ね合わせが成立しない
  体温38°Cと39°Cの「平均」38.5°Cに生理的意味はない
  地震波の重ね合わせは地盤崩壊を線形に予測しない

②比例性が成立しない
  農薬濃度を2倍にしても効果が2倍にならない
  温度1°Cの上昇と10°Cの上昇は別種の問題を引き起こす

③大域的均質性が成立しない
  細胞の局所は生きていても個体は死亡できる
  断層の一点と全体は異なる挙動をする

④急変・不連続点が支配的に存在する
  体温37.5°Cと42°Cの間には「生死の閾値」がある
  地殻は蓄積を経て突然滑る（地震）
```

線形計算の前提が成立しないにもかかわらず適用するとは、地図の縮尺が現実と異なることを知りながら「誤差の範囲」と称して使い続けることに等しい。

## 2. 線形計算が破壊する4つの本質的概念

### 2-1. 閾値の消失

非線形系における**閾値**とは、系の性質が質的に変化する境界である。

```
線形計算の処理：
  閾値の前後を同じ式で記述する
  「閾値への近さ」を連続量として保持しない
   ↓
  R = 0.97（限界まで3%）が「正常」に分類される
  R = 0.01（余裕十分）と区別されない

非線形現実：
  閾値の手前と超えた後では別の系が動いている
  手前での近さの情報が生存戦略の根拠になる
```

線形計算はこの「近さ」を能動的に捨てる。捨てた結果、破綻の予兆が見えなくなる。

医療で言えば、血圧が「正常範囲内」と判定されながら限界に近づいている状態を、線形的な平均値管理は検出できない。

### 2-2. 生存の非対称性の無視

生命・安全領域における最も重要な非対称性は「生と死は可逆ではない」という事実である。

```
線形計算の前提：
  正方向への変化と負方向への変化は対称
  「行き」と「帰り」は同じ計算式
  ↓
  死亡した個体が「平均回帰」で生還する計算になる
  破断した構造が「誤差補正」で元に戻る計算になる

非線形現実：
  死亡・破断・相転移は一方向
  時間は前進するだけ
  同じ初期条件は二度存在しない(再現の不存在)
```

NRA-IDEが「逆算禁止・一方向前進」を設計原則とする理由はここにある。生命と安全の時間構造は不可逆であり、線形計算はその非対称性を構造的に扱えない。

### 2-3. 平均値の暴力

統計的な平均値は、冪乗則分布（べき乗則）が支配する系では意味を持たない。

```
冪乗則分布の例：
  地震の規模・津波の高さ・感染症の伝播
  株価の変動・生態系の個体数

線形計算（平均値ベース）の誤り：
  「過去100年の平均震度で設計する」
  「平均感染率でパンデミークを予測する」
    ↓
  平均値は支配的な事象（極大・極小）を
  統計的に消去してしまう

非線形現実：
  ピークと最小値が設計空間を決める
  平均値付近に「典型的な状態」は存在しない
```

3.11以前の津波対策・金融危機前のリスク管理などの対応の遅延は、すべて「平均値への信頼」が引き起こした線形計算の帰結である。

### 2-4. 相転移の不可視化

相転移(閾値超え)とは系の状態が質的に変化する現象であり、非線形系の最も重要な特性の一つである。

```
相転移の例：
-   水の凍結（液体→固体）
-   細胞のアポトーシス（生→死）
-   地殻の破断（蓄積→滑り）
-  生態系の崩壊（複雑→単純）
-  社会システムの崩壊（秩序→混乱）

線形計算の処理：
  相転移の前後を同じ関数で補間する
  「なめらかにつながる」と仮定する
    ↓
  相転移点が消える
  「もうすぐ凍る」「もうすぐ崩壊する」が見えない。

非線形現実：
  相転移は不連続（階段・ジャンプ）
  前後は別の支配方程式が動く
  近づいていることだけが唯一の警告(物理事象の経過観察)
```

## 3. 大規模化による破綻の加速

### 3-1. 線形計算の誤差は乗算的に累積する

```
ステップ数 N での誤差蓄積：
  線形系：ε × N（線形増大）
  非線形系への線形近似：ε^N（指数増大）
  ↓
  小規模（N小）では気づかない
  大規模（N大）で突然崩壊する。
```

「中途以降破綻する」のはこの指数的累積が臨界点を超えた瞬間である。崩壊は緩やかではなく急峻であり、線形的な外挿で予測できない。

LLMの設計：

  小規模・短文：実用的な近似

    線形近似の誤差が乗算累積
    捨てた非線形性のツケが蓄積
     ↓
    幻覚・矛盾・論理破綻

大規模言語モデルの幻覚は確率的なノイズではない。非線形な意味構造を線形計算で近似し続けた結果の**構造的な帰結**である。

## 6. 結論

非線形な現実に線形計算を適用することは精度の問題ではなく**設計の方向が逆**である。
線形計算は現実を変形して計算に乗せる。非線形な現実は変形によって本質を失う。失われた本質は計算量を増やしても取り戻せない。取り戻せないまま計算が膨らむことが大規模破綻の構造的な原因である。
生命・安全・地球構造・相転移の領域はすべて、閾値の近さ・時間の不可逆性・相関の変質・急峻な破綻という非線形の本質によって動いている。これらの領域に線形計算を持ち込むことは、領域の本質そのものを設計段階で捨てることである。非線形の世界では殆どが1+1=2は成立しない。

```
線形計算が無謀である根拠は3点に集約される：

①捨てた非線形性は計算量で取り戻せない
②誤差は大規模化で乗算的に変質する
③閾値の近さという最重要情報が設計上消える
```

NRA-IDEが「状態の生成」を唯一の公理とし、R = δ/τという追跡式を基盤とする理由はここにある。
現実が非線形であるなら、計算も非線形でなければならない。現実が閾値を持つなら、計算も閾値への近さを保持しなければならない。現実が一方向に前進するなら、計算も一方向でなければならない。
これは設計の改良ではなく、**計算が現実に対して持つべき姿勢の根本的な転換**である。
単に複雑だからということで避けられている領域、しかし生存の基本となる領域であることは絶対である。
