# 相関票と多数決の限界 — 複数AI照合は不一致地点のマーカーとして使う

- 着想：M-Tokuni（2026-10-12の対話）。
- 本記録は着想の記録である。実験・数値の主張は含まない。

## 1. 現在の着想

- 複数AI（Claude・Gemini・ChatGPT・DeepSeek・Copilot等）で検証する運用は、単一AIの自己申告より強い。
- ただし複数社モデルは訓練文書の相当部分を共有するため、**票は独立標本ではない**。
- 多数決が働くのは各票が独立に誤りを散らす場合だけ。相関票の10:1は、独立証拠10個ではなく**同源見解の反復**の可能性がある。
- **ノイズで切り捨てた少数派が正しい**確定例は科学史上に多数。多数派は自分たちが多数派であることを根拠に誤りを強化することがある。
- したがって：**複数AIの一致は真理判定ではない。分散は真理の指標ではなく「次に照合すべき地点のマーカー」。**
- 運用：複数AI照合は**不一致地点の列挙**に使い、多数決はしない。決定は実行ログ（決定論）と利用者（物理的事象の照合）。
- 確率一般についての併せての着想：確率が意味を持つのは標本空間が先に定義された場面（物理的測定誤差・頻度）のみ。可能性探索は空間未定義なので、確率付与は精密さを装った独断。確率化は測りやすいものへのすり替えを起こし、重要度でなく測定容易度で議論が決まる。

## 2. 外部照合（2026-10-12、公開情報のみ）

- "correlated LLM judge errors"（arXiv 2510.13602）等、評価者間相関の測定・軽減を扱う複数論文。

## 4. 最小試行（案）

1. 同一プロンプトを複数社モデルに投げ、回答の不一致地点をリスト化する。
2. 不一致地点を実行ログ・物理照合で順に潰し、どのモデルの不一致が最多だったかではなく、**どの不一致が残ったか**を記録する。
3. 残った不一致＝未照合の論点。`evidence: generated` のまま保留扱いにする。
