四層誤差分解 と Fail-Closed 到達時刻

δ_total² = δ_classical² + δ_shot² + δ_decoh² + δ_gate² の独立合成と、τ_total = min(τ_system, τ_shot, τ_coh, τ_gate) の律速段原則を可視化します。T_FC = min_k { t : δ_k(t)/τ_k ≥ 1 } がどの層によって決まるかを観察できます。最も狭い層が、改善すべき対象を一意に指し示します。

誤差層の時間発展（δ_k(t)）

古典層 δ_classical（定常） ショット層 δ_shot ∝ σ_O/√N デコヒーレンス層 δ_decoh = A(1−e^{−t/T₂}) ゲート層 δ_gate = D·ε_gate τ_k（律速段）

各層の R_k = δ_k / τ_k

最初に R_k = 1 を超えた層が、Fail-Closed 到達時刻 T_FC を決めます。これは律速段原則の直接的な可視化です。

定式化と読み方

δ の独立合成 (二乗和): δ_total(t)² = δ_classical(t)² + δ_shot(t)² + δ_decoh(t)² + δ_gate(t)² τ の律速段原則 (最小値): τ_total(t) = min( τ_system, τ_shot(N), τ_coh(T₂), τ_gate(D) ) 層別 R_k と Fail-Closed 到達時刻: R_k(t) = δ_k(t) / τ_k T_FC = min_k { t : R_k(t) ≥ 1 } デコヒーレンス律速の場合: T_FC^decoh ≈ T₂ · ln( A / (A − τ_coh) ) ゲート律速の場合: T_FC^gate ≈ τ_gate / ( ε_gate · dD/dt )

どの層が最初に限界に到達したかを読むことが、改善対象の特定に直結します。デコヒーレンス律速なら T₂ の改善、ゲート律速なら ε_gate または回路深さ増加率の改善が、構造的に指示されます。
