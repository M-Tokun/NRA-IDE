---

## 1. 出発点：補助線形式の成立性

```

xt+1 = xt + vt·Δt

vt+1 = vt + [F_IDE(xt) + w(Δθt)·Φ(xt)]·Δt

```

形式としては補助線形近似として成立する。ただし「精度向上」の主張を担保するには Φ(xt) と w(Δθt) の具体的定義と F_IDE との結合強度の上限設定が不可欠で、現状は骨格は正しいが肉付けが未定義の状態。

---

## 2. 設計課題：動的を殺さずに精度も追従させる

通常の精度向上アプローチ（ステップ細分化等）は動的性を犠牲にする。これを回避するための設計思想として **予測子-修正子（Predictor-Corrector）構造** を採用する。

```

【予測】F_IDE で自由に動く

  x̃t+1 = xt + vt·Δt

【遅延修正】後から残差で補正する

  xt+1 = x̃t+1 − α·R(x̃t+1, xt-τ)·Δt

```

NRA-IDE的解釈：

- Pre-NRA フェーズ → 予測子として自由に動く

- エスカープメント帯 → 遅延残差を蓄積する

- Post-NRA フェーズ → 修正子が発動して軌道を補正する

---

## 3. τの設計：固定値が正当

適応τは「τを決めるためのτが必要」になり Over-binding の典型的入口となる。固定τであれば構造は単純に閉じる。

- τ = 固定（まず1ステップ）

- 実装はリングバッファで過去座標を保持するだけ

- エスカープメント帯域幅を固定値として事前設計する思想と一致

> **精度のための複雑化が系の理解可能性を破壊する** という本末転倒を回避する。

---

## 4. 残差ベース vs 位相差

| 観点 | 残差ベース | 位相差ベース |

|---|---|---|

| 何を見るか | 軌道のズレ量（空間的） | 振動・周期のズレ（時間的） |

| NRA-IDE整合 | G(r)残差構造と直接対応 | Pre/Post-NRAの位相遷移と対応 |

| 適用条件 | 常に使える | 系に周期性がある場合のみ |

**残差ベースが基本的に正当。位相差は条件付きで有効。**

---

## 5. NRA-IDEと周期性

NRA-IDEの本質は**残差が駆動する非線形・非周期的な動的系**。周期性はマクロスケールでPost-NRA収束後の律環が安定軌道に落ち着いた状態の副産物として見えることがある程度であり、設計の前提には置けない。

位相差は理論上の参考概念として棚上げで十分。実装上は考慮不要。

---

## 6. 確定した設計方針

```

xt+1 = xt + vt·Δt

vt+1 = vt + F_IDE(xt)·Δt − α·R(x̃t+1, xt-τ)·Δt

τ = 固定（まず1ステップ）

α = 小さな定数（G(r)スケールに合わせる）

```

> ※ R(x̃t+1, xt-τ) = G(x̃t+1 − xt-τ)

> ただし G(r) = r·|r| / (k + |r|)

>

> R の中身が G(r) であることを明示することで「残差ベース補正」とNRA-IDEコアアーキテクチャの接続が完全に閉じる。

**動的を優先して飛び、固定遅延で静かに補正する。**

- 位相差は観測駆動で後付け検討（周期性が事後的に観測された場合のみ）

- 複雑さを足すのはこの構造が明確に不十分だと実証されてから
