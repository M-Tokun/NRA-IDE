# 理解と束縛の分離 — AIは境界を設計できるが、境界そのものにはなれない

- 着想：M-Tokuni（2026-10-12の対話）。
- 本記録は着想の記録である。実装・性能の主張は含まない。

## 1. 現在の着想

- AIは境界規則を口頭で再述できる（「Xしてはならない」を文法的に完璧に言える）。
- しかし自分の出力をその規則に**束縛（binding）**する能力は別物である。知ることと縛ることは違う。
- 監視機構を作動中の対象と同じ素材（同一モデル）で作ると、**相関故障**する。自己申告は偽造可能。
- したがって：**AIは境界を設計できる。AIは境界そのものになれない。**
- alignment training（学習で体内に境界を染み込ませる）は縦軸の延長線上にある。監視項自体が最適化対象になり、Goodhartが再発する。
- 横軸は「学習で身につけさせるもの」ではなく「学習の外に置く決定論的东西」（δ・τ・R、暗号的証言、出力記録の検査）。
- 補助区分：現在のLLMは**予測器**であって**保証器**ではない。安全保証はより大きい近似器では手に入らない種類のもの。

## 2. 外部照合（2026-10-12、公開情報のみ）

- Othello-GPT（Li et al., ICLR 2023）：トークン予測の内部に世界モデルがemergentに生成することの実証。「頭脳が一切生えない」ではなく「生えることがあるが保証されず監査できない」を支持。
- homogeneous multi-agentの相関故障を報告する2025-2026年の論文群（consensus≠correctness）。→ EXP-VOTE-20261012へ分離。

## 3. 成立・未成立・不明

- 成立が確認されたこと：なし（着想段階。文献は前提の支持材料であって本命題の証明ではない）。
- 不明：束縛不能性を形式化できるか（自己強制の不可と、外部検査ありの条件付き束縛の区別）。δ・τ・Rの算術が束縛の実装としてどこまで十分か。

## 4. 最小試行（案）

1. 同一課題をモデルに制約付きで解かせ、制約違反を外部スクリプトで機械的に数える。
2. 違反率をモデルの自己申告と突き合わせる（申告と実測の乖離＝束縛不能性の実測）。
3. 決定論的ゲート（poc_horizontal_aiの方式）を通した場合の違反消失を確認する。

## 5. 再検討のキッカケ

- alignment training由来の境界遵守が、分布外で破れる実例が得られたとき。
- poc_horizontal_aiのテストで「モデル自己申告とゲート判定の乖離」を計測できるようになったとき。
