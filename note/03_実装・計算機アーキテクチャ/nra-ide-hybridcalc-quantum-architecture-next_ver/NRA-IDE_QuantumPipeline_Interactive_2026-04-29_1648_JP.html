NRA-IDE 量子拡張 三層パイプライン

QUANTUM → OBSERVE → JUDGE

量子層（Lindblad 時間発展による密度行列 ρ_t）から、観測・圧縮層（観測量期待値ベクトル z_t = ⟨O_i⟩_t）を経て、NRA-IDE 判定層（残渣 r_t、閾値比 R_t = δ_t/τ_t、ゲート関数 g(R_t)）へ流れる三層構造を可視化します。R_t は補正の開閉を決め、C(r_t) の飽和写像が局所急変への過剰反応を抑えます。

三層の役割と接続

第1層 量子層 (Quantum) dρ/dt = -(i/ℏ)[H,ρ] + Σₖ γₖ ( Lₖ ρ Lₖ† - ½{Lₖ†Lₖ, ρ} ) ρ_{t+1} = ρ_t + Δt · L(ρ_t) 第2層 観測・圧縮層 (Observe) z_t = ( ⟨O₁⟩_t, ⟨O₂⟩_t, ..., ⟨Oₘ⟩_t )ᵀ ∈ ℝᵐ ⟨Oᵢ⟩_t = Tr( Oᵢ ρ_t ) 第3層 NRA-IDE 判定層 (Judge) r_t = z_{t+1}^pred - z_{t-ℓ}^ref δ_t = ‖W r_t‖ R_t = δ_t / τ_t g(R_t) = ゲート関数（沈黙 / 遷移 / 飽和） z_{t+1}^corr = z_{t+1} - α_t · g(R_t) · C(r_t) C(r_t) = r_t · |r_t| / (k + |r_t|) （飽和写像）

第1層は密度行列の時間発展、第2層は観測量期待値による性質保存圧縮、第3層は閾値比による補正開閉です。式は古典文脈の NRA-IDE と完全に同型で、観測量を量子オブザーバブルに置き換えたのみとなります。
