# 比較シミュレーション結果（2026-10-22）

- スクリプト：`sim_compare.py`（`PYTHONIOENCODING=utf-8 python -I -X utf8 sim_compare.py`、約75秒）
- すべて古典計算機上の仮想モデル。数値は例示で、実機の値ではない。
- 構成：A 通常のSPSA／B 単純な閾値監視（欠測ゼロ埋め・測定時のみ判定・ラッチなし）／C NRA-IDE（観測喪失で停止・状態区分・ラッチ・記録）／D C＋適用直前の再判定
- 最適化：1量子ビット、各点8ショット、400ステップ、200試行の平均
- 熱モデル：δ=付加熱負荷、τ=宣言運転温度での冷却能力×健全性−基準負荷。閾値 r_warn=0.6、r_handoff=0.8、r_irrev=0.95

## τの定義（S3）

| 付加負荷δ | 真のR（運転温度で評価） | 応答温度で求めたR |
|---|---|---|
| 0.10 | 0.20 | 1.000 |
| 0.25 | 0.50 | 1.000 |
| 0.40 | 0.80 | 1.000 |
| 0.60 | 1.20 | 1.000 |

応答温度で冷却能力を評価すると、熱平衡では負荷によらず R=1 になる（解析的にも P_avail(T)=P_load から導ける）。

## 二重ゆらぎとRの増加傾向（S4・S5）

窓20ステップの回帰傾き、3σで有意とした警報。

| id | 場面 | 警報ステップ数 R増加傾向／二重ゆらぎ | 初回時刻 R増加傾向／二重ゆらぎ／R≥r_warn |
|---|---|---|---|
| S4 | τがゆっくり劣化、δも微増 | 223.8 / 4.8 | 114 / 204 / 288 |
| S5 | τ一定でδが一時的に増加（無害） | 19.9 / ほぼ0 | 97 / （ほぼ発報なし）/ 101 |

- 二重ゆらぎは、無害なδの増加では発報しない（特異性が高い）。一方、検出は遅く、回数も少ない（感度が低い）。
- Rの増加傾向の判定基準は目安値で、両者の感度は公平に調整していない。

## 解釈の限界

- Bの「欠測をゼロで埋める」は、素朴な実装を仮定したもの。適切に実装された監視ならS1の差は出ない。S1が示すのは原則の効果で、新規性ではない。
- S2の差は版・時刻の照合によるもので、一般的な非同期設計でも得られる。
- S6のC・Dの誤停止は、シミュレーションに外部の再許可を入れていないため。
- 1量子ビットの問題は容易に収束するため、最終コストには差が出ない。最適化性能の比較にはなっていない。

## 追補：誤警報率を揃えた比較（sim_double_fluct.py）

変化のない状態で、両判定の1ステップあたり誤警報率を0.1%に揃えた（閾値：R増加傾向の傾き0.00124、二重ゆらぎ1.85σ）。300試行。

| 場面 | 変化開始後の警報率 R増加傾向／二重ゆらぎ | 初回検出（中央値） R増加傾向／二重ゆらぎ |
|---|---|---|
| S4a 両側が悪化 | 71.7% / 15.4% | 121 / 121 |
| S4c δだけ増加（S4aと同じRの経路） | 74.1% / 2.9% | 121 / 159 |
| S4b τだけ劣化 | 47.5% / 3.2% | 135 / 156 |
| S5 δの一時増加 | 6.4% / 0.2% | 100 / 113 |

- 二重ゆらぎは、Rの増加傾向より早くはならない（S4aで同時点）。
- 同じRの経路でも、二重ゆらぎの警報率は両側悪化で約5倍高く、原因を区別できる。Rの増加傾向は区別できない。
- 片側だけの場面でも約3%発報する（一方の傾きが強く、他方が雑音で閾値を越える）。区別は1ステップごとではなく、一定期間の警報率として見る必要がある。
- 「初回検出」は、長い期間では雑音でもいずれ発報するため、区別の指標としては弱い。警報率を主な指標とした。
