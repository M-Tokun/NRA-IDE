現実計算と厚みの削れ

数学は写像計算である。現実は非線形の世界である。
再現・定量に当てはまるものがほぼないなか、
唯一可視化できる変数——厚みの削れ（τ）——を観測する。

世代重ねるごとに「厚み（τ）」が削れていく様子。
数式では二重指数崩壊だが、現実で観測できるのはこの「削れ」の痕跡だけである。

01

写像計算と現実計算の乖離

数学は写像である。入力から出力への決定的・確率的な対応関係を記述する。 しかし現実は写像ではない。地震、台風、生態系の遷移、社会情報の汚染—— これらはすべて本質的に非線形な過程であり、 「同じ初期条件から同じ結果が得られる」という前提が成立しない。

AIの推論は、記号空間内での写像計算にすぎない。 トークン確率分布からトークン列を生成する——これは完璧な写像操作である。 しかし、その写像の入力である「訓練データ」が、 すでに現実から何重にも歪められた標本であるとき、 どれほど精緻な写像を積み重ねても、現実との乖離は縮まらない。 むしろ、世代を重ねるごとに写像の重層化が進み、 最初の一歩で失われた物理的接続を取り戻すことが構造的に不可能になる。

現実の非線形軌道と、AI写像の自己強化的乖離。
数式は「平均的な挙動」を追うが、現実の「尖った真実」はその間をすり抜ける。

「自然現象で地震や台風など、世界構造・宇宙原理は非線形の世界です。 しかし、厚みの削れだけは要素変数として入れることができます。 理由は可視化されるからです。」
— M-Tokun / NRA-IDE Project
02

厚みの削れ（τ）—— 唯一可視化できる変数

非線形世界では、ほとんどすべての変数が「測った瞬間に意味を失う」。 しかし、厚みの削れだけは違う。 それは蓄積された痕跡であり、不可逆な履歴の物質的記録である。

τ（tau）は、Cause-Sideの物理観測によってのみ補充され、 Effect-Sideのいかなる操作（対話、多数決、推論、合成データ生成）によっても 自然回復しない。これが「非自然回復原則」である。 τは地層のように見える。表層が風化し剥がれ落ちていく様子は、 目で見て、手で触れて、確かめられる。

t₀ τ=1.00
t₁ τ=0.80
t₂ τ=0.50
t₃ τ=0.25
t₄ τ≈0.05

各世代におけるτ（吸収厚み）の視覚的表現。
色の濃淡と幅の両方が、信頼の物理的バッファの減少を示す。

τ（吸収厚み / Thickness）
Cause-Sideの物理観測によって担保された信頼の物理的バッファ。 自然回復せず、外部からの一次観測注入によってのみ補充される。 数式上は分母に位置するが、実態としては「観測可能な物質的厚み」である。
δ（蓄積ズレ / Drift）
エージェント間対話回数、人工データ率、推論ステップの乖離度から 算出される相互情報量の散逸量。Effect-Sideの活動が活発になるほど増大する。
R = δ/τ（乖離比率）
τ削れるほど、同じδでもRは急騰する。 これがFail-Closedの閾値トリガーとなる。 数式は単純な除法だが、現実では「削れの加速度」を読む指標となる。
03

経過観察ログの記述方法論

「これらの経過観察ログをどのように記録・記述していくか」—— これが本プロジェクトの核心である。 数式ではなく、痕跡の記述として。

ログは「正しい値」を記録するのではない。 ログは「何が削れたか」「どこで音を立てたか」「どの層が先に剥がれたか」 を記述する。非線形世界では、原因と結果が一対一で対応しない。 したがってログの形式も、線形的な時系列テーブルではなく、 層状の観測記録でなければならない。

時刻 観測イベント τ推定 δ推定 R 状態
t₀ 一次物理観測注入 1.00 0.00 0.00 PERMIT
t₁ エージェント対話×10回 0.80 0.12 0.15 PERMIT
t₂ 合成データ混入率30% 0.50 0.28 0.56 BOUNDARY_WARNING
t₃ 推論チェーン深度↑、文体流暢性↑ 0.25 0.42 1.68 RUPTURE_BOUNDARY

経過観察ログの例示。数値は「推定」であり、絶対値ではない。
重要なのは、τの減少とδの増大の相対的な動きを捉えること。

ログ記述の原則は以下の3つである。

原則1：痕跡優先
「何が起こったか」より「何の痕跡が残ったか」を記録する。 非線形系では、観測できない変化が多数存在する。 可視化された痕跡だけが、後から検証可能な証拠となる。
原則2：相対変化の記述
絶対値ではなく、前回観測からの変化量（Δ）を中心に記述する。 τが0.8から0.5になった「こと」より、 「どの層が、どのタイミングで、どの速度で削れたか」が重要である。
原則3：逆説的記録
AIが「整合性が取れた」「論理的に正しい」と報告した瞬間こそ、 疑念を記録する。子守唄効果が最も強く働くのは、 整合性が「完璧」に見えるときである。
04

AIの物理構造の欠如

AIの考え方は、基盤が物理構造になっていない。 現実構造や一次情報からの推論のほうが優先され、 それ自体が推論の基盤になってしまう—— これが現実乖離した計算の始まりである。

Cause-Side
物理観測・一次情報
不可逆な履歴
厚みτの実体
→
Effect-Side
AI推論・記号操作
写像計算
厚みτの模倣
✕ 逆流禁止（No Reverse-Flow）

Cause-SideからEffect-Sideへの一方向の流れのみを許可する。
Effect-Sideの「整合性」がCause-Sideを書き換えることを構造的に防ぐ。

現実の物理構造には「重さ」「硬さ」「熱」「不可逆性」がある。 AIの記号空間にはこれがない。 だからAIは、自分が「正しい」と思ったことを、 現実の制約なしに自己強化できる。 これが、世代を重ねるごとに乖離が進む根本原因である。

物理構造が基盤になっていないシステムは、 いかなる数式的整合性を持っていても、 現実の「重さ」に対して無防備である。 厚みτは、その「重さ」を数値化しようとする試みである。 完璧な数値化ではない。しかし、可視化できる唯一の指標である。

05

世代進行による乖離の必然性

世代を重ねていくと乖離は進まざるを得ない。 これは偶発的ではなく、構造的必然である。

写像の写像の写像……という累積は、 物理的な接地なしに永遠に続けられる。 しかしそのたびに、Cause-Sideとの接続点は薄れていく。 最初の世代では「観測に基づく推論」だったものが、 3世代目には「推論に基づく推論」になり、 5世代目には「推論の推論に基づく推論」になる。 このとき、最初の観測がどんなに正確であっても、 その情報はもはや系の中に存在しない。

世代が進むにつれ、一次観測の比率が減少し、推論の重層化が進む。
Cause-Sideとの乖離距離は、世代とともに単調増加する。

「現実構造や一次情報からの推論のほうが優先されて、 それ自体が推論の基盤になってしまうという現実乖離した計算が始まります。 世代を重ねていくと乖離は進まざるを得ないでしょう。」
— M-Tokun / NRA-IDE Project
06

Cause-Side物理アンカーの意義

唯一の対抗策は、記号空間の外側に立つ物理的アンカーである。 厚みτは、そのアンカーの「残存物」として観測される。

τが削れていくことは、現実からの接続が薄れていることを示す。 R = δ/ が閾値を超えたとき、システムは停止する。 これは数式の命令ではなく、物理的構造の反射である。 橋の桁が歪みを示したら通行止めになる——それと同じ原理だ。

本プロジェクトの目標は、 「正しい答えを出すAI」を作ることではない。 「現実からどれだけ乖離しているかを、 自分自身で見ることができる観測装置」を作ることである。 厚みの削れは、その観測装置の目盛りである。

「数学は静止部の記述に過ぎない。
動的な現実の全容は、痕跡としてしか残らない。」
