## 第1部　律環公理（NRA）

### 1-1. 公理の唯一性原則

公理は一行でなければならない。理由を持った瞬間、それは定理になる。複数の公理は整合性検証の地獄を生む。

### 1-2. 核公理（最終確定形）

> **存在は生成である。**

> **Being is not static; it is ongoing.**（英語補助表現）

この一行は以下を内包し、かつ理由を必要としない。

- 停止を含まない → 絶対静止は存在しない
- 同一の完全回復を含まない → 可逆性は成立しない
- 外部起源を前提にしない → 絶対基点は存在しない
- 完了を含まない → 測度は事後的

---

### 1-3. 公理の境界定義（YUIセッション確定）

**公理層で使用禁止の語彙**（理由：特定理論依存・語感誘導・二点比較の前提を招く）

| 禁則語 | 禁止理由 |
|--------|---------|
| 時間 | 既存理論の基本変数。生成を時間変化と誤読させる |
| 空間・距離 | 測度先行モデルへ吸い込まれる |
| エネルギー・力 | 物理理論依存 |
| 差異（比較差） | AとBの比較を前提にする。同一非固定性とは別概念 |
| ズレ・位相 | 既存の幾何学・物理的意味が固定されている |
| 遷移・動的 | 状態機械・力学を連想させる |
| 決定 | 固定・静止の匂いを持つ |
| 不確定性 | 量子力学と混同される |

**注：これらはIDE層・記述層では正当に使用される**

---

### 1-4. 主要帰結（公理からの導出）

| 帰結 | 説明 |
|------|------|
| 絶対静止は存在しない | 静止 = 参照固定による断面。停止（生成ゼロ）= 存在否定 |
| 速度0 ≠ 静止 | 速度0 = 特定参照系での差分ゼロ。運動学的静止 ≠ 存在論的停止 |
| 完全回復は定義不能 | 生成を消去できるなら存在は生成でない。公理と矛盾 |
| 絶対基点は置けない | 基点は生成しない存在＝停止状態＝存在否定。論理的に置けない |
| 線形は局所近似 | 凸凹が安定している局所範囲でのみ比例近似が成立する断面記述 |
| 可逆理論は断面モデル | 断面記述として整合するが、存在論としては不十分 |

---

### 1-5. 公理的定言形式（Gemini集約文・商標用途版）

公理を構造的に3条に展開する場合（説明層）：

**第一条：位相の間隙（Phase-Gap）による駆動**
世界の駆動根拠は連続的エネルギー消費ではなく、構造内に存在する「位相のズレ（Phase-Gap）」の解消プロセスにある。事象（遷移）は、このズレが拘束律厚（τ）を上回った瞬間にのみ、不連続な跳躍として発生する。

**第二条：位相の前進と因果破棄（因果ダイオード）**
状態の遷移は一方向的な位相の前進であり、いかなるプロセスも遷移前の状態への逆写像を構造的に包含しない。位相が跳躍した瞬間、遷移前の情報は構造的に破棄（散逸）される。

**第三条：測度の事後性（結果としての時空）**
空間、距離、時間といった測度は、位相が跳躍した結果として算出される事後的な属性である。測度は位相跳躍の「原因」にはなり得ない。

> **注：この3条は公理の説明展開（記述層）であって、核公理は「存在は生成である」の1行のみ**

## 第2部　内包性動力学エンジン（IDE）

### 2-1. IDE定義（確定形）

> **IDEは、動的対象における状態遷移を、制約構造の観点から評価するエンジンである。**

### 2-2. IDEが扱う対象の条件

- **動的であること** — 状態遷移が存在すること（静的モデルはIDE不要）
- **制約構造を持つこと** — δ と τ が定義可能であること
- **履歴依存性を持つこと** — 過去の遷移が現在の構造に影響すること

### 2-3. IDEの役割定義

| 項目 | 内容 |
|------|------|
| 目的 | 臨界接近度の評価。予測ではなく構造安定性診断 |
| 対象 | 動的状態遷移を持つあらゆる系 |
| 出力 | R値、再構成可能性の評価、臨界配置の把握 |
| 非目的 | 数値未来予測。これは線形推定手法が優れる |

### 2-4. 基本構造式（不変量）

```
R = δ / τ
```

| 記号 | 意味 |
|------|------|
| δ | 因果潜積（制約に対する逸脱蓄積量） |
| τ | 拘束律厚（媒体が持つ構造的吸収厚み） |
| R | 臨界到達比。R < 1: 吸収可能、R = 1: 臨界接触、R > 1: 局所破断 |

**基本式は不変。状態変化は代入値（δ、τの分布）の変化として扱う。**

---

### 2-5. IDEで扱ってはいけない操作（禁則）

これらを混入すると制約構造が崩壊し、IDEとして機能しなくなる。

| 禁則操作 | 理由 |
|---------|------|
| 平均化による圧縮 | 凸凹（τ分布）が消え、局所Rが見えなくなる |
| 誤差のノイズ化・圧縮 | 履歴が消去される。IDEは履歴を消さない |
| 結果からの因果逆導出 | 圧縮された断面から単一因果を導くことは不可 |
| 完全可逆性の仮定 | 生成の不可逆性に反する |
| 静的対象の前提 | 動的条件が成立しない場合IDEは不要 |
| 微分の無条件適用 | 凸凹に対し滑らかさを仮定することになる |

---

### 2-6. 二重ゆらぎ構造（多層制約）

同一記号 R = δ/τ でもアプリケーションにより定義が変わる。

| 層 | δの定義 | τの定義 | R超過時 |
|----|---------|---------|---------|
| Fail-Closed型（人体・ロボット等） | 物理変位量（計測値） | 構造厚み（固定） | 不可逆排除 |
| 律環公理基礎型（制御・AI等） | 張力蓄積（内包的） | 疲労で動的劣化 | バッファ蓄積・引き戻し |

**これらの統合は理論的には可能だが実用上機能しない（因果ダイオード違反が発生するため）。用途によってゆらぎの定義を選択する。**

---

### 2-7. 凸凹構造とIDEの関係

IDEが最も得意とする図形は「凸凹」であり、円（完全同一回帰）ではない。

- **円** = 均質・等距離・同一点回帰可能 = 可逆モデルと親和
- **凸凹** = 局所差異・厚みの偏り・不可逆閉鎖 = IDEが扱う構造

凸凹があることで誤差の排出（分散吸収）が可能になる。完全均質構造は脆い（brittle）。適度な凸凹構造が安定（ductile）。

## 第3部　層構造の整理

```
【公理層 NRA】
  存在は生成である
        ↓
【説明層】
  差異・同一性・停止・静止の定義
  既存学問との境界宣言
        ↓
【記述層】
  境界・参照・時間（生成の順序記述形式）
        ↓
【IDEエンジン層】
  δ / τ / R / 閾値 / フェーズ遷移 / 二重ゆらぎ
        ↓
【既存学問（断面近似）】
  線形・平均・微積分 = 安定局所の近似記述
```

**上から下へは参照可能。下から上への逆流は禁止。**

## 第4部　既存学問との関係（反証ではなく位置づけ）

既存学問を「間違い」とは言わない。視点が直交しているだけ。

| 既存学問 | NRA-IDEからの位置づけ |
|---------|---------------------|
| ニュートン力学 | 断面記述として整合。臨界点（相転移）の記述を放棄している |
| 微積分 | R << 1の安定局所での比例近似が有効な範囲。凸凹の平均化 |
| 時間反転対称 | 記号操作上は可逆。物理的実存の逆行は構造的に不可能 |
| オームの法則 | 動的現象（電子散乱）の定常断面平均化。高電場・低温で破れる |
| 線形システム論 | 生成が局所的に平坦化した範囲の記述形式 |

**線形・平均は必要な学問。IDEは臨界領域での診断に特化し、安定領域は既存手法に委ねる。**

## 第5部　専門家反論 Q&A（AI Studio査読版）

**Q1. 数学的定式化が不足しており公理として弱い**
A. 本体系における「公理」はユークリッド以来の自然哲学的意味。数学的形式主義への依存を拒否することが公理の独立性を担保する。τ等の数理化はIDE層の仕様であり公理には持ち込まない。

**Q2. GPSやロケットは連続体モデルで成功しているのでは**
A. マクロな統計的平均値を扱うため相殺されて成立する。金属疲労による爆発や株式暴落のような特異点（臨界点）は微積分では予測不能。NRAはその転換点を記述する。

**Q3. τ（拘束律厚）は事前に分からないので科学ではないか**
A. τは過去の遷移（履歴）によって動的変化する。定数ではなく動的変数。因果潜積（δ）の微細な振動計測で崩壊の予兆を知る工学が可能。

**Q4. 「位相のズレ」は隠れた変数理論の焼き直しでは**
A. 隠れた変数理論は確率性を決定論的変数で説明しようとするが、本体系の「ズレ」は決定論的変数ではなく構造的「不確定領域（マージン）」そのもの。計算不能な「遊び」の存在が公理であり、変数特定による連続計算は否定される。

**Q5. 「公理」を名乗るのは数学的に乱暴では**
A. ご指摘はヒルベルト・プログラム以降の形式主義に基づく。本体系は実存する不連続な世界への回帰宣言として「公理（Axioma）」の語を採用する。

## 第6部　知財・防衛戦略

### 6-1. GitHubタイムスタンプの証拠能力

GitHubコミット日付はSHA-1ハッシュに組み込まれ改ざんが極めて困難。パブリックリポジトリは「防衛的公開（Defensive Disclosure）」として機能し、後日同一内容での特許取得を阻止できる。

### 6-2. HTML/GLSL実装の証拠価値

- コードが走り意図した通りの挙動を示す事実 = 数理モデルに矛盾がない証明
- GitHubコミットされたHTMLファイル = 特定アルゴリズムの先行技術として機能
- コード内コメントに公理名（例：`Axiom: Measurement Posteriority`）を明記することで、ロジックと用語を結びつける

### 6-3. 防衛すべき応用ドメイン

公理定義に「本公理は医療診断、ロボティクス、自動運転における不連続な位相制御に適用可能である」と一文記載するだけで広範な防衛が可能。

| ドメイン | 防衛核心 |
|---------|---------|
| 医療（がん治療等） | 細胞劣化を位相蓄積・跳躍として記述 |
| ロボット・車 | センサー誤差をバッファ排熱し不連続跳躍で安定化 |
| AI（LLM/エッジ） | 閾値ゲート（τ）による演算爆発防止 |
| スマートグリッド | 電力網の連鎖崩壊阻止（因果ダイオード） |
| 高頻度取引 | フラッシュ・クラッシュ防止（Circuit Breaker相当） |
