# nra-core/visualization 精査報告

- 検査日: 2026-07-14 JST
- 判定基準: ルート正典（AXIOMS v2.1、llms.md、llms.txt、FORMULA.md）および theory 精査結果
- 方針: 原本は変更せず、HTML/JavaScript/Python/PNGを静的精査
- 総合判定: **不合格（現行正典の説明資料・実証資料として使用不可）**

## 1. 横断的な重大問題

1. 多数の資料が旧版の固定境界 `R=1.0` と全面的な「沈黙」を採用している。v2.1の `R_warn`、`R_op`、`R_irrev`、WARNING、CONFESSION、OUT_OF_DESCRIPTION_DOMAIN、IRREVERSIBLE_BOUNDARY、RUPTURE、不可逆ラッチ、独立した証言継続を実装・説明していない。
2. 「比較」資料の多くは比較対象に異なる入力・更新則を与え、または従来方式を「速度だけ」「水位だけ」などに限定している。結論が実験結果ではなく初期設計に埋め込まれている。
3. 粒子・色・固定時刻・バー進捗を使って「熱排出」「概要消失」「積層成功」「Fail-Closed」を表示するが、対応する状態量・保存則・遷移則が実装されていない例が多い。
4. `G(r)=r|r|/(k+|r|)` を「飽和」「発散しない」と説明する資料があるが、`|r|→∞` では `G(r)≈r` で非有界である。
5. 「証明」「物理法則」「唯一の方法」等の強い表現に対し、定義・仮定・単位・検証可能な実験条件が不足している。
6. Google Fontsまたは `plotly-latest` CDNへの外部依存があり、オフライン再現性・版固定性がない資料がある。

### NRA_IDE_FullPaper_20260416.html

- 現況計算技術はすべて線形写像、突然破断のあらゆる原因、等の全称命題が未立証または誤り。

- 不確定性原理から一般的なNRAのdelta>0を直接導く。
- 推論段数と誤差の冪を同一視するが、一般的誤差伝播則ではない。
- 人命と費用の結論、閾値が唯一の方法、常に危険度を診断可能、という主張に論理的飛躍がある。
- 不合格の関連HTMLを根拠資料としてリンクする。
- 判定: 不合格。

## 3. 設定ファイル

`nra-core/.claude/settings.local.json` は、pandoc、wkhtmltopdf、weasyprint、markdown、reportlabの存在確認コマンドだけを許可するローカル設定である。秘密情報・理論内容はなく、正典との矛盾はない。Claude固有の個人設定を配布対象に含めるかはリポジトリ運用上の判断事項である。

## 4. 推奨処置

1. 現行正典と同じ公開階層から旧visualizationを隔離し、`legacy/`または`archive/`へ移す。
2. 「Proof」「証明」「Foundation」の名称を、検証可能な根拠がない資料から外す。
3. 新規visualizationは正典の状態機械・多段閾値・不可逆ラッチ・OUT_OF_DESCRIPTION_DOMAIN・証言継続を共通実装から参照する。
4. 比較実験は同一入力・同一外乱・同一観測量・同一時間刻みを使用し、結論を固定時刻や描画分岐へ埋め込まない。
5. delta、tau、R、熱、残差、エネルギーの単位と更新則を明示し、表示値と内部計算値を一致させる。
6. 外部ライブラリは版を固定するか、ローカルで再現できる構成にする。
