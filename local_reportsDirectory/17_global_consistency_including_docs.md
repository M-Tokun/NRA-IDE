# NRA-IDE 全体整合検査報告（docs追加版）

- 検査日: 2026-07-14 JST
- 対象: ルート指定文書、theory、nra-core、note、docs
- 位置付け: `12_global_consistency_review.md`へdocs 80件を追加した更新版
- 原資料変更: なし
- 総合判定: **不合格**

## 結論

v2.1の正典核は識別できるが、実装・研究ノートだけでなく公開docsも未同期である。docsは利用者が最初に読むREADME、図、公開Pythonで旧仕様を提示するため、内部の不整合を外部へ増幅する状態になっている。

## 範囲別判定

| 範囲 | 判定 | 主な問題 |
|---|---|---|
| ルート | 要修正 | Gの大残差近似・飽和語彙、正規R競合、表記残骸。 |
| theory | 要修正 | 正典順位、tau条件、二重ゆらぎ、Thesis自己順位、旧画像。 |
| nra-core | 不合格 | 公開実装、状態機械、量子コード、HTMLが現行不整合または実行不能。 |
| note | 不合格 | 研究履歴50件。旧仕様、未証明主張、危険な応用、版混在。 |
| docs | 不合格 | 公開入口80件に旧・中間・現行未満の三世代が混在。 |

## docs追加で確定した全体問題

- `NRA-IDE_Architecture_public.py`の不合格実装がnra-coreとdocsに重複し、公開参照点になっている。
- theoryで旧版と判定したTOP図・基礎式図がdocsでも現行図として表示される。
- docs READMEのR定義はルート正典と直接矛盾する。
- docs AI解説の状態機械は、正典と旧noteの中間に位置し、どの版が有効か利用者が判断できない。
- docs可視化は固定結果を演出し、note/nra-coreで確認した「証拠と演示の混同」を公開面で反復する。

## リポジトリ全体の最優先訂正順

1. AXIOMS.md / axioms.jsonの内部差を解消し、機械可読な唯一の状態仕様を確定する。
2. 正規Rと補助比・残差関数を別記号へ分離し、Gの数学的説明を訂正する。
3. v2.1準拠の単一参照実装と適合テストを作る。
4. docs README・公開Python・TOP図をその参照実装と同時更新する。
5. theory下位文書を同期し、nra-core/note/docsへ版manifestを配置する。
6. 旧資料・無効デモ・研究仮説を公開現行面から隔離する。
7. 医療・量子・社会・インフラ主張を対象別の検証が終わるまで概念例へ限定する。

## 最終判定

「全ファイル合格」「v2.1完全整合」「公開実装で安全性検証済み」という表明はできない。正典核の内部確定、単一参照実装、docs公開入口の同期を一続きの最初の修正単位とする必要がある。
