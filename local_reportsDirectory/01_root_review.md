## 2. 指摘事項

### ROOT-001 — `FORMULA.md` 5.4 の大残差近似が誤っている

- 重要度: 重大
- 状態: 確定
- 原文位置: `FORMULA.md` 501–526行（特に518–522行）

定義式は次である。

```text
G(r) = r|r| / (k + |r|)
```

`|r| >> k` では分母が `|r|` に漸近するため、正しい近似は次になる。

```text
G(r) ≈ r|r| / |r| = r
```

本文はここから `G(r) ≈ r sgn(r)` と結論しているが、これは `|r|` に等しく、負の `r` でも非負になる。元の `G(r)` は `r` と同符号の奇関数なので、本文の結論は定義式と矛盾する。

推奨訂正:

- 日本語・英語とも `G(r) ≈ r` に訂正する。
- 符号特性は「`G(r)` は大残差領域で `r` に線形漸近し、`r` と同じ符号を保持する」と説明する。

### ROOT-002 — 「飽和応答 / saturation response」が式の挙動と一致しない

- 重要度: 高
- 状態: 確定
- 原文位置: `FORMULA.md` 530–539行

`G(r)` は大残差領域で `r` に線形漸近し、絶対値が有界値へ飽和しない。「飽和応答」は数式の挙動と一致しない。

推奨訂正:

- 「線形漸近応答 / asymptotically linear response」等へ変更する。
- knee は「二次的小応答から線形漸近応答への遷移領域」と説明する。

### ROOT-003 — 正規記号 `R` が二重ゆらぎ式で再定義されている

- 重要度: 重大
- 状態: 上位正典との照合待ち。ただし文書間不整合は既に確認できる
- 原文位置: `llms.md` 89–93行、507–531行、および `FORMULA.md` 325–347行

`llms.md` は `R = delta / tau` を唯一の正規式とし、二重ゆらぎ検出は正規の `R` 状態分類を置換しないと規定している。

一方、`FORMULA.md` 4.6 は次を「最終判定式」としている。

```text
R = max(R_upper, R_lower)
```

集約された `delta`、`tau` と側別量との同値関係が示されていないため、同じ予約記号 `R` に別の計算定義を与えているように読める。これは `FORMULA.md` 7 の記号予約とも緊張する。

訂正候補:

1. 側別最大値を補助量として別記号へ変更し、正規 `R` と分離する。
2. 正規 `R` と数学的に同値であるなら、集約 `delta`、`tau` の定義と同値性を明記する。
3. 上位正典が側別最大値を正規 `R` と認める場合は、`llms.md` の「唯一の正規式」および二重ゆらぎの非置換規則も同時に整合させる。

最終案は `theory/AXIOMS.md` と `theory/axioms.json` を基準に決定する。
