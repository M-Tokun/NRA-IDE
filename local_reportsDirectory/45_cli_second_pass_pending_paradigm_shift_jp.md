## 2. 検出した問題

### 2.1 公理・数式・領域の分類境界がない

唯一公理「存在は生成である」、基礎式、二重ゆらぎ式／第二次式、IDEエンジン、生存式・生存領域、安全応用の分類が本文にない。

影響: パラダイムシフトの説明だけでは、唯一公理と二つの計算系を混同したり、NRA-IDE本体を安全判定機構へ縮小したりする解釈を防げない。

### 2.2 生存領域を安全判定へ縮小している

本文は一貫して`安全判定`と`構造的安全性`を中心にし、NRA-IDE本体である生存式・生存領域と、事故防止・運用・制御へ適用する安全域の部分関係を示していない。動的な生存の定義もない。

影響: 生存を同じ形の維持へ狭め、揺らぎ、相転移、破断、淘汰、消滅、再構成を通じた新構造・新履歴の生成を取りこぼす。

### 2.3 基礎式と正典状態モデルが欠落している

宣言対象について`delta`と`tau`から定まる基礎式`R=delta/tau`、三閾値`R_warn < R_handoff < R_irrev < 1`、七つの正典状態、不可逆ラッチが示されていない。`R = 1.0`だけを「構造が成立しなくなる相転移境界」と説明している。

影響: `R_handoff`と`R_irrev`の異なる役割、`RUPTURE_BOUNDARY`、入力不足・記述領域外の状態を識別できず、基礎式を宣言済み評価の範囲を超えて自然一般へ一般化する余地がある。

### 2.4 観測可能性と定量化可能性を区別していない

Cause-Side観測量には触れるが、非線形相転移領域で数値精度が低下しても物理的兆候を観察できること、観測値・単位・不確かさ・機器限界・変換規則・欠落情報を分離する条件がない。

影響: 定量化不能を観測不能とみなすか、逆に測定されていない精度を補完する解釈を許す。`CONFESSION`、`OUT_OF_DESCRIPTION_DOMAIN`、`NOT_OBSERVABLE`の適用境界も失われる。

### 2.5 Handoffを旧経路内の人間判断への遷移としている

見出しを`不可逆域接近点で人間へ渡す`とし、本文も`これは終わりではなく、判断を人間へ渡すという遷移`と記述している。

影響: `R_handoff`で固定Effect-Side証言を外部人間監査へ提示して旧経路を終端する境界ではなく、旧Effect-Sideから人間判断へ同じ因果経路を継続する構造になる。

### 2.6 Cause-SideとEffect-Sideの権限分離が不足している

結果側の値を学習目標・制御入力へ還流しない一般説明はあるが、値、三閾値、状態、不可逆ラッチ、規則、変換入力、更新根拠、出所への逆接続禁止がない。自動処理だけでなく、手動介入、人間レビュー、承認、版更新にも禁止が及ぶことを示していない。

影響: 旧Effect-Side情報を後続操作によってCause-Side権限へ転用する余地が残る。

### 2.7 因果ダイオードの完全一方向性と旧経路終端がない

旧Cause-Sideから旧Effect-Sideまでの一方向経路、旧Effect-Sideでの終端、事故後分析や将来規則作成が旧ダイオード外であることを明記していない。

影響: 外部監査、事故後分析、学習、承認を旧経路の続きとして扱い、因果逆流を許す。

### 2.8 独立した新履歴の開始条件がない

後続評価を、独立宣言した新対象、新しいCause-Side観測、事前固定した新規則、新しい因果ダイオードから開始する条件がない。旧Effect-Sideの値・閾値・状態・規則・変換入力・根拠・出所のimport、名称変更、再構成、再利用禁止もない。

影響: 古いEffect-Sideを旧Cause-Sideまたは新Cause-Sideへ変換し、別履歴の境界を消失させる。

### 2.9 Fail-Closedと固定証言の範囲がない

自律出力停止には触れるが、Fail-Closed対象状態、固定Handoff証言・最終固定証言、ログ、通常説明の許可範囲がない。

影響: 停止後に自由生成説明を追加したり、固定証言まで沈黙させたりする相反する実装が可能になる。

### 2.10 LLM三層構成を必須構造・保証としている

`Pre-NRA / LLM / Post-NRAをシステム全体の必須構造`とし、三層の一つが省略されると`NRA-IDEとしての保証は成立しません`と記述している。

影響: LLMを含まないNRA-IDE評価や、権限分離を別構成で実装する場合を誤って排除する。また、安全保証を与えない理論に保証成立条件があるように読める。層を描くこと自体が適合証明になる誤解も残る。

判定: `HARD_CONFLICT / SEMANTIC_DRIFT / CLASSIFICATION_BOUNDARY_CONFLICT / HISTORY_BOUNDARY_CONFLICT / GUARANTEE_SCOPE_CONFLICT`
