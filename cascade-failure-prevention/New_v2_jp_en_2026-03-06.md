# 変更履歴：二重ゆらぎ構造の実装および各部修正 2026-03-26

本アップデートでは、システムのコアとなるゲートサービスに対して「二重ゆらぎ構造」を新たに実装しました。これに伴い、デプロイメント設定の同期、APIエンドポイントの拡張、Envoy統合部分の健全性回復、および検証用ツールの拡充を行っています。また、運用と理論の整合性を確保するため、各種ドキュメントに新たな計算式やパラメータ調整のガイドラインを追記しました。

## 1. コアサービスおよび連携モジュールの改修

システムの根幹となるロジック部分において、破損の修正と新機能の統合を行いました。

* **`gate/han_gate_service.py`**: コードの破損箇所を修正するとともに、今回の要となる「二重ゆらぎ構造」のメインロジックを実装しました。

* **`integrations/envoy/telemetry_sidecar.py`**: テレメトリ処理におけるコードの破損を修正し、正常に稼働する状態へ復旧させました。

## 2. デプロイメントおよびインフラ設定の同期

インフラ側で新しいゆらぎ構造のパラメータを適切に処理できるよう、設定ファイルの修正と同期を行いました。

* **`deploy/k8s/han-gate.yaml`**: ConfigMap内のコードを本体の最新実装と同期させました。また、新たな環境変数として `TAU_EMA_ALPHA` と `TAU_AMPLIFY` を追加定義しています。

* **`integrations/envoy/k8s_envoy_han.yaml`**: YAML定義におけるインデントの破損を修正しました。さらに、`lua_shared_dict` のメモリ割り当てを `10m` に設定し、処理の最適化を図っています。

## 3. API仕様と検証ツールの拡張

新たなパラメータと監視要件に合わせて、インターフェースとテスト群を強化しました。

* **`api/openapi.yaml`**: 新たに観測用の `/metrics` エンドポイントを定義し、既存の仕様に `tau` パラメータを追加しました。

* **`tools/han_validation_test.py`**: R値の計算に関するコメントを現状の仕様に合わせて修正しました。加えて、EMA（指数移動平均）の挙動テストおよび、新設した `/metrics` エンドポイントに対する検証テストを追加しています。

## 4. ドキュメントの更新

理論的背景と実際の運用方法を明確にするため、関連ドキュメントの加筆・修正を行いました。

* **`docs/SPEC.md`**: 二重ゆらぎに関する新たな計算式と、それに付随するパラメータの定義表を追記しました。

* **`docs/RUNBOOK.md`**: 実際の運用環境に向け、新たに追加されたパラメータ（`TAU_EMA_ALPHA`, `TAU_AMPLIFY`）の具体的な調整ガイドを追加しました。

* **`日本語総合解説.md`**: 読者の混乱を避けるため、ドキュメント内に記載されている旧式のコードサンプルに対して「概念説明用」である旨の注釈を明記しました。

# Changelog: Implementation of Dual Fluctuation Structure and Component Fixes  26-03-06

In this update, we have implemented the new "Dual Fluctuation Structure" into the core gate service. Alongside this major architectural update, we have synchronized the deployment configurations, expanded the API endpoints, restored the integrity of the Envoy integration components, and enhanced the validation tools. Furthermore, to ensure alignment between theoretical design and practical operation, we have updated the documentation with new calculation formulas and parameter adjustment guidelines.

## 1. Core Service and Integration Module Refactoring

We addressed code corruption and integrated the new functionality within the system's core logic.

* **`gate/han_gate_service.py`**: Repaired corrupted code segments and implemented the primary logic for the new "Dual Fluctuation Structure."

* **`integrations/envoy/telemetry_sidecar.py`**: Fixed broken code in the telemetry processing module, fully restoring its normal operational state.

## 2. Deployment and Infrastructure Configuration Synchronization

We synchronized and updated the configuration files to ensure the infrastructure accurately processes the parameters of the new fluctuation structure.

* **`deploy/k8s/han-gate.yaml`**: Synchronized the code within the ConfigMap with the latest main implementation. Additionally, introduced new environment variables: `TAU_EMA_ALPHA` and `TAU_AMPLIFY`.

* **`integrations/envoy/k8s_envoy_han.yaml`**: Corrected broken indentation in the YAML definition. Furthermore, allocated `10m` to `lua_shared_dict` to optimize memory and processing performance.

## 3. API Specification and Validation Tool Expansion

We enhanced the interfaces and test suites to accommodate the new parameters and monitoring requirements.

* **`api/openapi.yaml`**: Defined a new `/metrics` endpoint for observability and added the `tau` parameter to the existing specifications.

* **`tools/han_validation_test.py`**: Revised the comments regarding the R-value calculation to match current specifications. Also, added behavioral tests for EMA (Exponential Moving Average) and validation tests for the newly established `/metrics` endpoint.

## 4. Documentation Updates

We revised and expanded the related documentation to clarify the theoretical background and practical operational procedures.

* **`docs/SPEC.md`**: Appended new calculation formulas regarding the dual fluctuation and added definition tables for the associated parameters.

* **`docs/RUNBOOK.md`**: Added a specific adjustment guide for the newly introduced parameters (`TAU_EMA_ALPHA`, `TAU_AMPLIFY`) intended for the actual production environment.

* **`日本語総合解説.md`**: To prevent reader confusion, explicitly added annotations stating "for conceptual explanation purposes only" to the legacy code samples documented within.
